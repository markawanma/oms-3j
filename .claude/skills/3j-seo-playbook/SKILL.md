# SEO Playbook — 3J Jewelry (3jthailand.com)

## 0. 🔴 อ่านก่อน: อะไรบล็อกทุกอย่างอยู่ตอนนี้

**สินค้า 290 ตัวบนเว็บโชว์ `US$0.00` และสกุลเงินเป็น USD** (ยืนยันด้วยตาเปล่าบนเว็บจริง
28 ส.ค. 69 · บันทึกครั้งแรก `docs/3j-jewelry/web/HANDOFF-wix.md` 26 ส.ค.)
`sku` ว่าง · `description` ว่าง · `visible: true` = คนเห็นได้หมด

**อย่าเสนอแผน SEO ที่ไม่พูดถึงเรื่องนี้** — หน้า product 290 หน้าที่ไม่มีราคา/คำอธิบาย
คือหน้าคุณภาพต่ำ 290 หน้าที่ลากทั้งโดเมนลง และต่อให้ติดอันดับก็ไม่มีใครซื้อ
**เรียงลำดับเสมอ: แก้ของที่พังก่อน แล้วค่อยเพิ่มของใหม่**

## 1. ความจริงของธุรกิจ ณ ส.ค. 69 (แผน SEO เก่ายังไม่รู้เรื่องนี้)

| | ม.ค. | ส.ค. |
|---|---|---|
| เงินแท่ง | ฿12.0M (98.9%) | ฿137k (17.2%) |
| เครื่องประดับ | ฿130k | **฿664k (82.8%)** |

- เครื่องประดับ **+412%** · เงินแท่ง **−98.9%** · **ส.ค. ราคาเงินเด้ง +9.3% แต่คนยังไม่กลับ**
- `positioning-2pillar.md` (6 ส.ค.) วางหัวหอกเป็น **เงินแท่ง + OEM** —
  **ไม่มีเสาสำหรับเครื่องประดับปลีกซึ่งตอนนี้คือ 83% ของยอด** นี่คือช่องว่างหลักที่ต้องปิด
- ยอดเครื่องประดับ 83% มาจากไลฟ์ TikTok = **พื้นที่เช่า** ไม่ใช่สินทรัพย์ของร้าน
  → เหตุผลเชิงธุรกิจของ SEO คือ "สร้างช่องทางที่เป็นของเราเอง" ไม่ใช่แค่ traffic

## 2. เว็บคือ Wix — แก้อะไรได้/ไม่ได้ (สำคัญมาก อย่าเสนอสิ่งที่ทำไม่ได้)

| งาน | ผ่าน API | หมายเหตุ |
|---|---|---|
| ราคา / ชื่อสินค้า / คำอธิบาย / SKU | ✅ | ต้องมีข้อมูลจากเจ้าของก่อน |
| SEO title / description รายสินค้า | ✅ | |
| ซ่อน/แสดงสินค้า | ✅ | ใช้ซ่อนหน้าคุณภาพต่ำระหว่างรอข้อมูลได้ |
| เปลี่ยนสกุลเงิน USD → THB | ❌ | ตั้งค่าในแดชบอร์ด เจ้าของต้องกดเอง |

`3jthailand.com` ก่อนเขียนอะไรลงไป **ห้ามเดา** (เขียนผิดไซต์ = แก้ของที่ไม่ควรแก้)

## 3. ค้นภาษาไทยไม่เหมือนอังกฤษ — จุดที่ทำพลาดกันบ่อย

- **ภาษาไทยไม่เว้นวรรคระหว่างคำ** — การตัดคำเป็นเรื่องของเครื่อง อย่าคิดว่า keyword
  ยาวๆ จะถูกจับเหมือนภาษาอังกฤษ
- **คนไทยพิมพ์ปนอังกฤษ** ("แหวนเงิน 925", "silver bar ราคา") และ**สะกดหลายแบบ**
  ("เงินแท่ง"/"แท่งเงิน", "925"/"เงินแท้") → ต้องเก็บ variant ไม่ใช่คำเดียว
- **คำที่ใช้ในไลฟ์ ≠ คำที่คนพิมพ์ค้น** — ในไลฟ์พูด "เฉพาะไลฟ์ 2 กรัม" แต่คนค้นว่า
  "สร้อยเงินแท้ ราคา" → **อย่าเอาชื่อ SKU ภายในไปทำ keyword**
- **intent ต่างกันมาก**: "ราคาเงินวันนี้" (เช็คราคา ไม่ซื้อ) vs "ซื้อเงินแท่งที่ไหน"
  (พร้อมซื้อ) vs "เงินแท่ง 925 ต่างกันยังไง" (หาความรู้) — หน้าเดียวตอบไม่ได้ทุก intent

## 4. 🚫 ห้ามเดาตัวเลข — ต้องค้นจริงทุกครั้ง

**ห้ามเขียนในรายงานเด็ดขาด** ถ้าไม่ได้ค้นมาจริงในรอบนั้น:
- ปริมาณการค้นต่อเดือนของคำใดๆ
- อันดับปัจจุบันของเราหรือคู่แข่ง
- "คำนี้แข่งขันต่ำ/สูง"

ให้ค้นจากของจริง (Google ไทย, เว็บคู่แข่ง, autocomplete, People-also-ask) แล้ว
**ระบุเสมอว่าอันไหนคือสิ่งที่เห็น อันไหนคือการตีความ**
ถ้าเข้าเครื่องมือไม่ได้ ให้เขียนว่า "ยังไม่มีข้อมูล ต้องใช้เครื่องมือ X" — **ห้ามเติมตัวเลขให้ดูสมบูรณ์**

⚠️ ยังไม่มีใครยืนยันว่าเว็บต่อ Google Search Console แล้วหรือยัง — **ถ้ายังไม่ต่อ
นี่คืองานแรกก่อนพูดเรื่องวัดผลใดๆ** (ไม่งั้นเราจะทำ SEO โดยมองไม่เห็นผล)

## 5. กฎแบรนด์ที่จำกัดเนื้อหาบนหน้าเว็บ (ผิดข้อนี้เสียหายกว่าอันดับตก)

โหลด `3j-brand-and-market` ควบเสมอ สรุปส่วนที่กระทบ SEO:
- **ห้ามระบุตัวเลขส่วนต่างรับซื้อคืนบนหน้าเว็บ** — ผูกกับราคาเนื้อเงินที่เปลี่ยนทุกวัน
  ⚠️ `positioning-2pillar.md` เขียน "buy-back หัก 30บ./บาท" เป็น trust signal — **ขัดกฎนี้ ต้องแก้**
  พูดได้แค่ "อ้างอิงราคาเนื้อเงิน ณ วันที่ลูกค้าจัดส่ง"
- **925 ห้ามเทียบราคาเงิน spot** · **OEM ห้ามมีราคาสาธารณะ** · ราคาส่งเฉพาะส่งออก 30–100 ชิ้น
- เงินแท่งเปิดราคาได้เต็มที่ (มีระบบราคา realtime บนหน้าอยู่แล้ว)

## 6. งานพื้นฐานที่ยังไม่มีใครทำ (ตรวจก่อนเสนอของใหม่)

ไล่เช็คของจริงก่อนเสมอ อย่าสมมติว่ามีหรือไม่มี:
- title/description รายหน้า — ซ้ำกันไหม ว่างไหม
- schema markup: `Product` (ราคา/สต็อก) · `Organization` + `LocalBusiness` (มีหน้าร้านจริง = ข้อได้เปรียบ)
- โครงลิงก์ภายใน — หน้าใหม่ที่ไม่มีลิงก์เข้าถึงเท่ากับไม่มีอยู่
- `robots.txt` / sitemap — 290 หน้าราคา $0.00 ควรถูก noindex ระหว่างรอข้อมูลไหม
- ความเร็ว/มือถือ — ลูกค้าเกือบทั้งหมดมาจากมือถือ (TikTok/LINE)

## 7. รูปแบบส่งมอบ

ทุกข้อเสนอต้องมี: **ทำอะไร → ใครทำได้ (agent ผ่าน API / เจ้าของใน Wix Editor) →
ผลที่คาดและเมื่อไหร่ → วัดด้วยอะไร**
- แยก **"แก้ของที่พัง"** กับ **"เพิ่มของใหม่"** เสมอ และเรียงของที่พังก่อน
- SEO เป็นเกม 6–12 เดือน — **ห้ามสัญญาผลเร็ว** และต้องบอกเจ้าของตรงๆ ว่าอะไรจะยังไม่เห็นผลใน Q4
- ถ้าประเมินว่าบางงานไม่คุ้มลงแรงในสเกลนี้ (งบ 30k/เดือน คนทำจำกัด) **บอกตรงๆ อย่าเสนอให้ครบตามตำรา**
