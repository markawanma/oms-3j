# CEO Branding + อัตลักษณ์แบรนด์ — 3J Jewelry

> ใช้คู่กับ `3j-brand-and-market` (น้ำเสียงแบรนด์ + กฎการเปิดราคา) — ไฟล์นี้เสริมเฉพาะ
> ส่วน "ตัวคน" ที่ไฟล์นั้นไม่ได้ครอบคลุม

## 0. 🔴 กฎเหล็กข้อเดียวที่สำคัญที่สุด

**ห้ามแต่งเรื่องเจ้าของ แม้แต่รายละเอียดเล็ก**

CEO branding ทำงานได้เพราะ**คนเชื่อว่าจริง** — แต่งเรื่องแล้วโดนจับได้ครั้งเดียว
เสียมากกว่าที่ได้ทั้งหมด และผู้ชมไทยจับ "เรื่องเล่าที่ปั้น" ได้เร็วมาก
ทุกประโยคที่เป็น "เรื่องของเจ้าของ" ต้องมาจากปากเจ้าของหรือหลักฐานที่ตรวจได้เท่านั้น

**ถ้าไม่มีข้อมูล → ถาม ไม่ใช่เดา** (มีรายการคำถามข้อ 4)

## 1. ข้อเท็จจริงที่ยืนยันแล้ว — เคลมได้

| ข้อเท็จจริง | แหล่งยืนยัน |
|---|---|
| โรงงานผลิตเงินเอง **30+ ปี** | เว็บทางการ 3jthailand.com (ทั้งไทย/อังกฤษ) |
| รับผลิต OEM ให้แบรนด์ทั้งในและต่างประเทศ | เว็บทางการ |
| ผลิต**เงินแท่ง 999** และ**เครื่องประดับเงิน 925** | เว็บ + ข้อมูลขายจริงใน DB |
| **ไลฟ์ขายทุกคืน 20:00–23:00** · 83% ของออเดอร์ TikTok เกิดช่วงไลฟ์ | ข้อมูลออเดอร์จริง |
| มีหน้าร้าน/ที่ตั้งจริง (บางขุนเทียน จอมทอง กทม.) | ที่อยู่ผู้ส่งบนใบปะหน้าจริง |
| รับซื้อคืนเงินแท่งจริง | เว็บ + นโยบายที่เจ้าของยืนยัน |
| เจ้าของสร้างระบบหลังบ้าน (OMS/CRM) ของตัวเองอยู่ | งานที่ทำร่วมกันทุกวัน |

## 2. ⛔ ยังไม่ยืนยัน — ห้ามใช้จนกว่าจะถาม

- เจ้าของเป็นรุ่นที่เท่าไหร่ของโรงงาน · เข้ามาทำเมื่อไหร่ · เรื่องราวจุดเริ่มต้น
- เจ้าของเป็นคนจัดไลฟ์เองหรือมี host
- ตัวเลขใดๆ ที่ยังไม่เคยพูดออกสื่อ (จำนวนพนักงาน ยอดขาย กำลังผลิต ชื่อลูกค้า OEM)
- ธุรกิจในเครืออื่น (Golden Energy solar, ชุนหลีคลินิก) — **เป็นข้อมูลภายใน
  ห้ามผูกเข้าเรื่องเล่า 3J จนกว่าเจ้าของจะบอกว่าเปิดเผยได้**
- ความเชี่ยวชาญส่วนตัว (เจียระไน? หลอม? ออกแบบ?) — **อย่าสมมติว่าเจ้าของทำเป็นทุกอย่าง**

## 3. ทำไม CEO branding คุ้มสำหรับร้านนี้โดยเฉพาะ

จาก research คู่แข่ง (28 ส.ค.): ตลาดแยกเป็นสองขั้ว — ร้านพลอย/เงินไลฟ์แบบบ้านๆ
กับแบรนด์มูพรีเมียมในห้าง (MARON, Harmenstone ยอดร้อยล้าน/ปี)
**ตรงกลาง "ของแท้ + รู้จริง + ราคาเข้าถึงได้" ยังโล่ง**

- คู่แข่งมีงบและหน้าร้านห้างที่เราสู้ไม่ได้ — **แต่ไม่มีเจ้าของโรงงานที่เดินเข้าไลน์ผลิตได้ทุกวัน**
- "โรงงาน 30 ปี" เป็น**หลักฐานที่ลอกไม่ได้** ต่างจากดีไซน์/แคปชั่นที่ลอกได้ในวันเดียว
- ร้านไลฟ์ทุกคืน = เจ้าของ**มีเวทีอยู่แล้ว** ไม่ต้องสร้างช่องทางใหม่ ต้นทุนเพิ่ม ≈ 0

## 4. คำถามที่ต้องถามเจ้าของก่อนเริ่ม (อย่าเริ่มเขียนก่อนได้คำตอบ)

1. **สบายใจแค่ไหนที่จะออกหน้า** — เห็นหน้า/เสียงอย่างเดียว/ไม่ออกเลยแต่ให้เล่าเรื่องโรงงาน
2. **รุ่นที่เท่าไหร่ และเข้ามาทำเพราะอะไร** — แกนของเรื่องเล่าทั้งหมดอยู่ตรงนี้
3. **มีอะไรที่ห้ามพูดถึงเด็ดขาด** (ครอบครัว ตัวเลข ชื่อลูกค้า OEM สถานที่)
4. **ถ่ายในโรงงานได้ไหม** ส่วนไหนถ่ายได้/ไม่ได้ (ความลับทางการค้า)
5. **มีเวลาให้เท่าไหร่ต่อสัปดาห์** — แผนที่กินเวลาเกินจริงคือแผนที่ไม่ได้ทำ
6. **ธุรกิจในเครืออื่นเปิดเผยได้ไหม**

## 5. มุมที่ใช้ได้ (เรียงตามความปลอดภัย)

**ปลอดภัยสุด — เริ่มจากตรงนี้ ไม่ต้องออกหน้าก็ได้:**
- **กระบวนการผลิต** — หลอม/หล่อ/ขัด/ชุบ ของจริง (ตอบ objection "แท้ไหม" ไปพร้อมกัน)
- **ความรู้ที่คนหาจริง** — เงินแท้ดูยังไง · 925 กับ 999 ต่างกันยังไง · ทำไมเงินดำ · ดูแลยังไง
  (คนไทยค้นเรื่องนี้เยอะ และเป็นความรู้ที่โรงงานตอบได้ดีที่สุด)
- **เบื้องหลังไลฟ์** — เตรียมของ แพ็ก ส่ง

**ได้ผลแรงกว่าแต่ต้องเจ้าของยินยอม:**
- เจ้าของเล่าเอง: ทำไมถึงทำ · เจออะไรมา · ตัดสินใจยากๆ ครั้งไหน
- ตอบคำถามลูกค้าหน้ากล้อง (เอาคำถามจริงจากไลฟ์/แชท)

**⛔ ห้ามทำ:**
- อวดรวย/โชว์ยอด — ขัดน้ำเสียงแบรนด์ "ตรงไปตรงมา ไม่ขายฝัน" และดึงลูกค้าผิดกลุ่ม
- แต่งดราม่า/เรื่องซึ้งที่ไม่เคยเกิด
- เคลมสถานะ ("เจ้าแรก" "รายใหญ่ที่สุด") โดยไม่มีหลักฐาน — **เข้าข่ายโฆษณาเกินจริง**
- พูดแทนเจ้าของในเรื่องความเชื่อ/การเมือง/เรื่องส่วนตัว

## 6. ความเสี่ยงที่ต้องบอกเจ้าของก่อน

- **ผูกแบรนด์กับคน = ถอนยาก** วันที่อยากถอยไปอยู่หลังฉากจะทำได้ยากขึ้น
- **ตัวตนต้องสม่ำเสมอ** — โผล่เดือนละครั้งไม่สร้างอะไร ต้องทำได้ต่อเนื่องจริง
- **คำที่พูดครั้งเดียวอยู่ตลอดไป** — โดยเฉพาะเรื่องราคา/รับซื้อคืน/คุณภาพ
  (กฎใน `3j-brand-and-market` ใช้กับคำพูดเจ้าของเข้มกว่าคำโฆษณาปกติ
  เพราะคนเชื่อคำเจ้าของมากกว่า)
- **สายมู**: ตลาดใหญ่จริง แต่ **สคบ. เตรียมออกกฎคุมโฆษณาเครื่องรางอวดอ้างเกินจริง**
  เล่าความเชื่อได้ ("คนโบราณเชื่อว่า...") **ห้ามรับประกันผล** — และเจ้าของพูดเองยิ่งเสี่ยงกว่า

## 7. วัดผลยังไง

CEO branding วัดด้วย engagement/ยอดขายตรงๆ ไม่ได้ในระยะสั้น ให้ดู:
- คนดูไลฟ์ที่**อยู่นานขึ้น** (ไม่ใช่แค่จำนวนคนเข้า)
- คำถามในแชทเปลี่ยนจาก "ราคาเท่าไหร่" → "อันนี้ทำยังไง/ต่างจากอันนั้นยังไง"
- คนทักมาอ้างถึงคลิปที่เคยดู
- สัดส่วนลูกค้าที่กลับมาซื้อซ้ำ (ตอนนี้ทั้งร้านเฉลี่ยแค่ 1.76 ครั้ง/คน — ต่ำ)

**ห้ามสัญญาว่าจะเห็นผลใน 1 เดือน** — ถ้าเจ้าของอยากได้ผลเร็ว ให้บอกตรงๆ ว่าตัวนี้ไม่ใช่คำตอบ
