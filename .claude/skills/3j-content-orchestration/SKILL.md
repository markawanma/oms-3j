# ระเบียบสั่งงานสาย content — 3J

## ทำไม skill นี้ต้องมี

**subagent เรียก subagent ไม่ได้** ⇒ CMO สั่ง K-2SO/Maz/Padmé เองไม่ได้ ต่อให้ผังองค์กรบอกว่าเป็นลูกน้อง
**การประสานงานจึงตกที่ session หลักเสมอ ทั้งสาย dev และ content** เปลี่ยนด้วยการเพิ่มตำแหน่งไม่ได้

และสาย dev มีด่านครบ (design → security + QA คู่ขนาน → review) **แต่สาย content ไม่มีด่านอะไรเลย**
คนสั่ง คนตรวจ คนอนุมัติ เป็นคนเดียวกันหมด — skill นี้คือด่านที่หายไป

⚠️ **skill นี้ไม่ได้เก็บความรู้การตลาด** ความรู้อยู่ที่ `3j-brand-and-market` · `3j-founder-brand` ·
`3j-seo-playbook` แล้ว **ห้ามเขียนซ้ำที่นี่** ที่นี่เก็บแต่ "ลำดับและด่าน"

## 1. ลำดับงานบังคับ (ห้ามข้ามขั้นแรก)

```
ข้อมูลจริงก่อน (GSC / DB / เปิดเว็บจริง)
  → กลยุทธ์ (cmo / seo-specialist)
  → โครง (content-strategist / ux-ui)
  → เขียน (copywriter)
  → 3 ด่านตรวจ (ข้อ 2)
  → เจ้าของอนุมัติ
  → เผยแพร่
```

**ขั้นแรกคือขั้นที่คนข้ามบ่อยที่สุดและแพงที่สุด** — 29 ส.ค. 69 แผนพัง 2 รอบเพราะตัดสินจาก
เอกสารเก่าแทนข้อมูลจริง: สมมติฐาน "โรงงาน OEM ไทยหาบน Google ไม่เจอ" (ผิด เจอคู่แข่ง 8 ราย)
และการประเมินว่าเว็บไม่มีอะไรใช้ได้ (ผิด GSC ต่อไว้แล้วตั้งแต่แรก)

**ถ้าเอกสารในรีโปขัดกับสิ่งที่เพิ่งเปิดดูจริง — ของจริงชนะเสมอ แล้วไปแก้เอกสาร**

## 2. 🔴 3 ด่านก่อนอะไรก็ตามขึ้นสาธารณะ

| ด่าน | ตรวจอะไร | ใครตรวจ | ถ้าไม่ผ่าน |
|---|---|---|---|
| **ข้อเท็จจริง** | ตัวเลข · มาตรฐาน · หน่วยวัด · คุณสมบัติวัสดุ | `docs-researcher` ต้องส่ง **URL + ระดับความมั่นใจ** | เขียนว่า "ยังไม่มีข้อมูล" — ห้ามเติมให้ครบ |
| **กฎแบรนด์** | ราคา · spread รับซื้อคืน · เทียบ 925 กับ spot · ตัวเลข OEM · คำเด็ดขาด | เช็คกับ `3j-brand-and-market` (มีเช็คลิสต์ 6 ข้อท้ายไฟล์) | ตีกลับให้แก้ ห้ามแก้เองแล้วปล่อยผ่านเงียบๆ |
| **ความเสี่ยง** | ภาษี · สุขภาพ/ผิวหนัง · การลงทุน | **ห้ามทีมตอบเอง** ต้องเจ้าของ/ผู้เชี่ยวชาญยืนยัน | ตัดหัวข้อออก ดีกว่าขึ้นแบบค้าง placeholder |

**เส้นแบ่งที่สำคัญที่สุดของด่านความเสี่ยง**: เขียนถึง **"สิ่งที่ร้านทำ"** ได้เสมอ ·
เขียนถึง **"กฎหมายว่ายังไง"** ไม่ได้
✅ "ราคารับซื้อคืนที่เราประกาศเป็นราคาสุทธิ ไม่มีบวก/หัก VAT เพิ่ม"
❌ "ขายคืนไม่ต้องเสีย VAT" ← ชี้ขาดภาษีแทนลูกค้า เรารับผิดชอบไม่ไหว

## 3. วินัยการเขียน brief สาย content

(คู่ขนานกับวินัย brief สาย gate/security ใน CLAUDE.md — คนละสายแต่เหตุผลเดียวกัน)

- **แนบข้อมูลจริง ไม่ใช่แค่เจตนา** — ตัวเลขจาก DB/GSC/หน้าเว็บจริง พร้อมวันที่ที่ดึง
- **ระบุสิ่งที่ห้ามพูดเป็นข้อๆ** ไม่ใช่ "ระวังเรื่องราคา" แต่ไล่: ห้ามตัวเลขส่วนต่าง / ห้ามเทียบ spot /
  ห้ามคำว่าแน่นอน-ไม่จำกัด-ทุกกรณี
- **บอกด้วยว่าอะไร "ห้ามพัง"** ไม่ใช่แค่ "ห้ามผิด" — เนื้อหาที่ปลอดภัยจนไม่มีใครอยากอ่านก็คือของเสีย
- **ปิดท้ายทุก brief ด้วย "ถ้าคิดว่าสั่งผิดหรือมีช่องโหว่ บอกทันที"** — ทีมนี้เถียงกลับถูกมาแล้วหลายครั้ง
- **สั่งเสมอว่าใกล้หมดเวลาให้ส่งเท่าที่ได้ อย่าค้าง** (agent เคยตายกลางงานหลายครั้ง)
- **ห้ามใช้ browser automation** ในงาน content/research

### 🔴 กฎที่สำคัญที่สุดของข้อนี้: ตัวเลขภายในห้ามเข้า brief ของคนเขียน copy สาธารณะ

**ห้ามส่งเข้าไปเลยแม้แต่ในหมายเหตุหรือคำอธิบายประกอบ**: ต้นทุน · ค่ากำเหน็จ · ส่วนต่างรับซื้อคืน ·
margin · MOQ · ค่า CAD · ราคาส่งออก
ให้ส่งเฉพาะ **ข้อสรุปที่เผยแพร่ได้** และเขียนกำกับว่า
*"ถ้ารู้สึกว่าข้อมูลไม่พอจะเขียนให้น่าเชื่อ ให้บอกกลับมา อย่าเติมเอง"*

**เหตุผล**: ถ้าตัวเลขเข้าไปอยู่ในไฟล์ร่างแล้ว มีโอกาสติดไปถึงหน้าเว็บโดยไม่มีใครทันสังเกต
การกักไว้ที่ชั้นคนสั่งคือด่านที่ถูกที่สุดและแน่นที่สุด

## 4. เมื่อไหร่ต้องถามเจ้าของ vs ตัดสินเอง

**เกณฑ์เดียว: ถ้าตอบผิดแล้วแก้ได้ใน 5 นาทีและยังไม่มีใครนอกเห็น → ตัดสินเอง**

| ต้องถามเสมอ | ตัดสินเองได้ |
|---|---|
| ตัวเลขภายในที่มีแต่เจ้าของรู้ (น้ำหนักสินค้าจริง, ต้นทุน, MOQ) | ลำดับงาน · การจัดหมวด · โครงไฟล์ · การตั้งชื่อ |
| นโยบาย/ขอบเขตบริการ (รับซื้อคืนแบรนด์อื่นไหม) | ถ้อยคำที่ไม่แตะตัวเลข/นโยบาย |
| ความเสี่ยงทางกฎหมาย/ภาษี | งานที่ย้อนกลับได้ทันทีและยังไม่เผยแพร่ |
| การเปิดข้อมูลที่เคยห้ามไว้ (เช่น จะเปิด MOQ ไหม) | การเลือกว่าจะส่ง agent ตัวไหนทำอะไร |
| อะไรที่กระทบเงิน/ชื่อเสียง และกลับยาก | |

**ถามให้น้อยแต่ถามให้ตรง** — ถามทุกอย่างทำให้เจ้าของกลายเป็นคอขวด
แต่เดาในช่องซ้ายมือแพงกว่าถามเสมอ

## 5. เจ้าของกลับมติ = ต้องเขียนทับเอกสารทีม ห้ามจบที่แชท

ถ้าเจ้าของตัดสินต่างจากที่ทีมเสนอ **ต้องกลับไปแก้เอกสารที่ทีมเขียนไว้ทันที**
พร้อมระบุ **วันที่ · เหตุผลของเจ้าของ · เงื่อนไขที่ผูกมากับมติใหม่**

**ถ้าไม่ทำ อีก 2 เดือน agent ตัวเดิมจะอ่านเอกสารเก่าแล้วเสนอสิ่งเดิมซ้ำ**
(29 ส.ค. 69: CMO เขียนว่า "IG ❌ ไม่ทำ" ด้วยเกณฑ์ ROI — เจ้าของกลับมติเพราะ IG คือสินทรัพย์แบรนด์
ไม่ใช่ช่องขาย ⇒ ต้องเขียนทับใน `docs/3j-jewelry/marketing/audit-and-replan-28aug.md` ไม่ใช่ตอบในแชทเฉยๆ)

## 6. บทเรียนจริง 29 ส.ค. 69 — 4 จุดที่ด่านนี้มีไว้จับ

| เกิดอะไร | ด่านที่ควรจับ |
|---|---|
| Tech Lead ถอดค่า "1 บาทน้ำหนัก = 15.16 ก." จาก**อัตราส่วนราคา** แล้วบอกทีมว่า "ยืนยันแล้ว" | ข้อเท็จจริง |
| copywriter เขียน "ลูกค้าไม่ต้องเตรียมเอกสารทางภาษีฝั่งตัวเอง" | ความเสี่ยง |
| copywriter เขียน "รับซื้อคืนได้เสมอ" ทั้งที่เจ้าของพูดว่า "ปกติจะรับคืนอยู่แล้ว" | กฎแบรนด์ |
| แผน OEM ตั้งอยู่บนสมมติฐานจากเอกสารเก่าที่ไม่มีใครตรวจ | ลำดับงานข้อ 1 |

**ทั้ง 4 ถูกจับได้ที่ชั้น Tech Lead — แต่จับได้เพราะบังเอิญละเอียดวันนั้น ไม่ใช่เพราะระบบบังคับ**
skill นี้มีไว้ทำให้มันไม่ขึ้นกับความบังเอิญ

**และกฎที่แพงที่สุดจากวันนั้น**: ห้ามอนุมานค่าคงที่/มาตรฐาน/หน่วยวัด จากตัวเลขราคา —
ราคาคือสิ่งที่คนตั้ง ไม่ใช่ฟิสิกส์ · **ตัวเลขที่ "พอดีเป๊ะ" กับสมมติฐาน คือสัญญาณให้ตรวจซ้ำ ไม่ใช่สัญญาณว่าถูก**
