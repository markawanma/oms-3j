# Mobile Vet Clinic — สรุปสำหรับหารือหุ้นส่วน

> เอกสารสรุปแนวคิดธุรกิจ + ข้อเสนอความร่วมมือ · ปรับปรุง 17 ก.ค. 2026
> วัตถุประสงค์: ใช้เป็นกรอบพูดคุยกับผู้ร่วมทุน/สัตวแพทย์ผู้ร่วมงาน — ตัวเลขเป็นประมาณการเบื้องต้น ต้อง validate ร่วมกัน

---

## 1. แนวคิดธุรกิจ

**สัตวแพทย์เคลื่อนที่ (Mobile Vet)** ให้บริการดูแลสุขภาพสัตว์เลี้ยงถึงที่ — เจาะกลุ่มคอนโด/หมู่บ้าน pet-friendly

- **จุดต่าง:** มี connection กับโครงการของ **แสนสิริ (Sansiri) และ ออริจิน (Origin)** → เข้าถึงลูกบ้านที่เลี้ยงหมาแมวโดยตรง (ต้นทุนหาลูกค้าต่ำ)
- **Pain point ที่แก้:** เจ้าของสัตว์ในคอนโดพาสัตว์ไปคลินิกลำบาก (โดยเฉพาะแมวที่เครียด/ขนส่งยาก และคนไม่มีรถ)
- **Positioning:** "ดูแลสุขภาพสัตว์เลี้ยงประจำปี ถึงหน้าบ้าน" — เน้น preventive care ไม่ใช่คลินิกรักษาทุกโรค

## 2. ขอบเขตบริการ

**ทำ (onsite):** วัคซีน, ตรวจสุขภาพประจำปี, เจาะเลือดพื้นฐาน, ถ่ายพยาธิ/ป้องกันเห็บหมัด, ทำแผลเล็ก, ตรวจผิวหนัง/หู/ตา/ฟันเบื้องต้น

**ไม่ทำ (ส่งต่อ รพ.สัตว์):** ผ่าตัดใหญ่, ดมยาสลบ, X-ray, admit ค้างคืน, เคสฉุกเฉิน — *ต้องมี MOU ส่งต่อ รพ.สัตว์ 24 ชม. ก่อนเปิดบริการ*

## 3. โมเดลการทำงาน (แบ่งเป็นเฟส — เริ่มเล็ก พิสูจน์ก่อนขยาย)

| เฟส | ทำอะไร | ลงทุน |
|---|---|---|
| **ฐานคลินิก** | แบ่งพื้นที่จากคลินิกที่มีอยู่ (แยกทางเข้าชัดเจน) ทำเป็นคลินิกฐานเพื่อขอใบอนุญาต | renovate ~20,000–30,000฿ |
| **Validation** | จัด "vet day" ตามคอนโด/นิติ (นัดล่วงหน้าเป็นรอบ) วัดว่ามีคนใช้จริงไหม | รวมทั้งหมด ≤100,000฿ |
| **Scale** | ผ่านเกณฑ์แล้วค่อยเพิ่ม สัตวแพทย์ 1 + รถ 1 → ขยายทีละคัน | ตัดสินด้วยตัวเลขจริง |

**หลักการ:** ไม่ลงทุนก้อนใหญ่ก่อนพิสูจน์ว่ามี demand จริง — รถ/ทีมประจำมาทีหลัง

## 4. เงินลงทุน (ประมาณการ — ต้อง validate ร่วมกัน)

**เฟส Validation (ที่อนุมัติทำตอนนี้): ไม่เกิน 100,000฿**
- Renovate คลินิกฐาน 20,000–30,000฿
- อุปกรณ์ชุดเริ่มต้น (kit พกพา) 15,000–30,000฿
- ค่าจัด vet day + การตลาด + สำรอง ส่วนที่เหลือ
- **ยังไม่ซื้อรถ / ยังไม่จ้างหมอประจำ** — ใช้รถเหมาเที่ยว + สัตวแพทย์แบบแบ่งรายได้ (rev-share) ต่อ event

**เฟส Scale (เฉพาะเมื่อผ่านเกณฑ์):**
- รถ: เริ่มจาก**เช่า**ก่อน (downside จำกัด) ค่อยซื้อเมื่อ demand นิ่ง — *ยังไม่ตัดสินตอนนี้*
- อุปกรณ์เต็มชุด 40,000–70,000฿
- สัตวแพทย์ประจำ (เมื่อ order คุ้มค่ากว่า part-time)

## 5. Unit Economics เบื้องต้น (สมมติฐาน — ต้องพิสูจน์ด้วย event จริง)

- ราคาต่อเคส (premium ถึงหน้าบ้าน): ~800–1,500฿ *(ต้อง validate willingness-to-pay)*
- เคสต่อ event (โมเดลรอบคอนโด): เป้า 10–25 เคส/รอบ
- ต้นทุนผันแปร/เคส: ~250–430฿ (ยา/วัคซีน/เดินทาง/วัสดุ)
- **จุดคุ้มทุนขึ้นกับค่าตัวสัตวแพทย์ + ค่ารถ** — โมเดล rev-share ช่วงแรกทำให้ไม่มี fixed cost ก้อนใหญ่

## 6. เกณฑ์วัดผล (Gate) — ต้องผ่านก่อนลงทุนขยาย

จาก vet day นำร่อง 3–4 โครงการ ภายใน ~90 วัน:
- ✅ ≥25 เคสจ่ายเงิน ต่อ event ที่ราคาเฉลี่ย ≥800฿
- ✅ กำไรต่อ event เป็นบวก (หลังจ่ายค่าสัตวแพทย์ rev-share)
- ✅ ≥30% ของลูกค้าซื้อแพ็กเกจต่อเนื่อง/นัดครั้งถัดไป
- ✅ นิติ ≥2 แห่ง ตกลงเปิดพื้นที่รอบประจำ

**ไม่ผ่าน = หยุด ขาดทุนสูงสุดจำกัดที่ ~100,000฿** (ไม่จมทุนก้อนใหญ่)

## 7. ข้อเสนอความร่วมมือ (Partnership) — จุดที่อยากคุย

ธุรกิจนี้**คอขวดคือสัตวแพทย์** (ต้องมีใบประกอบวิชาชีพเป็นผู้ดำเนินการสถานพยาบาลสัตว์ตามกฎหมาย และต้องอยู่ปฏิบัติหน้าที่จริง)

**สิ่งที่แต่ละฝ่ายนำมา:**
| ฝ่ายเจ้าของธุรกิจ | ฝ่ายสัตวแพทย์ (หุ้นส่วน) |
|---|---|
| เงินลงทุนตั้งต้น + คลินิกฐาน | ใบประกอบวิชาชีพ + เป็นผู้ดำเนินการ/ผู้ขอใบอนุญาต |
| Connection แสนสิริ/ออริจิน + ช่องทางการตลาด | ความเชี่ยวชาญการรักษา + เลือก spec อุปกรณ์/ยา |
| ทีมบริหาร/ปฏิบัติการ (มีทีมแยกดูแล) | อยู่ปฏิบัติหน้าที่ตามเวลา |

**โครงสร้างที่อยากหารือ:** เริ่มจาก **rev-share ต่อ event** ช่วง validation (ความเสี่ยงต่ำทั้งสองฝ่าย) → ถ้าไปได้ดี ปรับเป็น **หุ้นส่วนถือ equity** (ให้สัตวแพทย์มีส่วนได้เสียระยะยาว ไม่ใช่แค่ลูกจ้าง — ลดความเสี่ยง "หมอลาออกแล้วธุรกิจหยุด")

*ตัวเลข % rev-share / สัดส่วน equity = เปิดคุยกัน*

## 8. สิ่งที่ต้องทำ/ตัดสินใจร่วมกันก่อนเริ่ม

1. **ยืนยันข้อกฎหมายกับกรมปศุสัตว์/สัตวแพทยสภา** — เงื่อนไขคลินิกเคลื่อนที่ + การแบ่งพื้นที่จากคลินิกเดิม (ผู้ที่มีใบประกอบช่วยประสานได้ดีกว่า)
2. ตกลงบทบาท + โครงสร้างผลตอบแทน (rev-share → equity)
3. สัตวแพทย์ช่วยเลือก spec อุปกรณ์ + ยา/วัคซีน (หลายชิ้นอาจมี supplier ที่ถูกกว่า)
4. ตกลง protocol ส่งต่อเคสหนัก + รพ.สัตว์คู่สัญญา
5. วางตาราง vet day นำร่องกับนิติชุดแรก

## 9. ความเสี่ยงที่รับรู้ร่วมกัน (พูดตรง)

- Demand ยังไม่พิสูจน์ — จึงเริ่มเล็ก งบจำกัด 100k
- Connection แสนสิริ/ออริจิน = ช่วยเปิดประตู แต่ไม่ผูกขาด (นิติเปลี่ยนคนได้)
- ข้อกฎหมายบริการนอกสถานที่ยังไม่ชัด 100% — ต้อง verify
- ต้องมีระบบส่งต่อเคสหนักที่ดี (ชื่อเสียงเสียได้จากเคสเดียว)
