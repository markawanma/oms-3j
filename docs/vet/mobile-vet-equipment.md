# Mobile Vet — รายการอุปกรณ์พกพา (kit ใส่รถ/vet day)

> เรียบเรียงจากมาตรฐานวิชาชีพ (17 ก.ค. 2026) — ⚠️ **ราคาทั้งหมดเป็นค่าประมาณ ต้องเช็คราคาจริงกับร้านอุปกรณ์สัตวแพทย์** (web search ล่มตอนค้น ยังไม่ได้ verify ราคาออนไลน์)
> Scope: วัคซีน + ตรวจสุขภาพ + รักษาเบื้องต้น onsite — ไม่ผ่าตัดใหญ่/ดมยา/X-ray/ค้างคืน (เคสหนักส่งต่อ รพ.สัตว์)
> ⚠️ **สัตวแพทย์ผู้ดำเนินการต้องเป็นคนเลือก spec + จัดหายา/วัคซีน/test kit เอง** (เวชภัณฑ์ควบคุมต้องสั่งโดยสัตวแพทย์ตามกฎหมาย) — ตารางนี้เป็นไกด์เจ้าของไว้คุยกับหมอ ไม่ใช่ตัดสินแทนหมอ

## สรุป 2 ชุดงบ (เฉพาะอุปกรณ์ ไม่รวมยา/วัคซีนที่หมอจัดหา)

### (ก) ชุดเริ่มต้น "just-enough" — เปิดบริการวัคซีน + ตรวจสุขภาพได้
เครื่องมือตรวจพื้นฐาน + cold chain + สิ้นเปลืองล็อตแรก + ควบคุมสัตว์ + ของเสีย + โต๊ะพับ + เอกสาร
**ประมาณ 15,000–30,000 บาท** (ตรงกับกรอบ mobile kit ≤15–30k ที่ CFO วางไว้ ถ้าคุมของ optional)
- ตัดงบได้ถ้า: หมอมี stethoscope/otoscope ของตัวเอง, ใช้ cooler แบบ ice pack ก่อน

### (ข) ชุดเต็มขึ้น — ทำได้หลากหลาย (glucometer, กล้องจุลทรรศน์, test เยอะ)
**ประมาณ 40,000–70,000 บาท**
- เพิ่มเมื่อ demand พิสูจน์แล้ว ไม่ใช่ซื้อตั้งแต่วันแรก

## รายการที่ "สัตวแพทย์ต้องเลือก/จัดหาเอง" (ห้ามเจ้าของสั่งแทน)
- **ยา + วัคซีนทั้งหมด** (เวชภัณฑ์ควบคุม สั่งโดยสัตวแพทย์ตามกฎหมาย)
- ชนิด/ยี่ห้อ rapid test kit
- ยาถ่ายพยาธิ / ยาป้องกันเห็บหมัด / ยาฉีด
- spec เครื่องมือเฉพาะทางที่หมอถนัด (stethoscope, otoscope)

## ⚠️ หมายเหตุก่อนซื้อ
1. **เริ่มจากชุด (ก) เท่านั้น** — validation ยังไม่พิสูจน์ demand (ตามมติบอร์ด/CFO)
2. ราคาทุกช่องต้อง**เช็คจริง**กับร้านอุปกรณ์สัตวแพทย์ (เช่น ร้านแถวเกษตร/มหาวิทยาลัยสัตวแพทย์, ตัวแทนขายเวชภัณฑ์สัตว์) — ตัวเลขนี้เป็นกรอบคร่าวๆ
3. ให้หมอ part-time ที่จะเป็นผู้ดำเนินการ **review รายการนี้ก่อนซื้อ** — หลายชิ้นหมอมีอยู่แล้ว/มี supplier ประจำที่ถูกกว่า
