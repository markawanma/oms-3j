## Story ที่ข้อมูลบอก (เจ้าของยืนยันแล้วว่าต้นปีขายดีจริง)

1. **ต้นปีบูมหนักผ่าน LINE มูลค่าสูง** — ม.ค.–ก.พ. LINE ~97% AOV ฿11k–17k (ตรุษจีน 2026 + ขายชิ้นใหญ่/ค่าสูง)
2. **AOV ร่วงต่อเนื่อง ฿17,106 → ฿715** ขณะที่ **TikTok live เข้ามาแทน** (0% → ~45% ของยอด)
3. **จำนวนออเดอร์เพิ่ม (713 → 1,364) แต่ยอดเงินลด** — เปลี่ยนจาก "LINE ขายก้อนใหญ่" เป็น "TikTok ขายเยอะชิ้นเล็ก (เงินตามกรัม)"
4. → เป็น **business shift ชัดเจน**: high-value/LINE (ต้นปี) → high-volume/TikTok (กลางปี)

## นัยต่อกลยุทธ์ (ต่อ flywheel เดิม)
- ต้นปี LINE ทำเงินมหาศาล — **ลูกค้า LINE คือขุมทรัพย์จริง** (ยืนยัน seed audience ทองคำ)
- TikTok เพิ่ม "จำนวน" แต่ AOV ต่ำมาก → ต้องวัดว่า **TikTok หาลูกค้าใหม่แล้วดันขึ้น LINE ได้ไหม** (cohort) ไม่งั้นคือแลกยอดสูงเป็นยอดต่ำ
- ⚠️ **ต้องแก้การกรอกต้นทุนด่วน** — ไม่งั้นดูไม่ออกว่ากำไรจริงต่อช่องทางเป็นบวกหรือลบ
