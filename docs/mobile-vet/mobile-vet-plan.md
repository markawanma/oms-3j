# Mobile Vet Clinic — แผนเริ่มต้น + มติบอร์ด + ข้อกฎหมาย

> อัปเดต: 17 ก.ค. 2026 · สถานะ: อนุมัติแบบมีเงื่อนไข (Conditional Go) · เจ้าภาพ: ทีมแยกของเจ้าของ

## มติบอร์ด C-level (17 ก.ค. 2026)

- **"ไม่เปิดธุรกิจเต็มรูป — ซื้อ option เพื่อพิสูจน์ก่อน"** งบรวม validation **≤100,000฿**
- โมเดลเต็ม (รถดัดแปลง+ทีมประจำ) ต้องใช้ 1.5-3.3M + fixed 100-165k/เดือน, break-even 120-250 เคส/เดือน, payback 3-5 ปี → **ไม่อนุมัติ** จนกว่าผ่าน gate
- เส้นทางที่อนุมัติ: คลินิกฐานต้นทุนต่ำ (แบ่งพื้นที่ชุนหลี ~20-30k) → ใบอนุญาต → หมอ part-time/rev-share → vet day ตามนิติแสนสิริ/ออริจิน → ผ่าน gate ค่อย หมอ 1 รถ 1 → scale
- **Gate ผ่าน (วัดจาก event จริง):** ≥25 เคสจ่ายเงิน/event เฉลี่ย ≥800฿ · margin/event บวก · ≥30% ซื้อแพ็กเกจต่อ · นิติ ≥2 แห่ง commit รอบประจำ
- **ห้าม:** จ้างหมอ fixed salary ก่อน demand พิสูจน์ · ซื้อ/ผ่อนรถก่อนผ่าน gate · แย่งเวลาเจ้าของจาก Golden Energy
- ลำดับ portfolio เครือ: 3J → Golden Energy → ชุนหลี → **Mobile Vet (ท้ายแถว, มีทีมแยกรัน)**
- P&L แยกเด็ดขาดจากธุรกิจอื่น (คำสั่ง CFO)

## ข้อกฎหมาย (ค้นโดย docs-researcher, 17 ก.ค. 2026 — ยืนยันขั้นสุดท้ายกับปศุสัตว์พื้นที่ก่อนลงมือ)

### ใบอนุญาตสถานพยาบาลสัตว์ ประเภทคลินิก (ไม่มีพักค้างคืน)
- พื้นที่ขั้นต่ำ **20 ตร.ม.** ส่วนแคบสุด ≥3 ม.
- ต้องมี: ห้องตรวจ 1 (เตียงตรวจ) · อ่างล้างมือ+สบู่+ผ้าเช็ดมือใช้ครั้งเดียว · ห้องน้ำถูกสุขลักษณะ · ป้ายชื่อตามแบบกรมปศุสัตว์ · เครื่องมือตรวจ/ทำลายเชื้อ · ตู้เวชภัณฑ์มิดชิด · ถังมูลฝอยแยกติดเชื้อ · ที่เก็บเวชระเบียน
- ค่าธรรมเนียม 600฿ · ใบอายุ 3 ปี · กระบวนการ ~45 วัน (ยื่น→ตรวจสถานที่→ออกใบ)
- เอกสาร: บัตร ปชช., ทะเบียนบ้าน, ใบอนุญาตสัตวแพทย์, ใบรับรองแพทย์ (≤30 วัน), รูป 4×5, สิทธิในอาคาร, (นิติบุคคล: หนังสือรับรอง ≤6 เดือน)
- อ้างอิง: พ.ร.บ.สถานพยาบาลสัตว์ 2533 (แก้ไข 2557) + ประกาศมาตรฐานสถานพยาบาลสัตว์ (ราชกิจจาฯ 23 ธ.ค. 2558) + info.go.th

### ผู้ดำเนินการ
- ต้องเป็นสัตวแพทย์จดทะเบียน และ**ปฏิบัติหน้าที่จริงตามเวลาเปิดทำการ** (ห้ามให้ชื่อเฉยๆ — เสี่ยงเพิกถอน)
- แนวทางที่เลือก: **หมอ part-time คนเดียวกับผู้ขอจด** + ตารางเวลาปฏิบัติหน้าที่ชัดเจน
- ต้องส่งรายงานสถิติการรักษารายเดือนต่อกรมปศุสัตว์

### การอยู่ร่วมอาคารกับคลินิกแพทย์แผนจีน (ชุนหลี)
- พ.ร.บ.สถานพยาบาลสัตว์: ไม่มีข้อห้ามชัดเจน
- ⚠️ พ.ร.บ.สถานพยาบาล 2541 (ฝั่งคน): **ห้ามสัตว์เข้าพื้นที่บริการผู้ป่วย** → ต้องแยกส่วนชัดเจน
- **แผนของเจ้าของ: แยกทางเข้าเป็นสัดส่วนชัดเจน** ✅ ตอบโจทย์ทิศทางถูกต้อง — ยืนยันรายละเอียด (ผนัง/ป้าย/สุขาภิบาล) กับ 2 หน่วยงานก่อน renovate
- เช็คด้วยว่าไม่กระทบใบอนุญาตเดิมของชุนหลี

### บริการนอกสถานที่ (mobile)
- ออกตรวจนอกสถานที่จาก "คลินิกฐานที่มีใบอนุญาต" ทำได้ (ตรงกับโมเดลที่วาง)
- ขอบเขตหัตถการนอกสถานที่ยังไม่มีกฎชัด → สอบถามกรมปศุสัตว์ + สัตวแพทยสภา
- อ้างอิงเพิ่ม: ประกาศสัตวแพทยสภา 51/2564 (telemedicine)

## ✅ Checklist สิ่งที่ต้องทำตอนแรก (เรียงลำดับ)

1. [ ] **โทรยืนยัน spec ก่อนกั้นห้อง** — ปศุสัตว์พื้นที่/กรมปศุสัตว์ 02-653-4444 ต่อ 4191-2: (ก) เงื่อนไขแยกส่วนจากคลินิกคน (ข) ขอบเขตหัตถการนอกสถานที่
2. [ ] เช็คฝั่งผู้อนุญาตคลินิกชุนหลี ว่าการแบ่งพื้นที่ไม่กระทบใบเดิม
3. [ ] ตกลงบทบาทสัตวแพทย์เป็นลายลักษณ์: ผู้ดำเนินการ = หมอ part-time คนเดียวกัน + ตารางปฏิบัติหน้าที่ + เรต rev-share
4. [ ] Renovate ตาม spec (งบ ~20-30k: กั้นห้อง แยกทางเข้า ป้าย อ่างล้างมือ เตียงตรวจ ตู้เวชภัณฑ์)
5. [ ] ยื่นขอใบอนุญาต (เผื่อเวลา ~45 วัน)
6. [ ] ระหว่างรอ: MOU ส่งต่อ รพ.สัตว์ 24 ชม. ≥2 แห่ง · ขอข้อมูลสัตว์เลี้ยง/ดีลรอบ vet day กับนิติแสนสิริ/ออริจิน ≥3 ตึก · ออกแบบแพ็กเกจ "annual pet wellness" + ราคา
7. [ ] ได้ใบ → จัด vet day นำร่อง 3-4 โครงการ → วัดตาม gate บอร์ด
8. [ ] ผ่าน gate → หมอ 1 รถ 1 (part-time → ประจำเมื่อ order คุ้ม) → scale ทีละขั้น
