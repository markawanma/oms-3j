# 01 — 3J Brand DNA (ตัวตนที่ส่งผลต่อดีไซน์)

> **ใช้ตอนไหน**: อ่านก่อนคิดธีม collection ใหม่ทุกครั้ง — ทั้งฝั่ง ChatGPT (คิด concept/สร้างภาพ) และ Claude (ทำ CAD)
> อ้างอิงเต็มจาก [`docs/ops/3j-brand-brief-for-ai.md`](../ops/3j-brand-brief-for-ai.md) — ไฟล์นี้เจาะเฉพาะส่วนที่กระทบการตัดสินใจดีไซน์/CAD

---

## แบรนด์นี้คือใคร (สรุปสำหรับดีไซน์)

3J Jewelry = **เครื่องประดับเงิน 92.5 ที่ใส่ได้จริงทุกวัน** ไม่ใช่ของโชว์ในตู้ ขายผ่านไลฟ์ Shopee/TikTok เป็นหลัก ลูกค้าตัดสินใจซื้อจากภาพ/ไลฟ์ ราคาต้องจับต้องได้

**นี่คือข้อจำกัด (constraint) ที่ต้องแปลงเป็นกฎดีไซน์ ไม่ใช่แค่สโลแกน:**

| ตัวตนแบรนด์ | → ผลต่อดีไซน์/CAD |
|---|---|
| "ใส่ได้จริงทุกวัน" ไม่ใช่ของโชว์ | ห้าม prong/bezel/ขอบบางเกินจนใส่แล้วเกี่ยว/บาด/หักง่าย — comfort-fit ต้องมาก่อนความจัดจ้านของทรง |
| "ราคาจับต้องได้" | **น้ำหนักเงินคุมต้นทุนตรงๆ** (เงินขายเป็นกรัม) — ดีไซน์ใหญ่/หนาเกินงบ = ต้องพูดตรงๆ ว่าเกินงบ ไม่ over-design เอาใจความสวยอย่างเดียว |
| "เงินแท้ 92.5 ไม่แพ้ ไม่ดำง่าย" | ต้องระบุ finish ชัด (polish/matte/oxidized/rhodium) เพราะกระทบทั้งลุคและความทนทานจริง |
| "ขายไลฟ์ Shopee/TikTok" — ตัดสินใจจากภาพ/จอ | ชิ้นงานต้อง**เด่นในจอมือถือ** — เส้นสายต้องอ่านออกในภาพขนาดเล็ก, แสงสะท้อนต้องช่วยขายของ (polish surface ที่จับแสงดี) |
| "มินิมอล สะอาด พรีเมียมแต่เข้าถึงง่าย" | หลีกเลี่ยง detail รกเกินจำเป็น, เส้นโค้งต่อเนื่องมากกว่ามุมคมจัด (ดูรายละเอียดใน `02_3J_Design_Language.md`) |
| กลุ่มลูกค้า: ผู้หญิงไทยใส่ทำงาน/ทุกวัน | ขนาด/น้ำหนักต้องเหมาะมือ/หูคนไทยทั่วไป ไม่ oversized เกินจำเป็น |

## โทนภาพ (ผลต่อ reference image + material call-out)

- **สีแบรนด์**: ขาว (background) · แดง #A2191D (accent — ใช้เป็นสีพลอย/แพ็กเกจ ไม่ใช่สีเงิน) · เทา #343434/#F0F0F0
- ตัวเครื่องประดับ = **เงิน 92.5 เท่านั้น** เว้นแต่โจทย์ระบุอื่น (ChatGPT ชอบเผลอเปลี่ยนเป็นทอง — ต้องยืนยันคำว่า "silver 925" ทุกครั้งตอนสั่งสร้างภาพ)
- ภาพสินค้า: พื้นหลังสะอาด แสงนุ่ม โฟกัสคม โชว์รายละเอียดเงิน — ไม่ใช่แค่ requirement ถ่ายภาพ แต่หมายความว่า**ดีไซน์ต้องมีพื้นผิว/เส้นที่จับแสงสวยตอนถ่าย** ตั้งแต่ขั้นคิดทรง

## Guardrails ที่ห้ามข้ามตอนออกแบบ

- ห้ามเคลมสรรพคุณเกินจริงในชื่อ/คอนเซปต์ชิ้นงาน (เช่น "เสริมดวง" แบบไม่มีมูล)
- ห้ามเปลี่ยนเงินเป็นทอง/โลหะอื่นโดยไม่ได้สั่ง
- ชื่อแบรนด์ในเอกสาร = "3J Jewelry" เสมอ (ไม่ใช่ "3J Silver")
- ราคา/งบที่ยังไม่ยืนยัน ห้ามพูดเป็นคำมั่นในสเปก

## สรุป 1 บรรทัดสำหรับ AI ทุกตัวในระบบนี้

> ดีไซน์ทุกชิ้นของ 3J ต้อง **สวยพอขายไลฟ์ได้ + ผลิตได้จริงด้วยเงิน 925 + ราคาคุมได้จากน้ำหนักเงิน** — ขาดข้อใดข้อหนึ่งไม่ใช่งาน 3J
