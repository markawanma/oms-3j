# 00_Design_Intent.md — ย้ายแล้ว (DEPRECATED — อย่าใช้ไฟล์นี้ต่อ)

> ไฟล์นี้ถูกแยกออกเป็น 2 ชั้นตามโครงสร้างใหม่ของระบบ (brand-level vs collection-level):
>
> - หลัก **brand-level** (สากลทุก collection: วัสดุ, feeling, บทบาท AI, visual priority, มาตรฐานผลิต) → ย้ายไปอยู่ที่ [`00_Brand_Principles.md`](./00_Brand_Principles.md)
> - หลัก **เฉพาะ motif "folded satin"** (test คำถาม, NEVER-DO twist/rope/spiral, กฎ split-near-head) → ย้ายไปอยู่ที่ [`collections/satin-flow/design-intent.md`](./collections/satin-flow/design-intent.md) เพราะเป็น DNA ของ **collection Satin Flow เท่านั้น** ไม่ใช่ทุก collection ของ 3J

**ทุกลิงก์ในระบบที่เคยอ้างไฟล์นี้ได้อัปเดตไปอ้าง 2 ไฟล์ข้างต้นแล้ว** ถ้าเจอลิงก์เก่าที่ยังชี้มาไฟล์นี้ ให้แก้เป็น `00_Brand_Principles.md` (+ เพิ่ม collection design-intent ถ้าเกี่ยวข้อง)

ไฟล์นี้เก็บไว้เป็น stub กันลิงก์เก่าพังเท่านั้น ไม่ใช่แหล่งอ้างอิงอีกต่อไป
