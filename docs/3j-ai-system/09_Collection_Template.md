## 5. ขั้นตอนถัดไป

1. กรอกส่วน 1–3 ให้ครบก่อนเริ่มออกแบบชิ้นแรก
2. เข้า pipeline ตาม `README.md` (ChatGPT reference image → analysis → Claude CAD spec)
3. ใช้ `04_Claude_Master_Prompt.md` สั่งงานทีละชิ้น อ้างธีม collection นี้ในทุก prompt เพื่อความสม่ำเสมอ
4. กรอกตารางสเปกกลาง (ข้อ 4) ทุกครั้งที่ชิ้นงานเสร็จ — ใช้เทียบ consistency ระหว่างชิ้นในเซ็ตเดียวกัน
