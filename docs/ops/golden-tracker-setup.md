# คู่มือติดตั้ง Golden Energy Tracker (Google Sheets)

Template หลังบ้านตามมติ COO — **Google Sheet 2 ใบ cost 0 บาท** สำหรับธุรกิจ 1-2 ดีล/เดือน

## 1. Import เข้า Google Sheets (ครั้งเดียว ~5 นาที)

1. เปิด [sheets.google.com](https://sheets.google.com) → สร้าง spreadsheet ใหม่ ตั้งชื่อ **"Golden Energy Tracker"**
2. **File → Import → Upload** → เลือก `golden-lead-tracker.csv`
   - Import location: **Insert new sheet(s)**
   - ✅ ติ๊ก "Convert text to numbers, dates, and formulas" (ค่า default) — สูตร ⚠ ติดตาม จะทำงานทันที
3. ทำซ้ำกับ `golden-project-tracker.csv`
4. เปลี่ยนชื่อ tab เป็น **Lead Tracker** และ **Project Tracker**
5. แถวแรกที่เป็นตัวอย่าง (มีคำว่า "ตัวอย่าง") ดูรูปแบบแล้วลบได้เลย
6. ลากสูตรคอลัมน์ "⚠ ติดตาม" (Lead) และ "เช็คยอดงวด" (Project) ลงล่างสัก 100 แถว

## 2. ใส่ Dropdown (~2 นาที — สำคัญ ห้ามพิมพ์สถานะเอง)

เลือกคอลัมน์ → เมนู **Insert → Dropdown** แล้ววางค่าตามนี้:

**Lead Tracker**
- คอลัมน์ B (ช่องทาง): `FB Form, FB Inbox, LINE, โทร, แนะนำต่อ, อื่นๆ`
- คอลัมน์ G (ประเภท): `บ้าน, ทาวน์โฮม, อาคารพาณิชย์, โรงงาน/กิจการ, อื่นๆ`
- คอลัมน์ J (สถานะ): `New, ติดต่อแล้ว, นัด Survey, Survey แล้ว, เสนอราคา, ต่อรอง, ปิด-Won, ปิด-Lost, เงียบ`
  ⚠ สะกด `ปิด-Won` / `ปิด-Lost` ตามนี้เป๊ะ — สูตรเตือนเลยนัดอ้างอิงค่านี้

**Project Tracker**
- คอลัมน์ G, I, K (สถานะงวด): `ยังไม่ถึงกำหนด, ถึงกำหนด-รอจ่าย, จ่ายแล้ว`
- คอลัมน์ M (สถานะขออนุญาต): `ยังไม่ยื่น, ยื่นแล้ว-รอผล, อนุมัติแล้ว, ติดปัญหา`

## 3. กติกาใช้งาน (ตามมติ COO — Admiral Ackbar)

- **ทุก lead จากทุกช่องทาง ลง Lead Tracker ใบเดียว** ห้ามจดกระดาษ/แชทแล้วไม่ลง
- **SLA ตอบ lead ภายใน 24 ชม.** (เป้าจริง <2 ชม. ในเวลาทำการ) — เปิด notification FB/LINE เข้ามือถือ
- **คอลัมน์ "วันนัด follow-up ถัดไป" ห้ามว่าง** ตราบใดที่ lead ยังไม่ปิด — lead ตายเพราะไม่มีวันนัดตาม
- **Routine จันทร์/พฤหัส 15 นาที**: เปิด sheet ไล่ทุกแถวที่ขึ้น "⚠ เลยนัดตาม" แล้วตามให้หมด
- **คนกรอก: เจ้าของคนเดียว** — หัวหน้าช่างรายงานผล survey ทาง LINE group แล้วเจ้าของจด
- ปิดดีลได้ (ปิด-Won) → ย้ายไปเปิดแถวใน **Project Tracker** ทันที พร้อมกรอกงวดเงิน + เริ่ม checklist ขออนุญาต
- **ห้ามสัญญาวันติดตั้ง/วันขนานไฟกับลูกค้า ก่อนคอลัมน์ "สถานะขออนุญาต" = อนุมัติแล้ว**
- วันส่งมอบ = กรอกวันหมดประกันทั้ง 3 ช่องทันที + ตั้งนัด maintenance ปีถัดไป

## 4. Trigger อัปเกรดเป็นระบบจริง (อย่าอัปเกรดก่อนเจออาการ)

- Lead >30-40 ราย/เดือน หรือมีคนขายเพิ่ม → ค่อยดู CRM (HubSpot free)
- งานติดตั้งซ้อน >3-4 โปรเจกต์ → ค่อยดู project tool
- ตอบ lead เกิน SLA ซ้ำๆ เพราะ sheet ตามไม่ทัน → ส่ง requirement ให้ Tech Lead (มี OMS + ทีม dev รออยู่แล้ว)
