## 0. สมมติฐาน/ข้อจำกัดที่ต้องระบุก่อน (ไม่เดา)

- **ไม่รู้ search volume จริง** — keyword ด้านล่างเป็นภาษาที่คนไทยค้นจริงจาก pattern ตลาดทอง/โลหะมีค่า แต่ตัวเลข volume/difficulty **เป็นการเดาเชิงคุณภาพเท่านั้น** → ต้องส่งให้ `docs-researcher` validate ด้วย Google Keyword Planner / Ahrefs / Search Console ก่อนจัด production queue จริง
- **ไม่รู้โครงสร้าง URL ปัจจุบันของ Wix บนหน้า `/silver-bar` และ `/silver-price`** (เนื้อหาที่มีอยู่, H-tag เดิม, meta เดิม) — ต้อง audit หน้าเดิมก่อนเขียนทับ ไม่ใช่เขียนจากศูนย์ทึกทักว่าหน้าว่าง
- **ไม่รู้ Wix Blog capability จริง** (custom URL slug ได้ระดับไหน, รองรับ FAQ schema markup ยังไง) — ส่งต่อ architect ยืนยันก่อน implement (ดู §7)
- **ภาษี/กฎหมายการซื้อขายโลหะมีค่า** — ไม่มีข้อมูลนี้ในเอกสารที่อ้างอิงได้ ห้ามเขียน content เดาเรื่องภาษี/กฎหมาย ถ้าจะทำหัวข้อนี้ต้องให้เจ้าของ/ที่ปรึกษากฎหมายยืนยันข้อเท็จจริงก่อน (มาร์คเป็น "รอข้อมูล" ใน §3)
- currency/multi-currency ของ Wix Stores V1 ยังเป็น open question (ข้อ 12 ใน positioning doc) — ไม่กระทบ content เชิง educational แต่กระทบหน้า transactional/pricing → flag ใน §7

- **Pillar page**: `/silver-bar` (URL เดิม, ใช้ต่อ — ไม่สร้างใหม่) เป็น hub รวม trust signal ทั้งหมด + ลิงก์ออกไปทุก spoke + ลิงก์เข้า `/silver-price`
- **`/silver-price`** (มีอยู่แล้ว): เปลี่ยนบทบาทเป็น "tool/utility page" ที่ pillar ลิงก์เข้าไปตอบ objection #3 (ราคาอิงอะไร) — ไม่ต้องแข่งเขียนบทความซ้ำ ให้โฟกัสแสดงราคา realtime + คำอธิบายสั้นว่าราคาคำนวณจากอะไร

- **Internal linking**:
  - ทุก spoke → ลิงก์กลับ pillar (`/silver-bar`) ด้วย anchor text ที่มี keyword หลัก
  - pillar → ลิงก์ออกทุก spoke ใน H2 section ที่เกี่ยวข้อง (ไม่ทำเป็น list ลิงก์ท้ายหน้าเฉยๆ — ฝังในเนื้อหาแต่ละ objection)

  - `/silver-price` เป็นปลายทางลิงก์จากแทบทุกหน้า (CTA "เช็คราคาวันนี้")

## 4. On-page SEO — Pillar Page `/silver-bar`

> ร่างจริง ไม่ใช่ placeholder — copywriter ปรับ tone ต่อได้ แต่โครงสร้าง H-tag/keyword placement ห้ามเปลี่ยนโดยไม่เช็คกับ SEO

> ⚠️ **แก้ fact (2026-08-26):** ไฟล์นี้เคยเขียนว่า "ตรวจสอบแท้ได้ทุกแท่งด้วย NFC" ซึ่ง **ผิด** —
> NFC + serial มีเฉพาะแท่ง **1 กิโลกรัม** เท่านั้น แท่ง 0.5/1/3/5/10 บาท **ไม่มี NFC ไม่มี serial**
> ตรวจสอบด้วยใบรับรอง + โลโก้ประทับ (ซึ่งมีทุกแท่ง) — ตรงกับที่ `silver-bar-copy-batch1.md`
> แก้ไว้แล้วตั้งแต่ 2026-08-06 แต่ไฟล์นี้ตกหล่น ถ้าเอา meta เดิมขึ้นเว็บ ลูกค้าซื้อแท่ง 1 บาท
> แล้วหา NFC ไม่เจอ = เสียความเชื่อถือหนักกว่าไม่พูดถึงเลย

**Title tag** (≤60 char):
> เงินแท่ง 999 แท้ ตรวจสอบได้ | ซื้อตรงโรงงาน 3J Jewelry

**Meta description** (≤160 char):
> ซื้อเงินแท่ง 999 จากโรงงานผู้ผลิตโดยตรง ราคาโรงงาน ไม่ผ่านคนกลาง ทุกแท่งมีใบรับรอง+โลโก้ประทับ แท่ง 1 กก. ตรวจเพิ่มด้วย NFC รับซื้อคืน มีหน้าร้านจริง 30+ ปี

**H1:**
> เงินแท่ง 999 จากโรงงานผู้ผลิตโดยตรง — ตรวจสอบแหล่งที่มาได้ทุกแท่ง

**H2 outline:**
1. เงินแท่ง 3J คืออะไร (ผลิตเองตั้งแต่เม็ดเงิน — ย้ำ trust anchor "โรงงานผลิตเอง 30+ ปี")
2. ตรวจสอบแท้ได้ทุกแท่งด้วย NFC — สแกนมือถือดูรูปแท่งจริงของคุณ *(ลิงก์ไป spoke #2)*
3. ขนาดเงินแท่งที่มีให้เลือก (0.5 / 1 / 3 / 5 / 10 บาท และ 1 kg) *(ลิงก์ไป spoke #7)*

## 5. AEO / AI-search angle

**เหตุผลที่ pillar นี้เหมาะกับ AEO เป็นพิเศษ:** คำถามแบบ objection-based (แท้ไหม/ขายคืนได้ไหม) เป็นรูปแบบที่ AI answer engine (Google AI Overview, ChatGPT search, Perplexity) ชอบดึงไปตอบตรงๆ ถ้าโครงสร้างเป็น Q&A ชัด

**FAQ schema — คำถาม-คำตอบที่ควรฝัง (`FAQPage` schema):**
- เงินแท่ง 3J เป็นเงินแท้ 999 หรือไม่? → ใช่ ทุกแท่งมีใบรับรอง + สแกน NFC ดูรูปแท่งจริงได้
- ซื้อเงินแท่งแล้วขายคืนได้ไหม? → ได้ ทั้งหน้าร้านและออนไลน์ ราคารับซื้อคืน = ราคาอ้างอิง หัก 30 บาทต่อน้ำหนัก 1 บาท
- เงินแท่ง 3J มีขนาดอะไรบ้าง? → 0.5, 1, 3, 5, 10 บาท และ 1 กิโลกรัม
- ราคาเงินแท่งอิงจากอะไร? → อิงราคาอ้างอิงเงินไทย ปรับตามราคาตลาดโลก realtime
- ตรวจสอบเงินแท่งแท้ยังไง? → แตะมือถือที่ NFC tag บนแท่ง จะเปิดหน้าเว็บแสดงรูปแท่งจริงที่ถ่ายไว้ตอนผลิต
- ซื้อเงินแท่งได้ที่ไหนบ้าง? → LINE, Shopee, TikTok, หน้าร้าน 3J Jewelry

**Entity/structured data ที่ควรมี:**
- `Organization` schema บนหน้าแรก/pillar — ผูก "3J Jewelry", ที่อยู่, เบอร์โทร, 30+ ปี (E-E-A-T signal ให้ Google เข้าใจว่าเป็นผู้ผลิตจริง ไม่ใช่ reseller)
- `Product` schema ต่อขนาดเงินแท่ง (name, size/weight เป็น additionalProperty, ราคาถ้ามี — currency ต้อง THB ตาม positioning)
- `BreadcrumbList` schema ผูก IA hub-and-spoke (`หน้าแรก > เงินแท่ง > [spoke]`)
- พิจารณา `HowTo` schema สำหรับบทความ "วิธีตรวจสอบเงินแท่งแท้ด้วย NFC" (ขั้นตอน 1-2-3 สแกน) — เข้ากับ format ที่ AI answer engine ดึงไปสรุปได้ตรง
