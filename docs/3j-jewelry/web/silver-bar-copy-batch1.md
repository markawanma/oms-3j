### H2-1: เงินแท่ง 3J คืออะไร

3J Jewelry ผลิตเงินแท่งบริสุทธิ์ 999 (99.9%) เอง ตั้งแต่ขั้นตอนหลอมเนื้อเงินไปจนถึงขึ้นรูปเป็นแท่ง โดยโรงงานของเราเอง — ไม่ใช่ผู้ค้าที่ซื้อแท่งสำเร็จรูปมาขายต่อ

เราอยู่ในธุรกิจเงินมากว่า 30 ปี เริ่มจากงานผลิตเครื่องประดับเงินแท้ 925 ให้แบรนด์ทั้งในและต่างประเทศ ก่อนขยายมาสู่การผลิตและจำหน่ายเงินแท่งเพื่อการลงทุนโดยตรง กระบวนการผลิตทั้งหมดอยู่ภายใต้การควบคุมของทีมช่างของเราเอง ตั้งแต่การคัดเนื้อเงิน การหลอม การหล่อ ไปจนถึงการตรวจสอบความบริสุทธิ์ก่อนออกจากโรงงาน

การที่เราผลิตเองทุกขั้นตอน หมายความว่าเราสามารถยืนยันแหล่งที่มาของเนื้อเงินได้ตั้งแต่ต้นทาง เงินแท่งทุกแท่งของเราจึงมาพร้อมใบรับรองความบริสุทธิ์และโลโก้บริษัทประทับบนตัวแท่ง เพื่อให้ตรวจสอบได้ด้วยตัวเอง ไม่ต้องเชื่อคำพูดเราฝ่ายเดียว ส่วนเงินแท่งขนาด 1 กิโลกรัม เรามีระบบตรวจสอบเพิ่มอีกชั้นด้วย NFC tag ที่ผูกกับแท่งนั้นแท่งเดียวโดยเฉพาะ

### H2-2: ตรวจสอบแท้ได้ทุกแท่ง — ใบรับรอง+โลโก้ทุกขนาด เสริม NFC สำหรับแท่ง 1 กิโลกรัม

เงินแท่งทุกแท่งของ 3J ไม่ว่าขนาดไหน มาพร้อมใบรับรองความบริสุทธิ์และโลโก้บริษัทที่ประทับบนตัวแท่งโดยตรง — ตรวจสอบได้ด้วยตาตั้งแต่แกะกล่อง เทียบโลโก้บนแท่งกับใบรับรองที่มาด้วยกัน

สำหรับเงินแท่งขนาด 1 กิโลกรัม เรามีระบบตรวจสอบเพิ่มอีกชั้นด้วย NFC tag ที่ฝังในตัวแท่ง เพียงแตะมือถือที่มีระบบ NFC ลงบนแท่ง หน้าจอจะเปิดหน้าเว็บที่แสดงรูปถ่ายจริงของแท่งเงินแท่งนั้น — แท่งเดียวกับที่อยู่ในมือคุณ ถ่ายไว้ตั้งแต่ขั้นตอนการผลิต ผูกกับแท่งนั้นแท่งเดียวโดยเฉพาะ ต่างจากใบรับรองที่ยืนยันได้แค่ระดับรุ่น/ล็อต

ระบบ NFC นี้เป็นสิ่งที่ 3J ทำก่อนในตลาดเงินแท่งไทยสำหรับแท่งลงทุนขนาดใหญ่ ส่วนแท่งขนาดเล็ก (0.5–10 บาท) ตรวจสอบด้วยใบรับรองและโลโก้บนแท่งเป็นหลัก — เป็นคำตอบตรงที่สุดสำหรับคำถามที่ลูกค้าถามมากที่สุด: **"เงินแท่งนี้แท้จริงไหม"**

อ่านรายละเอียดขั้นตอนการตรวจสอบทั้งหมด (ใบรับรอง/โลโก้ + NFC สำหรับแท่ง 1 กก.) → *[internal link: anchor text "วิธีตรวจสอบเงินแท่งแท้" → ลิงก์ไป spoke #2 (บทความ NFC ด้านล่างในไฟล์นี้)]*

### H2-1: ทำไม "แท้ไหม" ถึงเป็นคำถามแรกที่ต้องตอบ

เมื่อซื้อโลหะมีค่าจากผู้ขายที่ไม่เคยรู้จักมาก่อน คำถามแรกที่นักลงทุนทุกคนถามคือ "แท้จริงหรือเปล่า" คำถามนี้ยิ่งสำคัญเมื่อซื้อผ่านช่องทางออนไลน์ ที่ไม่ได้เห็นสินค้าจริงก่อนตัดสินใจ

ใบรับรองกระดาษตอบคำถามนี้ได้ระดับหนึ่ง โดยเฉพาะเมื่อใช้ร่วมกับโลโก้บริษัทที่ประทับบนตัวแท่งโดยตรง — เทียบกันได้ทันทีว่าโลโก้บนแท่งตรงกับใบรับรองที่มาด้วยกันหรือไม่ แต่สำหรับแท่งลงทุนขนาดใหญ่อย่าง 1 กิโลกรัม 3J เพิ่มการตรวจสอบอีกชั้นด้วยระบบ NFC ที่ผูกกับตัวแท่งจริงโดยเฉพาะ ปิดช่องว่างที่ใบรับรองแยกออกจากตัวสินค้าได้

---

### H2-2: ตรวจสอบด้วยใบรับรอง + โลโก้บนแท่ง (ใช้ได้ทุกขนาด)

เงินแท่งทุกแท่งของ 3J ไม่ว่าขนาดไหน — 0.5, 1, 3, 5, 10 บาท หรือ 1 กิโลกรัม — มาพร้อมใบรับรองความบริสุทธิ์ 999 และมีโลโก้บริษัทประทับบนตัวแท่งโดยตรงตั้งแต่ขั้นตอนการผลิต

วิธีตรวจสอบ: เทียบโลโก้ที่ประทับบนแท่งกับใบรับรองที่มาด้วยกัน และเก็บใบรับรอง/ใบรับประกันไว้เป็นหลักฐานเวลาขายคืนหรือติดต่อสอบถามกับร้าน นี่คือมาตรฐานการตรวจสอบขั้นพื้นฐานที่ใช้ได้กับเงินแท่ง 3J ทุกแท่ง

### H2-3: NFC บนเงินแท่ง 3J คืออะไร — เฉพาะแท่ง 1 กิโลกรัม

**ระบบ NFC ของ 3J มีเฉพาะเงินแท่งขนาด 1 กิโลกรัมเท่านั้น** แท่งขนาดเล็ก (0.5–10 บาท) ไม่มี NFC tag — ตรวจสอบด้วยใบรับรอง+โลโก้ตามหัวข้อด้านบนแทน

เงินแท่งขนาด 1 กิโลกรัมทุกแท่งฝัง NFC tag ไว้ในตัวแท่งตั้งแต่ขั้นตอนการผลิต NFC tag นี้บันทึกข้อมูลเฉพาะของแท่งเงินแท่งนั้นแท่งเดียว ไม่ใช่ข้อมูลรุ่นหรือล็อตการผลิต

เมื่อสแกน ระบบจะเปิดหน้าเว็บที่แสดงรูปถ่ายจริงของแท่งเงินแท่งนั้น — ถ่ายไว้ในขั้นตอนการผลิตก่อนจัดส่งถึงลูกค้า ทำให้ผู้ซื้อเทียบแท่งที่อยู่ในมือกับรูปที่ระบบแสดงได้โดยตรง

1. เปิดการตั้งค่า NFC บนโทรศัพท์มือถือ (มือถือรุ่นใหม่ส่วนใหญ่มี NFC ในตัว)
2. นำด้านหลังของโทรศัพท์แตะลงบนตำแหน่ง NFC tag บนแท่งเงิน
3. รอสัญญาณแจ้งเตือนจากมือถือ แล้วกดเปิดลิงก์ที่ปรากฏ
4. หน้าเว็บจะแสดงรูปถ่ายจริงของแท่งเงินแท่งนั้น พร้อมข้อมูลยืนยัน

### H2-5: NFC ต่างจากใบรับรองทั่วไปยังไง
