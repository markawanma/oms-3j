## 🔴 ปัญหาที่พบ (เรียงตามความเสียหาย)

### 1. `/shop` ยังโชว์ราคาอยู่ — หน้าที่ตกสำรวจ
อยู่ใน sitemap = Google เก็บไปแล้ว · ยังแสดง `R10101CZ ราคาเริ่มต้นที่ ฿50.00` และ `฿79.50`
**ไม่ได้อยู่ในเมนูนำทาง** จึงหลุดจากการไล่ปิดราคารอบแรก · ไม่มี meta description ด้วย

### 2. หน้าซ้ำ 2 คู่ ที่ถูก index ทั้งคู่
| คู่ | หลักฐาน |
|---|---|
| `/silver-bar` **=** `/silver-bar-test` | เนื้อหาเท่ากันเป๊ะ 2,928 ตัวอักษร · title เดียวกัน · **canonical ชี้ตัวเอง ไม่ชี้หากัน** |
| `/blog-silver-price-determination` **↔** `/สำเนาของ-ราคาเงินถูกกำหนดอย่างไร` | **meta description เหมือนกันคำต่อคำ** · slug "สำเนาของ" = Copy of |
⇒ แย่ง ranking กันเอง และกินโควตา crawl

### 3. 290 หน้าสินค้า = 290 หน้าคุณภาพต่ำ
`description` ว่าง · `sku` ว่าง · ตอนนี้ราคาก็ถูกซ่อน ⇒ หน้าเหลือแค่ชื่อรหัส (`0020`, `EA13703`) + รูป
**และมี 421 URL ใน store-products-sitemap แต่สินค้าจริงมี 290** — ส่วนต่าง ~131 URL ต้องตรวจว่าตายหรือซ้ำ

### 4. รูปไม่มี alt text
หน้า PRODUCT COLLECTIONS: **68 จาก 76 รูปไม่มี alt** — เสีย image search ทั้งหมด ซึ่งเป็นช่องทางที่เครื่องประดับได้เปรียบ

### 5. หน้าบทความไม่มี schema + บางหน้าไม่มี H1
บทความทุกหน้า JSON-LD = 0 (ไม่มี `Article` / `FAQPage`) · `/ลงทุนเงินแท่ง` ไม่มี H1 เลย
หน้าแรกมี H1 = `"THE ART OF FINE SILVER JEWELRY"` — สวย แต่ไม่มีคำที่คนไทยค้น

### 6. หน้าขยะจาก template ยังถูก index
`/courses` · `/book-online` · `/customer-area-1` · `/portfolio` (เนื้อหา = "My Portfolio" อย่างเดียว) · `/blank-2`
+ `/services-4` ที่โชว์ `Casting ฿10,000` / `Photograph jewelry ฿5,000` จาก template
