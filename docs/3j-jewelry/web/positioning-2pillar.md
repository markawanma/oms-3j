> วางโดย CMO (Leia) 2026-08-06 · หัวหอก SEO = เงินแท่ง/ลงทุน + โรงงาน/OEM
> อ้างอิงตัวตนที่ตกลง: [positioning memo](../../../) — silver value-chain hub, trust anchor = "โรงงานผลิตเอง 30+ ปี"

## 0. บริบทสำคัญก่อนอ่าน (CMO note)

ยอดขายจริง H1 บอกว่า **hero เงินแท่งล่มไปแล้ว** (ม.ค. ฿12.2M → มิ.ย. ฿975k เพราะราคาเงินร่วง) — แต่นี่คือ **demand cycle ไม่ใช่ปัญหา positioning**. SEO เป็นเกม 6–12 เดือน; ราคาเงินเป็น cyclical เมื่อรอบกลับมา คนที่ search "ซื้อเงินแท่ง" ต้องเจอเรา **ก่อน**. ดังนั้น:

- เลือก 2 pillar นี้เป็นหัวหอก SEO = ถูก
- **แต่ pillar เงินแท่ง = ปลูกต้นไม้รอฤดู ไม่ใช่ตัวทำยอด Q3–Q4 นี้** — ตัวทำยอดสั้นยังเป็น TikTok live + สร้อยคอ อย่าดึง resource ไปสวนแผน CEO
- Trade-off: ลงแรง SEO วันนี้ไม่เห็น conversion ทันที แต่ CAC ของ organic ตอน cycle กลับ ≈ 0 เทียบยิงแอดแย่ง keyword ตอนนั้น

## 1. Positioning Statements

**แบรนด์รวม (umbrella):**
> "3J Jewelry — โรงงานเงินครบวงจรของไทย ประสบการณ์ 30+ ปี: จากเม็ดเงินถึงเครื่องประดับ ผลิตเอง ขายเอง ตรวจสอบได้"

**Pillar เงินแท่ง 999 / ลงทุน:**
> "ซื้อเงินแท่งจากโรงงานผู้ผลิตโดยตรง — เงินแท้ 999 ราคาโรงงาน ไม่ผ่านคนกลาง จับต้องได้จริง มีหน้าร้านจริง"

**Pillar โรงงาน / OEM:**
> "โรงงาน OEM เครื่องประดับเงิน 925 ที่แบรนด์ไทยและต่างประเทศไว้ใจมากว่า 30 ปี — ผลิตครบวงจรตั้งแต่ต้นแบบถึงส่งมอบ"

**ตัวผูก:** narrative เดียวขายสองตลาด — "เราหลอมเงินเอง" = หลักฐานว่าเงินแท่งแท้ (B2C) + credential ว่ารับผลิตได้จริง (B2B). ทุกหน้าวนกลับ trust anchor นี้.

## 2. Audience & Messaging Matrix

| มิติ | รายละเอียด |

| **Tone** | มืออาชีพ ตรงไปตรงมา ภาษาธุรกิจ โชว์ process · หน้า EN + **USD ถูกต้องสำหรับ OEM export** (ต่างจาก B2C ไทยที่ต้อง THB) |

## 3. จุดต่างจากคู่แข่ง

**เงินแท่ง** (vs ร้านทอง / ผู้ค้าโลหะออนไลน์):
- เราผลิตเอง คู่แข่งซื้อมาขายไป → พิสูจน์แหล่งที่มาตั้งแต่เม็ดเงิน (ร้านทองเลียนแบบ claim นี้ไม่ได้)
- เงินคือธุรกิจหลัก ไม่ใช่ของแถม → content ความรู้ลึกกว่า = แกน SEO ที่ชนะได้ (ร้านทองไม่ลงทุนเขียนเรื่องเงิน)
- **ยอมรับตรงๆ:** ไม่มี brand recognition เท่าร้านทองเยาวราช + (ยังไม่ยืนยัน) อาจไม่มี buy-back เป็นทางการ → ถ้าไม่มี buy-back อย่า claim สภาพคล่อง ให้ชู "แท้ + ราคาโรงงาน" แทน

**OEM** (vs โรงงานไทยอื่น / จีน-อินเดีย):
- vs ไทย: ครบวงจรกว่า (เงินแท่งต้นน้ำ + เครื่องประดับปลายน้ำ + CAD) + มี online presence ที่โรงงานรุ่นเก่าไม่มี → **โรงงาน OEM ไทยส่วนใหญ่หาบน Google ไม่เจอ = ช่องว่าง SEO ใหญ่**
- vs จีน/อินเดีย: ไม่ชนที่ราคา (แพ้) — ชนที่ MOQ ยืดหยุ่น, สื่อสารง่าย, QC ใกล้ชิด, craftsmanship ตลาดกลาง-บน

## 4. Brand Voice Guardrails

**ใช้ได้:** "เงินแท้ 999/99.99", "เงินแท้ 925 (Sterling Silver)", "ผลิตเอง", "โรงงานโดยตรง", "ราคาโรงงาน", "ตรวจสอบได้", "30+ ปี", "มีหน้าร้านจริง", "สินทรัพย์ทางเลือก", "ราคาอ้างอิง spot price"

**ห้ามใช้ (compliance — เข้มสุดที่ pillar ลงทุน):**
- ❌ การันตีผลตอบแทน/กำไรทุกรูปแบบ ("รวยแน่", "ราคาขึ้นชัวร์", "ได้กำไร X%")
- ❌ ทำนายราคา ("เงินกำลังจะขึ้น รีบซื้อ") — ข้อมูลเราเองพิสูจน์ว่าราคาลงแรงได้ = liability
- ❌ เรียกตัวเองเป็น "ที่ปรึกษาการลงทุน" / ภาษาที่ทำให้เข้าใจว่าเป็นผลิตภัณฑ์การเงินภายใต้กำกับ — เราขาย physical commodity
- ✅ **บังคับ disclaimer** ทุกหน้า pillar ลงทุน: "ราคาโลหะมีค่ามีความผันผวน อาจขึ้นหรือลงได้ โปรดศึกษาก่อนตัดสินใจ"
- ชื่อแบรนด์ = "3J Jewelry" (ไม่ใช่ "3J Silver") · ราคาที่ไม่ยืนยันห้ามประกาศเป็นคำมั่น · ห้ามสรรพคุณมู/รักษาโรค
- ⚠️ OEM: ห้ามโชว์ผลงานลูกค้ารายใดโดยไม่ได้รับอนุญาต (NDA)
- **Tone แยก pillar:** retail voice "เพื่อนอบอุ่น" ห้ามลามมาหน้าเงินแท่ง/OEM — สองหน้านี้ institutional/professional. คนละเสียงบนโดเมนเดียวได้ ถ้า visual identity (สี/โลโก้) คุมเหมือนกัน

## 5. ข้อมูลที่ยังขาด — ต้องได้คำตอบก่อน content-strategist เดินต่อ

**เงินแท่ง — ✅ ได้คำตอบแล้ว (2026-08-06):**
1. **รับซื้อคืน: ใช่** — ราคารับซื้อคืน = ราคาเงินอ้างอิง (คิดเป็นไทยบาท) หัก **30 บาท ต่อน้ำหนัก 1 บาท** จากราคาขายออก. ขายคืนได้ทั้งหน้าร้านและออนไลน์ → **lock ราคา ณ วันที่ลูกค้าส่งของถึง** แล้วโอนเงินให้. *(ปลดล็อก objection #2 สภาพคล่อง — claim ได้เต็มปาก)*
2. **ราคาอัปเดต:** มี Google Sheet (แยกอีกตัว) → ให้ Wix ดึงมาแสดงบนหน้าเว็บ. **[งาน dev]** ต้องทำ integration Sheet→Wix (Velo) ให้ราคาโชว์ realtime — architect/backend รับช่วง
3. **ขนาดแท่ง:** 0.5 / 1 / 3 / 5 / 10 บาท และ 1 kg
4. **การรับรอง:** ใบรับรองทุกแท่ง · โลโก้บริษัทประทับบนเงินแท่งทุกชิ้น · **serial เฉพาะแท่ง 1 kg** · **NFC tag (IMI) ทุกแท่ง — เอามือถือแตะสแกน → เปิดหน้าเว็บแสดงรูปแท่งจริงตัวนั้น** *(anti-counterfeit + provenance — ปลดล็อก objection #1 "แท้ไหม"; คู่แข่งไม่มี = differentiator + hero SEO angle)* **[งาน dev]** ระบบ NFC→landing per-bar
5. **ช่องทาง:** สั่งผ่าน LINE / Shopee / TikTok / หน้าร้าน · ใบรับประกันทุกชิ้น · ซื้อ-ขายคืนได้ทั้งหน้าร้านและออนไลน์

**OEM:**
6. MOQ จริงต่อประเภทงาน (= conversion gate)
7. เอ่ยชื่อ/โชว์ผลงานลูกค้า OEM รายไหนได้ (NDA)
8. Lead time โดยประมาณต่อ prototype / production run
9. ค่าต้นแบบ/CAD คิดยังไง (ฟรีเมื่อสั่งผลิต? แยก?)
10. ตลาดส่งออกที่เคยทำ (ประเทศไหน — ใช้เป็น credibility ได้แม้ไม่เอ่ยชื่อแบรนด์)
11. นโยบายกันก๊อป (design ownership) เป็นลายลักษณ์อักษรไหม

**โครงสร้างเว็บ (Tech Lead/เจ้าของ):**
12. ยืนยันแผน multi-currency: retail/เงินแท่ง = THB, OEM export = USD — Wix Stores V1 รองรับแบบไหน ต้องเช็คก่อนวาง IA

## 6. ส่งต่อ execution + metric

**content-strategist (Bail):**
- ใช้ข้อ 1-2 เป็นฐาน keyword cluster: เงินแท่ง = **educational-first** (objection 5 ข้อ = หัวข้อ content ตรงๆ เช่น "เงินแท่งดูยังไงว่าแท้", "เงินแท่ง vs ทองคำ") · OEM = **intent-based** ("โรงงานผลิตเครื่องประดับเงิน", "OEM jewelry manufacturer Thailand" TH/EN)
- **อย่าเขียนหน้า product/pricing จนกว่าข้อ 5 (คำถาม 1-9) มีคำตอบ** — เขียน educational content ไปพลางได้ ไม่ติดบล็อก

**metric (Tech Lead):**
- Organic traffic + ranking แยก pillar (Search Console แยก /silver-bar, /oem cluster)
- Conversion: เงินแท่ง = คลิกดูราคา/ทัก LINE · OEM = form inquiry/ทัก LINE — **เว็บตอนนี้ไม่มี inquiry tracking ต้องมีก่อน launch** ไม่งั้นวัด ROI ไม่ได้
- ผูก analytics DB ที่ design ไว้ (LINE = จุด resolve identity)
