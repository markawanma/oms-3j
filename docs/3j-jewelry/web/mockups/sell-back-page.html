สิ่งที่ต้องรู้ก่อนส่งเงินแท่งมาขาย

ก่อนตัดสินใจส่งเงินแท่งมูลค่าสูงทางไปรษณีย์ เราอยากให้คุณรู้คำตอบของคำถามเหล่านี้ก่อน

1รับซื้อคืนเงินแท่งของร้านไหนบ้าง?
3J รับซื้อคืนเฉพาะเงินแท่งที่จำหน่ายจากร้าน 3J เท่านั้น เพื่อยืนยันแหล่งที่มาและความบริสุทธิ์ของเนื้อเงินได้ตรงตามมาตรฐานที่เราผลิตเอง เงินแท่งจากผู้ผลิตหรือร้านอื่น ทางเรายังไม่รับซื้อคืนในขณะนี้
2เงินแท่งมีรอย ไม่มีกล่อง หรือใบรับรองหายแล้ว ยังรับซื้อคืนได้ไหม?
รอเจ้าของยืนยัน
เงื่อนไขสภาพแท่งที่ยังรับซื้อคืนได้ — รอยขีดข่วนเล็กน้อยรับไหม / ไม่มีกล่องหรือใบรับรองแล้วรับซื้อคืนได้ไหม / ราคาต่างจากแท่งที่มีครบไหม
3ต้องเตรียมเอกสารอะไรบ้าง?
แนบใบรับรองความบริสุทธิ์และใบรับประกันที่มากับแท่ง (ถ้ายังมีอยู่) จะช่วยให้ตรวจสอบและประเมินราคาได้เร็วขึ้น
รอเจ้าของยืนยัน
ต้องแนบสำเนาบัตรประชาชนหรือเอกสารยืนยันตัวตนเพื่อรับโอนเงินไหม
4ค่าส่งพัสดุ ใครเป็นคนออก?
รอเจ้าของยืนยัน
ค่าส่งพัสดุขาไป (ลูกค้าส่งเงินแท่งมาขาย) ลูกค้าออกเองทั้งหมด หรือร้านช่วยออก/คืนค่าส่งบางส่วน
5ถ้าเงินแท่งสูญหายหรือเสียหายระหว่างขนส่ง ใครรับผิดชอบ?
รอเจ้าของยืนยัน
นโยบายกรณีพัสดุสูญหาย/เสียหายระหว่างทาง ร้านรับผิดชอบแค่ไหน แนะนำให้ส่งแบบลงทะเบียน/ซื้อประกันพัสดุไหม
6ส่งไปแล้วกี่วันถึงจะได้เงิน?
รอเจ้าของยืนยัน
ระยะเวลาโอนเงินหลังของถึงร้าน (นับเป็นวันทำการ/ชั่วโมง) — คำถามที่ลูกค้าถามมากที่สุด
7ถ้าตกลงราคาที่เสนอไม่ได้ ของจะได้กลับคืนไหม ใครออกค่าส่งกลับ?
รอเจ้าของยืนยัน
ถ้าลูกค้าไม่พอใจราคาที่ประเมินหลังของถึงร้าน ปฏิเสธไม่ขายได้ไหม ของส่งกลับใคร ใครออกค่าส่งกลับ
