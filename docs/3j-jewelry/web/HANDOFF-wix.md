# งานหน้าร้าน Wix — ใครทำอะไร

> อัปเดต 26 ส.ค. 2026 · ไฟล์นี้คือจุดนัดพบระหว่างงานที่ agent ทำได้กับงานที่ต้องใช้มือเจ้าของ
> อ่านคอลัมน์ "สถานะ" ก่อน — บอกว่าตอนนี้ติดอยู่ที่ใคร

---

## สรุปสั้น: agent ทำ **ข้อมูล** ได้หมด · เจ้าของทำ **หน้าตา** เท่านั้น

| งาน | agent ทำได้ไหม | ทำไม |
|---|---|---|
| แก้ราคา / ชื่อสินค้า / คำอธิบาย / SKU (290 ตัว) | ✅ ผ่าน Wix API | เป็นข้อมูลในระบบ |
| ใส่ title/description สำหรับ SEO รายสินค้า | ✅ | เป็นข้อมูล |
| ซ่อน/แสดงสินค้า | ✅ | เป็นข้อมูล |
| เปลี่ยนสกุลเงิน USD → THB | ❌ | เป็นค่าตั้งค่าในแดชบอร์ด ไม่ใช่ API |
| แก้ข้อความตั้งต้นช่องราคา (`0` → `กำลังโหลด...`) | ❌ | อยู่ใน Wix Editor |
| จัดหน้า/วางบล็อกในหน้าเว็บ | ❌ | อยู่ใน Wix Editor |

## 🔴 งานที่ค้าง — เรียงตามความเร่งด่วน

### 1. สินค้า 290 ตัวโชว์ `US$0.00` อยู่หน้าร้านตอนนี้

**สถานะ: ติดที่เจ้าของ** — ต้องได้ราคาก่อน agent ถึงจะทำได้

ยืนยันจากฐานข้อมูล Wix จริง (26 ส.ค.):
```
totalResults: 290 · price: 0 ทุกตัว · currency: USD
sku: "" ว่าง · description: "" ว่าง · visible: true (เปิดให้คนเห็นหมด)
```
**ไม่ใช่บั๊กโหลดช้า — ราคาไม่เคยถูกกรอกเลย**

**เจ้าของเลือก 1 ใน 2 ทาง:**
- **(ก) ส่งไฟล์ราคามา** — Excel/CSV ที่มีรหัสสินค้า + ราคา → agent กรอกให้ทั้ง 290 ตัว
- **(ข) สั่งให้ซ่อนสินค้าที่ยังไม่มีราคาไว้ก่อน** → agent ทำได้ทันที หน้าร้านจะว่างแต่ไม่พัง ดีกว่าโชว์ของฟรี 290 ชิ้น

> ⚠️ agent จะไม่แตะหน้าร้านจนกว่าเจ้าของสั่ง เพราะเป็นหน้าที่ลูกค้าเห็นจริง

---

### 2. สกุลเงินเป็น USD ทั้งที่ลูกค้าไทย

**สถานะ: ต้องเจ้าของทำเอง** (ไม่ใช่ API)

แดชบอร์ด Wix → `การตั้งค่า` → `รับชำระเงิน` → เปลี่ยนสกุลเงินเป็น **THB**

⚠️ **เปลี่ยนสกุลเงินไม่ได้แก้ `0.00`** — เป็นคนละปัญหา ต้องทำทั้งสองอย่าง

---

### 3. หน้าราคาเงินโชว์ `0 บาท` ก่อนโหลดเสร็จ

**สถานะ: ต้องเจ้าของทำเอง** (อยู่ใน Editor)

**วิธีแก้ที่ได้มาจากการดูคู่แข่ง** — Bowins ใช้ระบบเดียวกับเรา (ราคาโหลดทีหลังด้วย JavaScript) แต่ต่างกันจุดเดียว:

| | ตอนยังโหลดไม่เสร็จ |
|---|---|
| Bowins | `Loading price data...` |
| 3J | `0 บาท` ❌ |

**ทำ:** Wix Editor → เลือกช่องที่แสดงราคาแต่ละช่อง → เปลี่ยน**ข้อความตั้งต้น**จาก `0` เป็น `กำลังโหลดราคา...` หรือ `—`

**ทำไมต้องแก้ แม้ราคาจะขึ้นใน 5-6 วิ:** Google กับตัวพรีวิวลิงก์ (ไลน์/เฟซบุ๊ก) **ไม่รอ** มันอ่านค่าตั้งต้นแล้วจากไป ตอนนี้มันอ่านได้ว่า "0 บาท"

### 4. LINE — รวมเหลือลิงก์เดียว

**สถานะ: ต้องเจ้าของทำเอง** (แก้ตามที่ต่างๆ)

ตรวจแล้ว **ทั้งสองลิงก์ถูกต้องทั้งคู่ ชี้ไปบัญชีเดียวกัน**:
```
lin.ee/OOpBqt1  →  @duh3461p  ┐
lin.ee/xI9iXTJ  →  @duh3461p  ┘ = 3J Silver (@3jjewelry) เพื่อน 7,399 คน
```
`@duh3461p` = รหัสอัตโนมัติที่ LINE แจกตอนสมัคร · `@3jjewelry` = รหัสสวยที่ซื้อเพิ่ม — **บัญชีเดียวกัน**
มี 2 ลิงก์เพราะกดสร้างลิงก์ใหม่คนละครั้ง (ท้ายลิงก์มี timestamp ต่างกัน)

**ทำ:** เปลี่ยนทุกที่ให้ใช้ **`https://page.line.me/3jjewelry`**
เหตุผล: อ่านออกว่าเป็นร้านอะไร · จำได้ · **ไม่มีวันเปลี่ยน** ต่างจาก `lin.ee` ที่งอกใหม่ได้เรื่อยๆ

**เจอเพิ่ม:** ที่อยู่บน LINE OA เขียน **112/20*2*** แต่ที่อยู่จดทะเบียนคือ **112/20*3*** — ต่างกันหนึ่งตัว ควรแก้ให้ตรง

### 5. หน้าขายคืน — เนื้อหา + ภาพจำลอง

**สถานะ: agent กำลังทำ** → เสร็จแล้วเจ้าของเอาไปวางเอง

ไฟล์ที่จะได้:
- `docs/3j-jewelry/web/sell-back-page-redesign.md` — ข้อความพร้อม copy ไปวาง
- `docs/3j-jewelry/web/mockups/sell-back-page.html` — เปิดในเบราว์เซอร์ดูหน้าตาได้เลย

**หน้าเดิมโครงดีอยู่แล้ว** (4 ขั้นตอนชัด · ล็อกราคา ณ วันที่จัดส่ง = ยุติธรรมและเป็นจุดแข็ง) แต่**ไม่ตอบสิ่งที่คนกลัวที่สุด** — คนกำลังจะส่งของหลักหมื่น-แสนไปให้คนแปลกหน้า

**❓ ต้องเจ้าของตอบ 3 ข้อ ไม่งั้นเขียนไม่ได้ (ห้ามแต่งตัวเลขเอง):**
1. ของถึงร้านแล้ว **โอนเงินภายในกี่วัน**
2. **ค่าส่งมาใครออก** และถ้าตกลงราคาไม่ได้ **ค่าส่งกลับใครออก**
3. **ต้องแนบเอกสารอะไรบ้าง** (บัตรประชาชน? ใบรับรอง?)

*(อีก 3 ข้อที่ควรตอบด้วยถ้ามีเวลา: แท่งมีรอย/กล่องหาย/ใบรับรองหาย รับไหม · ของหายระหว่างส่งใครรับผิดชอบ)*

### 6. SEO — ทำไมไม่ขึ้น และแผน

**สถานะ: ติดที่ข้อ 1** — ทำก่อนแก้ 290 ตัวไม่มีประโยชน์

**คำตอบว่าทำไมไม่ขึ้น:**

| Google ต้องการ | ของเรา |
|---|---|
| ชื่อสินค้าที่มีคำค้น | `RP9963` `R10012PL` — ไม่มีคำไทยสักคำ |
| คำอธิบายสินค้า | **ว่างเปล่าทั้ง 290 ตัว** |
| ราคา | `US$0.00` |
| SKU | ว่าง |

**ไม่ใช่อันดับแย่ — แต่ไม่มีอะไรให้ Google อ่านเลย** คนค้น "แหวนเงินแท้" ไม่มีทางเจอหน้าที่มีแค่คำว่า `RP9963`

**ข่าวดี:** สินค้าชุดใหม่ (พ.ค. 2026) เริ่มตั้งชื่อไทยแล้ว — `เทพเจ้าฮก` `เทพเจ้าซิ่ว` `เทพเจ้าลก` **มาถูกทางแล้ว**

**พอได้ราคา+ชื่อแล้ว agent ทำต่อได้ทันที:** ตั้งชื่อสินค้าที่มีคำค้น · เขียนคำอธิบาย · ใส่ title/description รายหน้า · ปรับชื่อให้เข้ากับวิธีค้นของแต่ละแพลตฟอร์ม (Google กับ Shopee คนละกติกา)

## ลำดับที่แนะนำ

```
เจ้าของส่งราคา 290 ตัว ──┐
                          ├──> agent กรอกราคา+ชื่อ+คำอธิบาย ──> agent ทำ SEO
เจ้าของเปลี่ยน USD→THB ──┘

เจ้าของตอบ 3 ข้อขายคืน ──> agent เขียนเนื้อหาให้ครบ ──> เจ้าของวางใน Editor

เจ้าของแก้ข้อความช่องราคาใน Editor  (ทำแยกได้เลย ไม่ต้องรอใคร)
เจ้าของรวมลิงก์ LINE                (ทำแยกได้เลย)
```

**ทำแยกได้ทันทีโดยไม่ต้องรอใคร: ข้อ 2, 3, 4** — ใช้เวลารวมไม่เกิน 1 ชั่วโมง และเป็น 3 ข้อที่กระทบความน่าเชื่อถือมากที่สุด
