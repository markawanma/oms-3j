## 0. เถียงกลับก่อน — โจทย์ที่เจ้าของถามอาจตั้งผิดฐาน

เจ้าของถามว่า **"ทำยังไงให้ลูกค้าเข้ามาค้นหาแล้วดูได้ทั้ง 3 เสา แล้วไม่งง"**

คำว่า **"ดูได้ทั้ง 3 เสา"** คือสมมติฐานที่ข้อมูลจริงไม่สนับสนุน: คนที่ซื้อทั้งเงินแท่งและเครื่องประดับมีแค่ **1.6% (22/1,256)** แปลว่าลูกค้าจริง 98.4% ต้องการแค่ 1 เสาเท่านั้น การออกแบบให้ "ดูได้ทั้งหมด" แปลว่าทุกคนต้องไถผ่านเนื้อหาอีก 2 เสาที่ไม่เกี่ยวกับตัวเองก่อนเจอของที่ต้องการ — นั่นคือ **เพิ่มความงง ไม่ใช่ลด**

**เป้าหมายที่ถูกต้องกว่าคือ:** ลูกค้าแยกทางได้เร็วที่สุด (หน้าแรกใช้เวลา ≤3 วินาทีในการรู้ว่าต้องกดตรงไหน) ส่วนคนที่ยังไม่รู้ตัวว่าอยากได้อะไร (เช่นเข้ามาทาง brand search "3j" 216 ครั้ง — คนกลุ่มนี้*อาจ*อยากเห็นภาพรวม) ให้เจอทางเลือกทั้ง 3 แบบเท่าเทียมกันในจุดเดียว (หน้าแรก) แล้วปล่อยให้เขาเลือกเอง — ไม่ใช่ยัดทั้ง 3 เรื่องปนกันทุกหน้า

เอกสารนี้ตอบคำถามเจ้าของด้วยการ reframe เป็น: **"แยกเร็ว + เชื่อมเฉพาะจุดที่มีเหตุผลจริง"** ตามที่ระบุในโจทย์ ไม่ใช่ตีความว่าเจ้าของสั่งผิด — แค่คำว่า "ดูได้ทั้ง 3 เสา" ต้องตีความเป็น "มีทางเลือกให้เห็นครบตอนแรกเข้า" ไม่ใช่ "ทุกหน้าต้องพูดถึงทั้ง 3 เสา"

## 2. โครงเมนูนำทาง — แยกทางภายใน ≤3 วินาที

### หลักการ
มือถือเป็นช่องทางหลัก (TikTok/LINE) → เมนูต้องเป็น **hamburger ที่เปิดมาเจอ 6 บรรทัดสั้นๆ ไม่ใช่ dropdown ซ้อน dropdown**

### ลำดับเมนู (บนลงล่าง)

```
☰ เมนู
├─ หน้าแรก
├─ เครื่องประดับเงินแท้ 925      ← เสา 2 (ยอดขาย 82.8%)
├─ ราคาเงินแท่งวันนี้            ← เสา 1 (traffic 34% ของเว็บ)
├─ รับผลิต OEM                  ← เสา 3
├─ เกี่ยวกับเรา (โรงงาน 30 ปี)   ← สะพานร่วม
└─ ติดต่อเรา
```

**ทำไมเรียงแบบนี้ (ไม่ใช่เรียงตาม traffic ปัจจุบัน):**
- เครื่องประดับขึ้นอันดับ 1 แม้ยัง 0 traffic วันนี้ เพราะเป็นทิศทางธุรกิจที่ CMO ตัดสินใจแล้วว่าเป็นหัวหอกใหม่ (82.8% ของยอดขายจริง) — เมนูต้องนำธุรกิจ ไม่ใช่ตามหลัง traffic เก่า
- **"ราคาเงินแท่งวันนี้" ต้องอยู่ top-level ห้ามซ่อนใน dropdown** แม้เสานี้ถูกลดชั้นเป็น "รักษาฐาน" เพราะเป็น 34% ของ impression ทั้งเว็บ — ซ่อนเมนูนี้ = ฆ่า traffic ที่แข็งที่สุดที่มีอยู่จริงตอนนี้ทันที (คนละเรื่องกับการไม่ลงทุน content เพิ่ม)
- ป้ายชื่อเมนูใช้คำที่ตรง intent การค้นจริง ("ราคาเงินแท่งวันนี้" ตรงกับคำค้นอันดับ 1 จริง) ไม่ใช้ jargon แบบเดิม (CATALOG / ART TOY) ที่ทำให้เดาไม่ออกว่าคืออะไร

### ปุ่มลอย (sticky) บนทุกหน้า — มือถือ
ปุ่ม LINE ทักแชท ลอยมุมล่างขวาตลอด scroll — เป็น primary action เดียวที่ตามทุกหน้า เพราะเว็บนี้ไม่ใช่ shop, ทุก journey จบที่ "ทัก" ไม่ใช่ "checkout"
⚠️ **ต้องตรวจก่อนว่า Wix มี widget floating button สำเร็จรูปให้ใช้ไหม** (ดูคำถามข้อ 5) — ถ้าไม่มีในธีมปัจจุบัน อาจต้องใช้ Wix App Market แทนการสร้างเอง

## 3. Customer Journey แยกตามกลุ่ม

### 3.1 เงินแท่ง (นักลงทุน, AOV ~฿20,000)

```

```
**ไม่ควรเจอ**: หน้าเครื่องประดับ/OEM แบบ cross-sell CTA — ไม่ใส่ปุ่ม "ไปดูเครื่องประดับ" ในหน้านี้เลย (98.4% ของคนกลุ่มนี้ไม่ต้องการเห็นของอีก 2 เสา — ยัดเข้าไปคือ noise ไม่ใช่ opportunity)
🔄 **ข้อยกเว้นเดียว**: "วงจรเนื้อเงิน" ใน `/sell-silver-bar` จะพูดถึงเครื่องประดับ 925 **แต่พูดในฐานะคำอธิบายว่าทำไมโรงงานรับซื้อคืนได้** (เนื้อเงินถูกนำไปผลิตต่อจริง) ไม่ใช่ CTA ชวนไปซื้อเครื่องประดับ — ต่างกันตรงที่อันนี้ไม่มีปุ่ม ไม่มี "ดูคอลเลกชัน →" แค่เป็นประโยคอธิบายกลไกเท่านั้น (ดูรายละเอียดหัวข้อ 4.1)

## 4. สะพานระหว่างเสา — สองชั้นที่ต้องแยกจากกัน (🔄 แก้ไขรอบ 2)

### 4.0 ทำไมต้องแยกเป็นสองชั้น

ดราฟต์แรกพูดถึง "สะพาน" เป็นเรื่องเดียว วัดด้วยพฤติกรรมซื้อ (1.6% overlap) แล้วสรุปว่าอ่อน — **ข้อสรุปนั้นยังจริง แต่ตอบแค่ครึ่งเดียวของคำถาม**

มี 2 มิติที่ต้องแยกกันเด็ดขาด เพราะออกแบบต่างกันคนละแบบ:

| มิติ | วัดจากอะไร | แข็งหรืออ่อน | ออกแบบยังไง |
|---|---|---|---|
| **สะพานฝั่งลูกค้า** (พฤติกรรมซื้อข้ามเสา) | คนซื้อทั้งเงินแท่ง+เครื่องประดับ = 1.6% | **อ่อน** | ไม่ทำ cross-sell CTA ("อาจสนใจ...") ข้ามเสา |
| **สะพานฝั่งเรื่องเล่า** (ที่มาวัตถุดิบ/ความน่าเชื่อถือ) | วงจรเนื้อเงินเดียวกันไหลไปทั้ง 3 เสาจริง | **แข็งมาก** — คู่แข่งไม่มีโรงงานเลียนแบบไม่ได้ | อธิบาย "กลไก" เป็น trust layer ไม่ใช่ CTA ชวนซื้อข้ามเสา |

พูดง่ายๆ: **ห้ามชวนคนซื้อเงินแท่งไปซื้อเครื่องประดับ (สะพานลูกค้าอ่อน) แต่บอกได้เต็มที่ว่า "เงินที่คุณถือมาจากที่เดียวกับที่เราใช้ผลิตเครื่องประดับ" (สะพานเรื่องเล่าแข็ง)** — ประโยคแรกคือการขาย ประโยคหลังคือการอธิบายความจริงที่เสริมความน่าเชื่อถือโดยไม่ต้องขายอะไร นี่คือเส้นแบ่งที่ทำให้ใส่เนื้อหานี้ได้โดยไม่รบกวนคนที่ไม่สนใจ

### 4.1 🔄 วงจรเนื้อเงิน — สะพานเรื่องเล่าที่แข็งที่สุด (องค์ประกอบใหม่)

**คืออะไร**: ไดอะแกรมง่ายๆ 3 ขั้น อธิบายว่าเนื้อเงินบริสุทธิ์ 99.99% แยกไปเป็น 2 สาย (เงินแท่ง 999 กับเครื่องประดับ 925) และเงินแท่งที่รับซื้อคืนไม่ได้ถูกขายต่อ แต่ไหลกลับเข้าสายผลิตเครื่องประดับจริง

**ทำไมสำคัญกว่าที่คิดตอนแรก**: นี่คือเรื่องเล่าเดียวที่ผูก 3 เสาด้วย "เหตุผลเชิงโครงสร้าง" ไม่ใช่คำสัญญา — คู่แข่งที่ไม่มีโรงงานพูดแบบนี้ไม่ได้เลย เพราะไม่มี demand ใช้เนื้อเงินจริงมารองรับ

**Wireframe มือถือ — ต้องอยู่ใน 1 หน้าจอ (vertical stack, ไม่ใช่ horizontal flowchart)**:

```
┌─────────────────────────────┐
│   🔘 เนื้อเงินบริสุทธิ์ 99.99%   │
└──────────────┬──────────────┘
               │
      ┌────────┴────────┐
      ▼                 ▼
┌───────────┐     ┌───────────┐
│ เงินแท่ง 999 │     │เครื่องประดับ│
│ เก็บ/ลงทุน  │     │  เงิน 925   │
└─────┬─────┘     │ขายปลีก+OEM │
      │           └───────────┘
      ▼                 ▲
┌─────────────┐         │
│ รับซื้อคืน    │─────────┘
│(โรงงานใช้ผลิต│  "เงินที่รับคืนไม่ได้ขายต่อ
│ เครื่องประดับ│   แต่เข้าสายการผลิตจริง"
│  ทุกวัน)     │
└─────────────┘
```

**ข้อความประกอบ (สั้น 3 บรรทัด ต่อกลุ่มผู้ชม — ไม่ต้องทำ 3 เวอร์ชันแยกหน้า แค่ 3 บรรทัดใต้ไดอะแกรมเดียว)**:
- นักลงทุน: "โรงงานรับซื้อคืนเงินแท่งได้อย่างต่อเนื่อง เพราะนำเนื้อเงินไปผลิตเครื่องประดับต่อจริงทุกวัน (ราคารับซื้อคืนอิงราคาเนื้อเงิน ณ วันที่ลูกค้าจัดส่ง มีเงื่อนไขตามขนาด)"
- คนซื้อเครื่องประดับ: "เครื่องประดับเงิน 925 ของเรา มาจากเนื้อเงินบริสุทธิ์มาตรฐานเดียวกับที่เราขายเป็นแท่งลงทุน"
- OEM: "เราคุมคุณภาพตั้งแต่เนื้อเงินบริสุทธิ์ ไม่ได้ซื้อวัตถุดิบต่อจากใคร"

**⚠️ ขอบเขตคำที่ต้องระวัง (ส่งต่อ copywriter ตอนเขียนจริง)**:
- ห้าม "ขายคืนได้แน่/รับคืนไม่จำกัดทุกกรณี" — ต้องมีวงเล็บ/หมายเหตุว่า "มีเงื่อนไขตามขนาด" กำกับเสมอ (ของจริงมีเงื่อนไข ไม่ใช่ unconditional)
- ห้ามใส่ตัวเลขส่วนต่าง/สูตรคำนวณใดๆ ในไดอะแกรมหรือข้อความประกอบ
- ห้ามเทียบราคา 925 กับราคาเงิน spot ในบรรทัดที่พูดถึงเครื่องประดับ — พูดได้แค่ "ที่มาวัตถุดิบเดียวกัน" ไม่ใช่ "ราคาคำนวณจากฐานเดียวกัน"
- ฝั่ง OEM ห้ามมีตัวเลขทุกชนิดตามเดิม

**ที่วาง (3 จุด, ความเข้มข้นต่างกัน)**:

| หน้า | เวอร์ชัน | เหตุผล |
|---|---|---|
| หน้าแรก | **ย่อ** — ไดอะแกรมเล็ก + หัวข้อเดียว "เนื้อเงินเดียวกัน 2 ทาง" ไม่มี 3 บรรทัดอธิบายเต็ม | เสริมความน่าเชื่อถือให้ทุกกลุ่มเห็นตั้งแต่แรก โดยไม่แย่งพื้นที่จาก 3-card hero ที่เป็น primary action — วางไว้ below-the-fold หลัง hero (ดูหัวข้อ 5) |
| `/know-us-more` (เกี่ยวกับเรา) | **เต็ม** — ไดอะแกรม + 3 บรรทัดครบ + รายละเอียดกระบวนการโรงงาน | หน้านี้เป็นสะพานร่วมอยู่แล้ว (หัวข้อ 4.3) คนที่มาหน้านี้กำลังหาเหตุผลเชื่อใจ ให้ข้อมูลเต็มที่ได้ |
| `/sell-silver-bar` (ขายคืนเงินแท่ง) | **เต็ม เฉพาะบรรทัดนักลงทุน** — ไดอะแกรม + บรรทัดเดียว (นักลงทุน) ไม่ใส่อีก 2 บรรทัด | นี่คือคำตอบตรงของคำถามจริงที่ K-2SO เจอ ("ทำไมรับซื้อคืนได้") — ไม่ต้องพูดถึงเครื่องประดับ/OEM ในมุมอื่นเพราะไม่ตรง intent ของคนอ่านหน้านี้ |

**ทำไมไม่รบกวนคนที่ไม่สนใจ**: วงจรเนื้อเงินเป็น **info block ไม่มีปุ่ม action** — ไม่แข่งกับปุ่มหลักของหน้า (LINE/เช็คราคา/ดูคอลเลกชัน) วางเป็นเนื้อหาคั่นระหว่าง section ไม่ใช่สิ่งที่ต้องอ่านก่อนถึงปุ่มหลัก คนที่ไม่สนใจ trust story ก็ scroll ผ่านได้เหมือนเนื้อหาเสริมทั่วไป — ต่างจาก cross-sell CTA (หัวข้อ 4.4) ตรงที่อันนี้**ไม่มีลิงก์ชวนไปหน้าอื่น** มีแต่ข้อความอธิบาย

**Effort**: M (ต้องสร้าง 1 กราฟิก/ไดอะแกรมง่ายๆ ใช้ซ้ำ 3 จุด + เขียนข้อความ 3 เวอร์ชันความยาว) — เสนอให้ทีม content ทำเป็นภาพ static เดียว (ไม่ต้อง interactive) เพราะ Wix custom animation มี cost สูงเกินความจำเป็น

### 4.2 เครื่องประดับ → OEM (แข็งที่สุดฝั่งลูกค้า, มีอยู่แล้ว)
**ที่วาง**: ป้าย/badge เล็ก "รับผลิต OEM" บนหน้ารายละเอียดสินค้าแต่ละชิ้น (มีอยู่แล้วทุกตัวจาก 290 ตัว)
**ทำไมไม่รบกวน**: เป็น badge ขนาดเล็กอยู่ใต้รูป ไม่ใช่ popup/banner ที่บังคับอ่าน — คนที่แค่มาดูจะใส่เองก็ผ่านมันไปได้โดยไม่ต้องสนใจ ส่วนคนที่เป็นพ่อค้า/แบรนด์จะสะดุดตาป้ายนี้ทันทีเพราะมัน relevant กับเขาโดยตรง
**Action**: ไม่ต้องทำอะไรเพิ่ม เก็บของเดิมไว้

### 4.3 โรงงาน 30 ปี → ทั้ง 3 เสา
**ที่วาง**: หน้าเดียว `/know-us-more` (เกี่ยวกับเรา) แล้วลิงก์จาก **footer ทุกหน้า** (ไม่ใช่ nav บนหรือ banner)
**ทำไมไม่รบกวน**: footer อยู่ล่างสุด ต้อง scroll ผ่านเนื้อหาหลักไปก่อนถึงจะเห็น — คนที่ไม่สนใจ trust story ก็จะไม่ต้อง scroll ไปเจอ แต่คนที่กำลังตัดสินใจซื้อ (โดยเฉพาะ OEM ที่ตัดสินใจนานกว่า) จะหาเจอเมื่อต้องการ
🔄 หน้านี้คือที่อยู่ของ "วงจรเนื้อเงิน" เวอร์ชันเต็มด้วย (ดู 4.1) — โรงงาน 30 ปี + วงจรเนื้อเงิน เป็นสองเรื่องที่เสริมกัน (โรงงาน = ประสบการณ์/ฝีมือ, วงจรเนื้อเงิน = โครงสร้างธุรกิจที่ทำให้คำมั่นสัญญาเป็นจริงได้)

### 4.4 เงินแท่ง ↔ เครื่องประดับ **ฝั่งลูกค้า** — จงใจไม่สร้างสะพาน active
ข้อมูลยืนยัน 1.6% overlap — ไม่ใส่ banner/CTA ชวนซื้อข้ามเสาในเนื้อหาทั้งสองฝั่ง ปล่อยให้เชื่อมได้ทางเดียวคือ **เมนูบนสุด** ที่มีอยู่แล้วทุกหน้า (ไม่ต้องเพิ่มอะไร)
**เหตุผลที่ต้องระบุชัด**: การใส่ cross-sell CTA เพิ่มในจุดนี้ (เช่น "ลูกค้าที่ซื้อเงินแท่งอาจสนใจ...") จะเสีย cognitive space ของหน้าที่ traffic แข็งที่สุด (`/silver-price`) โดยแลกกับ conversion ที่พิสูจน์แล้วว่าแทบไม่เกิด — **trade-off ไม่คุ้ม**
🔄 **นี่คือคนละเรื่องกับหัวข้อ 4.1** — วงจรเนื้อเงินไม่ใช่ CTA ชวนซื้อ เป็นข้อความอธิบายกลไก จึงใส่ในหน้าเงินแท่งได้โดยไม่ขัดกับหลักการข้อนี้

### 4.5 เงินแท่ง → OEM — ไม่มี
นักลงทุนไม่ใช่ผู้ผลิต ไม่มีเหตุผลเชื่อมตามโจทย์ — ไม่ออกแบบอะไรเพิ่ม (วงจรเนื้อเงินไม่ได้เปลี่ยนข้อสรุปนี้ เพราะนักลงทุนยังไม่ใช่ผู้ผลิต แค่รู้ที่มาของเงินที่ตัวเองถือ)

## 5. หน้าแรก — แก้ความขัดแย้งพาดหัว vs เนื้อหา

### ปัญหา
H1 ปัจจุบัน "THE ART OF FINE SILVER JEWELRY" (สื่อเครื่องประดับ) แต่เนื้อหาจริง ~90% เป็นเงินแท่ง — เว็บ "พูดไม่ตรงกับตัวเอง" ตั้งแต่ประโยคแรก

### แนวทางแก้: เปลี่ยนจาก "1 พาดหัวเดี่ยว" เป็น "3-card split" ในโซน hero

```
[ Hero: ไม่มีพาดหัวยาวบรรยายเดี่ยว — แทนที่ด้วย 3 การ์ดเท่ากัน ]

┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│ 💍 เครื่องประดับ  │  │ 🪙 ราคาเงินแท่ง   │  │ 🏭 รับผลิต OEM   │
│    เงินแท้ 925    │  │    วันนี้         │  │                  │
│ [ดูคอลเลกชัน →]  │  │ [เช็คราคา →]      │  │ [ขอใบเสนอราคา →]│
└─────────────────┘  └─────────────────┘  └─────────────────┘

[ Below fold: 🔄 วงจรเนื้อเงิน (เวอร์ชันย่อ) — ไดอะแกรมเล็ก "เนื้อเงินเดียวกัน 2 ทาง" ]
[ Below fold: โรงงาน 30 ปี (trust, สะพานร่วม) ]
[ Below fold: บทความล่าสุด — mixed feed มี tag แยก 3 หมวด ]
[ ปุ่ม LINE ลอยตลอดหน้า ]
```

🔄 **ทำไมวงจรเนื้อเงินอยู่ below-fold ไม่ใช่ใน hero**: hero 3-card ต้องทำหน้าที่เดียวคือ "แยกทางเร็วที่สุด" — ถ้าใส่ไดอะแกรมวงจรเนื้อเงินปนอยู่ในโซนแรกจะแข่งกับ primary action (กดเข้าเสาที่ต้องการ) วงจรเนื้อเงินเป็นเนื้อหาสำหรับคนที่ **เลื่อนลงมาต่อ** เพื่อหาความมั่นใจเพิ่ม ไม่ใช่สิ่งที่ต้องเห็นก่อนตัดสินใจว่าจะไปทางไหน — ลำดับความสำคัญคือ "แยกทางก่อน อธิบายทีหลัง"

**ลำดับการ์ด**: เครื่องประดับก่อน (เหตุผล = 82.8% ยอดขายจริง + ทิศทาง CMO) แต่ **ขนาดการ์ดเท่ากันทั้ง 3 ไม่ลดขนาดการ์ดเงินแท่ง** เพราะยังเป็น traffic แข็งสุดของเว็บ การลดขนาดเท่ากับเสี่ยง drop-off ของกลุ่มที่ยังทำเงินจริงให้เว็บอยู่ตอนนี้

**Trade-off ที่ต้องยอมรับตรงๆ**: การใช้ 3-card split ทำให้หน้าแรก "ไม่มี story เดียว" ซึ่งขัดกับหลัก branding ทั่วไปที่อยากให้แบรนด์เล่าเรื่องเดียวชัดๆ แต่ในเคสนี้จำเป็น เพราะ 3J เป็น **3 ธุรกิจใต้ชื่อเดียว** ไม่ใช่ 1 ธุรกิจที่ขยาย SKU — นี่คือ compromise ที่ยอมรับได้ตอนนี้ ไม่ใช่ solution ที่สวยสมบูรณ์แบบ ถ้าในอนาคตเสาใดเสาหนึ่งชัดเจนว่าทิ้งไปแล้ว (เช่นเงินแท่งหดจนไม่มีความหมาย) ค่อยกลับมา revisit ให้เหลือ narrative เดียว

**Effort**: ขึ้นกับว่าธีม Wix ปัจจุบันมี section "3 กล่องเท่ากัน" สำเร็จรูปให้ลากใช้ไหม — **ถ้ามีให้ reuse ทันที (M effort)** ถ้าไม่มีต้องสร้าง section จาก layout ว่าง (L effort) → ดูคำถามข้อ 3

## 6. State ที่คนจะเจอจริง — สินค้าไม่มีราคา/ไม่มีคำอธิบาย

Mapping ตาม 4 state บังคับ แต่ต้องพูดตรงๆ ก่อนว่า **Wix เป็น CMS แบบ static-ish ไม่ใช่ app ที่ fetch data สด** — loading/error ส่วนใหญ่ Wix จัดการเองในตัว component ไม่ต้อง over-engineer สิ่งที่เราควบคุมได้จริงคือ **empty** กับ **"ราคาที่ตั้งใจไม่โชว์"** (ซึ่งไม่ใช่ empty จริง แต่ต้อง treat เป็น state แยกเพราะพฤติกรรมที่ต้องออกแบบต่างจาก empty ทั่วไป)

| State | สถานการณ์จริง | สิ่งที่ต้องทำ | ใครทำ |
|---|---|---|---|
| **Loading** | โหลด grid 290 สินค้า | ปกติ Wix Stores จัดการ skeleton ในตัว — ไม่ต้องแตะ | — |
| **Error** | โหลดข้อมูลสินค้าไม่สำเร็จ | Wix native fallback จัดการเอง — ไม่ต้อง custom เพิ่ม | — |
| **Empty (ไม่มีคำอธิบาย)** | 290 ตัวมี `description` ว่างเปล่าจริง | เติม description มาตรฐาน (วัสดุเงิน 925, ตัวเลือกชุบ, หมายเหตุน้ำหนักถ้ามี) แทนปล่อยว่าง | **ผมทำผ่าน API ได้** |
| **"ราคาที่ตั้งใจไม่โชว์" (จุดวิกฤตที่สุด)** | ตอนนี้โชว์ `฿0.00` หรือช่องราคาว่าง = ดูเหมือนเว็บพัง | **ห้ามโชว์ 0.00 หรือปล่อยว่างเปล่า** แทนที่ด้วยข้อความในตำแหน่งราคาเดิม เช่น "สอบถามราคา — ทักไลฟ์/LINE" + ปุ่ม LINE inline ตรงนั้นเลย | เจ้าของแก้ label ใน Wix Editor (ถ้าทำได้ — ดูคำถามข้อ 2) |
| **Success (ข้อมูลครบ)** | สินค้าที่มี description + SEO title ครบ | รูป + ชื่อ + description + ป้าย "925" + ป้าย OEM + ปุ่ม "สอบถาม" | ผสมทั้งสองฝั่ง |

**เหตุผลที่ "ราคาที่ตั้งใจไม่โชว์" ต้องแยกเป็น state ของตัวเอง ไม่ใช่แค่ empty**: empty ทั่วไปคือ "ข้อมูลหายจะเติมทีหลัง" แต่นี่คือ "ข้อมูลมีอยู่แต่ห้ามเปิดเผยสาธารณะ" — ถ้าปฏิบัติเหมือนกันคือใส่ placeholder เดียวกัน ผู้ใช้จะไม่รู้ความแตกต่างระหว่าง "ร้านนี้ยังไม่กรอกราคา (ดูไม่น่าเชื่อถือ)" กับ "ร้านนี้ตั้งใจให้ทักถามราคา (โมเดลธุรกิจปกติของ B2B/live commerce)" ข้อความต้องสื่อสารเจตนาให้ชัด ไม่ใช่ปิดบังด้วยความเงียบ

- **P0 ใช้เวลาจริงแค่ ~30-40 นาที** (unpublish หน้าขยะ/หน้าอันตราย) ควรทำก่อนสุดเพราะเป็นความเสียหายที่เปิดอยู่ตอนนี้ ไม่ใช่แค่ SEO
