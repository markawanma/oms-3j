   - **แก้ความเข้าใจเดิม:** positioning doc ข้อ 2 + content-plan #5/#12 คิดว่า "Sheet→Wix ยังไม่ทำ" — **ผิด มันทำแล้ว** ไม่ใช่ blocker การเขียน

## 🔴 ปัญหาที่ audit เจอ (ต้องแก้)

1. **ราคาโชว์ 0 บาท ตอนนอกเวลาทำการ** — `/silver-bar` ตอน 04:26 = 0 ทุกช่อง (น่าจะ Sheet ยังไม่ update ราคาวันนั้น หรือ cache stale)
   - **ปัญหา UX/trust:** ลูกค้าที่เข้าตอนกลางคืน/เช้ามืดเห็น "0 บาท" = เว็บดูพัง → ต้องมี fallback แสดง "ราคาล่าสุด ณ [เวลา]" แทน 0 → **[งาน dev — backend/sre]**
   - อาจเป็น root cause เดียวกับ homepage ที่โชว์ US$0.00 (ต้องเช็คว่าตอนกลางวันหายไหม)
2. **`/silver-bar` กับ `/silver-price` เนื้อหาซ้ำกันเกือบ 100%** — title เดียวกัน, ราคาเดียวกัน, เนื้อเดียวกัน
   - = **duplicate content / keyword cannibalization** Google ไม่รู้จะจัดอันดับหน้าไหน
   - ตรงกับที่ Bail แนะใน content-plan §2: ต้องแยกบทบาท — `/silver-bar` = pillar (เนื้อหา+trust), `/silver-price` = tool page (ราคาอย่างเดียว) หรือ canonical ไปหน้าเดียว → **[architect ตัดสิน IA]**
3. **ไม่มี NFC messaging บนหน้าเลย** — differentiator #1 ที่ CMO/Bail ชูเป็นหัวหอก ยังไม่ปรากฏบนเว็บ → **[copywriter เพิ่ม]**
4. **เนื้อหาเดิมมีจุดเสี่ยง compliance** — พบประโยคทำนายราคา:
   - *"ราคาของเงินก็มีโอกาสปรับตัวสูงขึ้นในอนาคต"* → ผิด guardrail CMO (ห้ามทำนายราคา)
   - ไม่พบ disclaimer ความเสี่ยง/"ไม่ใช่ที่ปรึกษาการลงทุน" บนหน้า → ต้องเพิ่มตาม content-plan §6 → **[copywriter แก้ + เพิ่ม disclaimer]**
5. มี "องค์เทพเจ้าเสริมมงคล เงินแท้ 99.99%" (art toy) โผล่ในหน้าเงินแท่ง — pillar สายมูปนเข้ามา → ต้องตัดสินว่าอยู่ถูกที่ไหม (IA)
6. **ตัวเลข buy-back หน้าเว็บ vs ที่เจ้าของบอกไม่ตรง** — เจ้าของบอก "หัก 30 บาท/บาท" แต่ตารางหน้าเว็บ ขนาด 1 บาท: ขายออก 1,380 / ซื้อเข้า 1,032 = ส่วนต่าง 348 บาท → ต้อง reconcile ว่าเลขไหนจริง ก่อนเขียน content buy-back → **[ถามเจ้าของ]**
