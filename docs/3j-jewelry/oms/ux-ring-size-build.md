```
R0 ─▶ R1Pick ─┬─▶ R2Coin (สอนอยู่ในจอเดียว) ─┐
              └─▶ R1 (สอนบัตร) ─▶ R2 ─────────┴─▶ R3 ─┬─▶ R4A ─▶ R5A ─┐
                                                       └─▶ R4B ─▶ R5B ─┴─▶ R6 / R6Between / R6Out / G4

```

- **คนใหม่ทางเหรียญ 7 จอ** (R0 R1Pick R2Coin R3 R4 R5 R6) · **ทางบัตร 8 จอ** (เพิ่ม R1) · **คนกลับมา 5 จอ** (R0Return R3 R4 R5 R6)
- ตัวนับขั้น: R1Pick/R1/R2Coin/R2 = `01/03` · R3/R4A/R4B/R5A/R5B = `02/03` · R6 = `03/03` · **คนกลับมา (มีค่าเทียบที่ใช้ได้) = `01/02` ที่ R3-R5 และ `02/02` ที่ R6** (mockup R3 ขึ้น 02/03 ตายตัว — ต้องทำเป็น dynamic)
- ปลายทางย้อน/วัดใหม่ = คำนวณจาก state `{ ref, method, hasCalibration }` ไม่ผูกตายตัว:
  - R1Pick back → R0 (หรือ R0Return ถ้ามีผลล่าสุด) · R1 back → R1Pick · R2Coin back → R1Pick · R2 back → R1
  - R3 back → จอเทียบของ `ref` ปัจจุบัน (ถ้าเพิ่งเทียบ) หรือ R0Return (ถ้าข้ามขั้น 1)
  - G4 "วัดใหม่" → R5A ถ้า `method=A` · R5B ถ้า `method=B`
  - G5 → จอเทียบของ `ref` ที่เก็บไว้ (R2Coin/R2) **ข้าม R1Pick** พร้อมแถบ G5 · "เทียบใหม่" (ผู้ใช้ตั้งใจ) → R1Pick

- ทุกจอ = 1 history entry · Back ของเครื่องไม่ปิดหน้า · ค่าที่วัดแล้วไม่หายเมื่อย้อน (ตามสเปค §2/§6)

### 3.1 เวที: ห้ามวัตถุจำลอง (R2) · ใช้ SVG (R6) · เส้นไม่ปัด

**3.1.1 ไม่มีวัตถุจำลองบนเวที** (R2 บัตร · R2Coin · R5A · R5B) — เวที = ส่วนที่ปรับได้อย่างเดียว:

| เวที | DOM ที่อนุญาต | ห้าม |
|---|---|---|
| R2 | `<svg>` พื้นขาวเรียบ + เส้นแดง 2 เส้น (`<line>`) | กรอบ/ภาพ/สีพื้นของบัตร · ข้อความ "ภาพจำลอง" |
| R2Coin | `<svg>` + วงแดง 1 วง (`<circle fill="none">`) กลางเวที + ป้ายข้อความ "วางเหรียญตรงกลางวงนี้" (ล่างเวที) | วงกลมเหรียญสีเงิน/ทอง · ตัวเลข "10" |
| R5A | `<svg>` + วงแดงทึบ + กากบาท + ป้ายข้อความ "วางแหวนทับวงกลมแดง" | ภาพแหวนจำลอง |
| R5B | ไม้บรรทัด + เส้นอ่านค่า + ที่จับ | แถบกระดาษจำลอง · "ภาพจำลองกระดาษ…" |

เหตุ: ผู้ใช้ที่ยังไม่หยิบของจริงจะปรับให้ตรงของปลอม ค่า px/มม. ผิดแต่ดูสำเร็จ ไม่มีด่านจับ · **รูปประกอบ "ภาพสอน" (R1, R4A, R4B, ภาพตัวอย่างข้อ 4.2) วาดวัตถุได้** — ห้ามอยู่ในเวทีวัด · test: snapshot DOM เวที (ข้อ 6 B11)

**3.1.2 เวทีทุกจอวาดด้วย SVG — ห้าม `border` + `width`** (Tailwind preflight เปิด `box-sizing: border-box` ทั้งแอป → `border:3px` + `width:d` ทำให้เส้นผ่านศูนย์กลางด้านในเหลือ `d − 6 px` ≈ ผิด 2 มม. ที่เส้นรอบวงแหวน)

- วงเหรียญ: `<circle cx=W/2 cy=H/2 r={ coinMm*ppm/2 + sw/2 } fill="none" stroke="var(--rs-brand)" stroke-width={sw}/>` → **ขอบด้านในของเส้น = ขอบเหรียญ** (`2r − sw = coinMm × ppm`)
- เส้นบัตร: `<line x1=x x2=x y1=0 y2=H>` ที่ `x = cx ± (cardMm*ppm/2 + sw/2)` (ขอบในของเส้น = ขอบบัตร)
- `sw = CALIBRATION_STROKE_PX = 2` `ux` (เดิม 3 — เส้นหนาสร้างโซนตาบอด "เล็กไป" กว้าง 3 px/ด้าน เพราะเส้นอยู่นอกขอบวัตถุ) · สี `--rs-brand` (8.0:1 บนขาว)
- 🔴 **`viewBox` ต้องเท่ากับขนาด CSS px ที่วัดจริงของเวที (หรือไม่ใส่ viewBox และใช้ attribute px)** — 1 หน่วย SVG = 1 CSS px · ห้ามใช้ `viewBox` คงที่แล้ว `width:100%` (สเกลเพี้ยน = ค่าเทียบเพี้ยน) · ใช้ `ResizeObserver`/`getBoundingClientRect` วัดเวที
- **ห้ามปัด px เป็นจำนวนเต็ม** (mockup `Math.round` ทำให้กด −/+ บางครั้งไม่เห็นผลที่ DPR 1) · ใช้ค่าทศนิยม · `shape-rendering="geometricPrecision"`
- R5A วงทึบ: `<circle r={ d*ppm/2 }>` (d = ตัวเลขใน state เป็น มม.) · R5B: ขีด 1 มม. ที่ `y = top0 + mm*ppm`

**ก้าว −/+ และแถบเลื่อน** (`FineAdjuster` prop `stepMm`)

| วิธี | ก้าว | หมายเหตุ |
|---|---|---|
| บัตร | 0.1 มม. ของความกว้างบัตร (`Δppm = 0.1×ppm/53.98`) | ตามสเปค |
| เหรียญ | **0.05 มม.** ของเส้นผ่านศูนย์กลางเหรียญ (`Δppm = 0.05×ppm/26`) `ux` | ให้ผลต่อเส้นรอบวง ~0.1 มม. เท่าบัตร (0.1 มม. ที่เหรียญ ≈ 0.21 มม. หยาบกว่า 2 เท่า) |

## 6. เคสที่ QA ต้องผ่าน (รวม spec §7 + D1 + ข้อบังคับข้อ 3)

**ต้องถูกปฏิเสธ/ตักเตือน** (สเปค §7 เดิม 1–7 ยังใช้ทุกข้อ)
- A1 ซูม (scale ≠ 1) ที่ R2 · R2Coin · R5A · R5B → ปุ่มบล็อก + G1
- A2 `pxPerMm < 4.5 || > 7.5` → G3 **ทั้ง 2 `ref`** · G3 ไม่บันทึกค่าจนกดตัดสิน · ข้อความ G3 ตรง `ref`

1. **ความแม่น "±1 เบอร์" ทั้งสองวิธีเป็นมติเจ้าของ ไม่ใช่ผลวัด** — ถ้าทดสอบเครื่องจริงแล้วเหรียญเกิน ±1 ต้องกลับมาแก้ถ้อยคำ (ค่าอยู่ที่ `ACCURACY_*` จุดเดียว) · และมติชุดเดียวทำให้ R3 ไม่มีเหตุผลความแม่นช่วยเลือกวิธี A/B (ลบ pill แล้ว เหลือแค่ "ถ้ามีแหวนที่ใส่พอดี เลือกวิธีแรก") — ยืนยันกับเจ้าของที่ UAT ว่าตั้งใจ
