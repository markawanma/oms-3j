### 0.1 โครงข้อมูลที่หน้าจอต้องการ (ส่ง architect — brief §6)

- **ทรงพลอย** `gem_shape`: id · ชื่อ (กลม/ไข่/…) · เปิดใช้ — แอดมินเพิ่มได้
- **แบบแหวน** `ring_design`: id · จำนวนเม็ด · ชื่อแบบ (ลูกค้าเห็น เช่น "แบบ ก") · `shape_id` · ขนาด กว้าง×ยาว (มม.) · ราคาตัวเรือน (ทุกไซซ์) · รูปการ์ด · โมเดล 3D (ไม่บังคับ) · ตำแหน่งเม็ดสำหรับภาพ 2D · เปิด/ปิด · **ล็อก จำนวนเม็ด/ทรง/ขนาด หลังเคยออกรหัส** → "ทำสำเนาเป็นแบบใหม่"
- **ราคาพลอย** `gem_price`: พลอย × ทรง × ขนาด → ราคาต่อเม็ด (ห้ามซ้ำ ทรง+ขนาด ต่อพลอย · > 0)
- **พลอยที่ขึ้นให้ลูกค้าเลือกในแบบหนึ่ง** = พลอยเปิดขาย **และ** มีราคาตรง ทรง+ขนาด ของแบบนั้น (ไม่ตรง = ไม่โผล่เลย) · CZ ขาวขึ้นเสมอ (รวมในตัวเรือน)
- **รหัสสั่งทำ** ต้องผูก: แบบ (รวมทรง/ขนาด ณ ตอนนั้น) · พลอยทีละตำแหน่ง · ไซซ์ · ราคารายบรรทัด ณ ตอนสร้าง · เวลา
- **โมเดล 3D**: เม็ดในไฟล์ตั้งชื่อ `gem_1`…`gem_N` นับซ้าย→ขวาเมื่อมองตรงหน้าแหวน · ตรวจตอนอัปโหลดว่าครบ N · กำหนดรูปแบบไฟล์ + ขนาดสูงสุด (โหลดบน 4G ได้) `[ต้องยืนยัน — architect]`

## 5. รูปสรุป (`SummaryImage` 1080×1920)

ลำดับ: โลโก้ + "ราคา ณ วันที่" → เส้นแดง → **"แถว N เม็ด · แบบ x (พลอย ทรง ขนาด)"** → แผนภาพเม็ดพร้อมเลข → "ตำแหน่งนับจากซ้ายไปขวา เมื่อมองตรงหน้าแหวน" → ชื่อพลอยทีละตำแหน่ง (2 คอลัมน์) → กล่อง ไซซ์ + ราคารายบรรทัด + รวม → รหัส + QR (รหัสล้วน ไม่ใช่ URL · ขอบว่าง · ไม่มีโลโก้ทับ) + LINE @3jjewelry → กล่อง "ยังไม่ใช่การสั่งซื้อ… · pre-order ≤ 21 วัน · CZ ไม่ใช่เพชร"
- ตัวหนังสือเล็กสุด **≥ 32–34px** (LINE บีบรูป)
- **ทุกส่วน `flex: none`** (ห้ามหด) — 5 เม็ด ≈ 1,770px · 7 เม็ด ≈ 1,890px · เกิน 1920 ให้ยืดความสูงรูป ห้ามบีบ
- เป็น `<img>` จริง (ไม่ใช่ `blob:`/canvas) เพื่อให้กดค้างบันทึกใน LINE webview ได้
