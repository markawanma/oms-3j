### 0.1 รายละเอียดเทียบจอด้วยเหรียญ (ใหม่ — spec ยังไม่มี)

- **ขนาดอ้างอิง:** `COIN_10THB_DIAMETER_MM = 26` ✅ ตรวจแล้ว 24 ต.ค. — เหรียญ 10 บาทหมุนเวียน (สองโลหะ) Ø 26 มม. หนา ~2–2.2 มม. หนัก 8.5 ก. ใช้ขนาดเดียวทุกรุ่นตั้งแต่ปี 2531 (รุ่น ร.9 เดิม · ร.9 ปี 2551 · ร.10 ปี 2561) เปลี่ยนแค่ลาย · แหล่ง: Wikipedia "Ten-baht coin", Numista #11369 / #22038, uCoin 2018–2022 (ยังไม่ใช่เอกสารกรมธนารักษ์โดยตรง) · เหรียญที่ระลึกบางรุ่นอาจต่าง → บนจอบอกให้ใช้เหรียญ 10 บาทที่ใช้ทั่วไป
- **เวที (`CoinCalibrationStage`):** วงกลมเดียวอยู่**กลาง**เวที · เส้นแดงหนา 3px วาด **ด้านนอก** เส้นผ่านศูนย์กลาง (ขอบในของเส้น = ขอบเหรียญ) → พอดี = เห็นวงแดงล้อมเหรียญรอบวงเท่ากัน · เล็กไป = เหรียญทับเส้น · ใหญ่ไป = เห็นช่องขาว
- **คำนวณ:** `pxPerMm = diameterPx / COIN_10THB_DIAMETER_MM` → ได้ค่าชนิดเดียวกับบัตร ใช้ต่อใน R3–R6 เหมือนเดิมทุกอย่าง
- **ปุ่ม −/+:** ทีละ ≈ 0.1 มม. ของเส้นผ่านศูนย์กลางเหรียญ · ช่วง/ค่าเริ่ม/G1/G3/G5 ใช้ชุดเดียวกับบัตร (6.0 · ปกติ 4.5–7.5 · แถบเลื่อน 3.0–9.0)
- **ความแม่น:** เหรียญเล็กกว่าบัตรราวครึ่ง → พลาด 1px ≈ 0.35 มม. ที่เส้นรอบวงแหวน (บัตร ≈ 0.17 มม.) ยังต่ำกว่าเกณฑ์ครึ่งเบอร์ (0.25 มม. ของกฎปัด) จึงใช้ได้ · บนจอเขียนว่า "แม่นใกล้เคียงกัน · ใช้บัตรจะแม่นกว่าเล็กน้อย" (ไม่ใช้คำว่า "แม่นยำ")
- **บันทึกค่า:** เพิ่ม field `ref: "card" | "coin"` ในค่าเทียบจอ → `{ pxPerMm, ref, dpr, screenShort, screenLong, savedAt, version }` (เพิ่ม `version`)
- **G3 ข้อความ:** "ใช้บัตรขนาดมาตรฐาน" → เปลี่ยนตาม `ref`: บัตร = "ใช้บัตรขนาดมาตรฐาน" · เหรียญ = "ใช้เหรียญ 10 บาท วางนอนราบกลางวง"
- **สลับวิธี:** R1/R2 มีลิงก์ "ใช้เหรียญ 10 บาทแทน" · R1Coin/R2Coin มีลิงก์ "ใช้บัตรแทน"
- **event เพิ่ม/แก้ (spec §10):** `calib_ref_pick` (ref: coin/card) · `calib_view` + `calib_done` เพิ่มค่า `ref`

## 1. วิธีดูไฟล์

- **ดีที่สุด:** เปิดลิงก์ canvas (เจ้าของต้องกด Share ให้ทีม dev ก่อน) — จอที่มีป้าย "(กดลองได้)" ลองเลื่อน/กดได้จริง
- **ไฟล์ใน `screens/`:** เปิดในเบราว์เซอร์ได้ แต่ `{{...}}` ต้องใช้ runtime ของ canvas จึงจะทำงาน (กระทบ R2, R2Coin, R5A, R5B)
- `screens/canvas.json` = ชื่อหน้า · ขนาดเฟรม · ตำแหน่งบน canvas
- `assets/3j-logo.png` (โลโก้เต็ม พื้นใส — R0, การ์ดแชร์) · `assets/3j-mark.png` (สัญลักษณ์แหวน — มุมขวาบนทุกจอ)
- 🔴 **mockup ใช้ 6 px/มม. ตายตัว** ขนาดบนจอจึงไม่ใช่ขนาดจริง — ของจริงต้องคำนวณจากค่าเทียบจอ

### 3.2 ตัวอักษร
- หัวข้อ/ตัวเลข: **Noto Serif Thai** 500/600/700 · เนื้อหา: **IBM Plex Sans Thai** 400/500/600 · fallback `system-ui, sans-serif`
- line-height ≥ 1.6 (หัวข้อ 1.35–1.4)
- H1 25–30px · คำสั่งใต้เวที 18px · เนื้อหา 15–16px · ตัวรอง ≥ 13px · ตัวเลขผล 100–104px
- 🔴 ถ้าใช้ฟอนต์/โทเคน `--gq-*` ของ gem quiz แทน → เจ้าของต้องตัดสิน (spec §11) · mockup นี้ออกแบบใหม่ทับ

### 3.3 ขนาด / รูปทรง
- เฟรม 390×844 · ขอบจอ 22px · เวทีวัดสูง 380px เต็มความกว้าง
- ปุ่มหลัก ≥ 56px มุม 16px · ปุ่ม −/+ **56×56** · ลิงก์/พื้นที่แตะ ≥ 40–44px
- การ์ด มุม 20–22px · ป้าย 99px
- ปุ่มล่างจอใช้ `dvh` + `safe-area-inset-bottom` (ห้าม `100vh`)

## 6. กติกาพฤติกรรม (สรุป — รายละเอียดใน spec)

- เบอร์ = เส้นรอบวงด้านใน (มม.) · ปัด 0.1 ก่อน → `rec = ceil(c − 0.25)` · ระหว่างเบอร์เมื่อ |c − เบอร์ใกล้สุด| > 0.25
- G1 ซูม (`visualViewport.scale` ≠ 1 ±1%) = บล็อกปุ่ม · **ห้ามปิด pinch-zoom ทั้งหน้า** · `touch-action: none` เฉพาะเวที
- G3 ค่าเทียบนอก 4.5–7.5 px/มม. = เตือนไม่ห้าม · G4 เส้นรอบวงนอก 40–75 มม. = ไม่ขึ้นผล · G5 DPR/ขนาดจอเปลี่ยน = ห้ามใช้ค่าเก่าเงียบๆ
- เก็บค่าเป็น มม. ใน state แปลง px ตอนวาด · localStorage ทุกจุดใน try/catch · ค่าเสีย/นอกช่วง = ทิ้ง
- LINE: `oaMessage` กับ `@3jjewelry` (ยังไม่ทดสอบ — Q4) · ทางสำรอง "คัดลอกข้อความ" + "เปิดแชท LINE" (`https://lin.ee/PzIJl6j`)
