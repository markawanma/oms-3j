# ร่าง LINE OA Broadcast — Win-back "at-risk" (1,012 คน)

> เขียนโดย copywriter (Maz Kanata) · อ้างอิง `campaign-plan-99-winback.md` (CMO) และ
> `discount-policy-99.md` (CFO) เพื่อคุม voice/กติกาให้ต่อเนื่องกับชุด 9.9 · **ร่างเฉยๆ ยังไม่ส่ง**
>
> **บริบทกลุ่มนี้ (สำคัญ ต้องรู้ก่อนอ่านสคริปต์):** at-risk = ซื้อครั้งสุดท้าย >90 วัน หลัง backfill
> ข้อมูล 8 เดือน (ม.ค.–ส.ค. 2026) ส่วนใหญ่คือคนที่ซื้อช่วง **ต้นปี (ม.ค.–เม.ย. = ฤดูเงินแท่ง/ตรุษจีน)**
> แล้วเงียบไป **ไม่ใช่ลูกค้าเก่าหลายปี** — กลุ่มนี้ปนทั้งสาย **เงินแท่งลงทุน** กับสาย
> **เครื่องประดับ 925** เราแยกไม่ได้ว่าใครเป็นใคร (ไม่มี line-item ต่อ SKU) จึงต้องส่ง 3
> มุมคู่ขนานแล้วให้ลูกค้าเลือกเอง หรือถ้าระบบ tag/narrowcast ไม่พร้อม ให้ใช้เวอร์ชันกลาง (#3)
> เป็น broadcast วงกว้างแทน
>
> **ข้อจำกัดที่คุมการเขียนทุกเวอร์ชัน:**
> 1. ห้ามอ้างชื่อลูกค้า/ยอดซื้อ/สินค้าที่เคยซื้อรายคน — ยังไม่มี personalization layer
> 2. ห้ามสัญญาลดราคาเงินแท่ง (`discount-policy-99.md` ข้อ 2: NO DISCOUNT เด็ดขาด)
> 3. เครื่องประดับ 925 — **ไม่ใส่ตัวเลข % ส่วนลดในสคริปต์นี้เลย** เพราะยังไม่มีบรีฟ/เพดานเฉพาะ
>    win-back จาก CFO (เพดานที่มีอยู่ตอนนี้ผูกกับ 9.9 เท่านั้น) ใช้ exclusivity/perk/reconnect แทน
> 4. โทน: อบอุ่น น่าเชื่อถือ ไม่ spammy — "เราคิดถึงคุณ" ไม่ใช่ "กลับมาซื้อสิ"
> 5. เขียนให้ใช้ได้ทั้งกรณี narrowcast เฉพาะกลุ่ม at-risk และ broadcast วงกว้าง (ไม่รู้สถานะ
>    tag ของ LINE OA จนกว่าเจ้าของยืนยัน)

## 1) เวอร์ชัน A — สาย investment / เงินแท่ง

**ใช้เมื่อ:** narrowcast ได้ และรู้ว่าคนนี้เคยซื้อ/สนใจเงินแท่ง (หรือส่งคู่กับ B แบบ A/B ให้ทั้งกลุ่มเลือกเอง)

```
เงินแท่งของคุณ วันนี้ราคาไปถึงไหนแล้ว เช็คให้หน่อยไหมคะ 🪙

ราคาเงินขยับทุกวันตามตลาดโลก — ช่วงนี้ [ทิศทางราคา: ต้องดึง realtime ก่อนส่งจริง]
เราอัปเดตราคาแบบเรียลไทม์ทุกแท่งค่ะ พร้อม NFC ให้สแกนตรวจได้เองว่าเป็นแท่งจริง
และรับซื้อคืนโปร่งใส (หัก 30 บาท/บาท เท่านั้น ไม่มีเงื่อนไขซ่อน)

ถ้ากำลังมองจะเก็บเพิ่มหรืออยากรู้ราคาวันนี้ กดรับสิทธิ์ไว้ได้เลยค่ะ
แอดมินจะแจ้งราคาให้ก่อนใคร ไม่พลาดจังหวะ
(การกดปุ่ม = ยินยอมให้ 3J ส่งข่าวสารราคาเงิน/สิทธิพิเศษผ่าน LINE นี้ค่ะ)

[ปุ่ม CTA: กดรับสิทธิ์ อัปเดตราคาเงิน]
```

**หมายเหตุ:** ไม่มีคำว่า "ลด" ตลอดทั้งข้อความ — มุมขายคือ "โปร่งใส + เช็คได้ + ไม่พลาดจังหวะ"
ไม่ใช่ราคาถูก ตรงกับ policy CFO ข้อ 2 เป๊ะ

## 2) เวอร์ชัน B — สายเครื่องประดับ 925

**ใช้เมื่อ:** narrowcast ได้ และคาดว่าคนนี้ซื้อเครื่องประดับ (ไม่ใช่เงินแท่ง) หรือส่งคู่กับ A

```
เราคิดถึงคุณค่ะ 🤍

หายไปพักใหญ่เลยนะคะ ระหว่างนี้ 3J มีคอลเลกชันใหม่เข้ามาหลายชิ้น
ยังขึ้นรูปด้วยมือช่างทุกชิ้นเหมือนเดิม — เงินแท้ 925 ที่เราตั้งใจมากว่า 30 ปี

อยากชวนคุณกลับมาดูอีกครั้งค่ะ ไม่ได้เร่งให้ซื้อนะคะ แค่อยากให้คุณเห็นก่อนใคร
(การกดปุ่ม = ยินยอมให้ 3J ส่งสิทธิ์พิเศษเฉพาะคุณผ่าน LINE นี้ค่ะ)

[ปุ่ม CTA: กดรับสิทธิ์ดูคอลเลกชันใหม่]
```

**หมายเหตุ:** ตั้งใจเขียนให้ soft ที่สุดในชุดนี้ ("ไม่ได้เร่งให้ซื้อนะคะ") เพราะกลุ่มนี้เงียบไปแล้ว
ยิงแรงจะยิ่งดันให้ unsub — ตรงกับกติกาเหล็กของ brief (ไม่ขายแข็ง)

## 3) เวอร์ชัน C — มุมกลาง ใช้ได้ทั้งกลุ่ม (fallback ถ้า tag/narrowcast ไม่ได้)

**ใช้เมื่อ:** ไม่รู้ว่าใครเป็นสายไหน หรือ LINE OA ทำ narrowcast ไม่ได้ → ส่งเป็น broadcast เดียวถึงทั้ง 1,012 คน

```
นานแล้วนะคะที่ไม่ได้เจอกัน ✨

3J ยังอยู่ตรงนี้เหมือนเดิมค่ะ — ไม่ว่าจะเงินแท้ 925 งานฝีมือ หรือเงินแท่งสำหรับเก็บ
เราอยากดูแลคุณในฐานะลูกค้าคนพิเศษของเรา ไม่ใช่ลูกค้าทั่วไป

กดรับสิทธิ์ไว้ค่ะ แล้วพี่จะดูแลเป็นพิเศษ — ให้ดูของก่อนใคร ถามอะไรก็ทักตรงมาได้เลย
(การกดปุ่ม = ยินยอมให้ 3J ส่งสิทธิ์พิเศษเฉพาะคุณผ่าน LINE นี้ค่ะ)

[ปุ่ม CTA: กดรับสิทธิ์ กลับมาเป็นคนพิเศษของเรา]
```

**หมายเหตุ:** "สิทธิพิเศษ" ในนี้ = ได้ดูก่อน/บริการพิเศษ (แอดมินดูแลเป็นพิเศษ) **ไม่ใช่ส่วนลด**
ตรงตามที่ brief กำหนด ("สิทธิพิเศษลูกค้าเก่า ไม่ใช่ลดราคา")

## 4) เวอร์ชัน D — Follow-up nudge (ส่งซ้ำ 4–5 วันให้คนที่ยังไม่กด)

**ใช้เมื่อ:** ส่งตามหลังเวอร์ชัน A/B/C ไปแล้ว ~4–5 วัน ยิงเฉพาะคนยังไม่คลิก (ถ้า tag ได้)
หรือข้ามได้เลยถ้า narrowcast ไม่ได้ (อย่ายิงซ้ำทั้ง broadcast — เสี่ยง unsub)

```
แค่แวะมาทักอีกครั้งค่ะ 🙏

ถ้ายังไม่พร้อมตอนนี้ก็ไม่เป็นไรเลยค่ะ แชทนี้เปิดไว้เสมอ
เวลาไหนอยากดูของ ถามราคาเงิน หรือแค่ทักคุยกัน 3J ยินดีค่ะ

[ปุ่ม CTA: กดรับสิทธิ์ (ยังเปิดอยู่)]
```

**หมายเหตุ:** สั้นและเบาที่สุดในชุด — เป้าคือรักษาความสัมพันธ์ ไม่ใช่ปิดยอด ถ้า block/unsub
เพิ่มผิดปกติหลังส่งเวอร์ชันนี้ ให้หยุดและทบทวน (ตาม metric เดิมของแผน CMO: block/unsub < 2%/broadcast)

## ธงเตือน

1. **เวอร์ชัน A (เงินแท่ง) — ต้อง fill ราคา realtime ก่อนส่งจริงทุกครั้ง** ห้ามใส่ตัวเลขราคา/ทิศทางลอยๆ
   ล่วงหน้า เพราะราคาผันผวนรายวัน (ตรงกับกติกาเหล็ก: ราคาเงินต้องมี disclaimer วันที่/เวลา) — ดึงจาก
   ระบบราคา realtime (Google Sheet → Wix) ตอนใกล้ยิงจริงเท่านั้น
2. **ไม่มีเวอร์ชันไหนมีตัวเลข % ส่วนลด** — ไม่ต้องผ่าน CFO ก่อนส่ง (safe ตาม policy ที่มีอยู่)
   **ยกเว้น** ถ้าอนาคตอยากแนบ perk แบบมีต้นทุน (เช่น ฟรีค่าส่งมีประกันสำหรับเงินแท่ง ~฿50–100 —
   มี precedent ผ่านแล้วใน `discount-policy-99.md` ข้อ 2) ให้ยืนยันกับ COO ก่อนว่าพร้อมให้บริการจริง
   แล้วค่อยเพิ่มเป็นบรรทัดในเวอร์ชัน A
3. **เวอร์ชัน D (follow-up)** — ส่งเฉพาะกรณี tag คนคลิกได้ ถ้า broadcast วงกว้างอย่างเดียว
   ห้ามส่งซ้ำเวอร์ชัน C อีกรอบในช่วงเวลาสั้นๆ (เสี่ยง spam) — ใช้ D แทนเพราะโทนเบากว่าเยอะ
4. **Timing ซ้อนกับแผน 9.9** — at-risk 1,012 คน เป็นคนละกลุ่มกับ champion/loyal/new ในแผน CMO
   (RFM segment แยกกันอยู่แล้ว ไม่น่าซ้ำ) แต่ **ต้องเช็คกับ CMO ก่อนว่าจะยิง win-back ชุดนี้
   คู่ขนานกับ 9.9 หรือเว้นจังหวะ** เพื่อไม่ให้ quota/ความถี่รวมของบัญชี LINE OA เกินที่วางแผนไว้
5. **PDPA consent line** — ทุกเวอร์ชันมีบรรทัดยินยอมกำกับปุ่ม CTA ตามแนวทางเดิมของชุด 9.9
   (`broadcast-scripts-99.md`) — ก่อนส่งจริงให้เช็คว่าถ้อยคำ consent ตรงกับ privacy policy ปัจจุบันของร้าน

## วัตถุดิบที่ยังขาด

1. **สถานะ tag/narrowcast ของ LINE OA** — ยังไม่ยืนยัน (ปัญหาเดิมจาก `campaign-plan-99-winback.md`)
   กำหนดว่าจะส่ง A+B แยกกลุ่ม หรือใช้ C ตัวเดียวแบบ broadcast กว้าง
2. **ราคาเงินแท่ง realtime + ทิศทางราคา ณ วันที่จะยิงจริง** — ยังใส่ไม่ได้ล่วงหน้า (เวอร์ชัน A)
3. **Mapping รายคนว่าใครเคยซื้อเงินแท่ง vs เครื่องประดับ** — ถ้ามี (แม้หยาบๆ) จะเลือกส่ง A หรือ B
   ให้ตรงกลุ่มได้แทนที่จะส่งทั้งคู่หรือใช้ C คลุม — ตอนนี้ไม่มี line-item ต่อ SKU (ปัญหาเดิมที่ระบุใน
   แผน CMO) จึงเขียนแบบ generic ไว้ก่อน
4. **Timeline ยิงจริง** — ยังไม่มีวันที่ชัดจาก CMO ว่าจะยิงชุดนี้ก่อน/หลัง/คู่ขนานกับ 9.9 (ดูธงเตือนข้อ 4)
