## 3. เอาแหวน ฿1,590 เข้าไลฟ์ที่ขายของ 300–400 ยังไงไม่ให้พัง

หลักการ: **ไลฟ์เป็นที่โชว์ ไม่ใช่ที่ปิดการขาย**

1. **ห้ามขึ้นตะกร้าในไลฟ์รอบทดสอบ** — ขึ้นแล้วไม่มีคนกดต่อหน้าคนดู = social proof ติดลบทันที และ dead air ทำ conversion ของ SKU ราคาถูกทั้งคืนตกตาม
2. **วางเวลา 21:40–21:50 ก่อนพีค 22 น. ไม่ใช่ทับพีค** — ใช้ช่วงที่คนกำลังทยอยเข้าให้เป็นเนื้อหาที่ทำให้คนอยู่รอถึง 22 น. แหวนกลายเป็นตัวดึง retention ไม่ใช่ตัวแย่งยอด
3. **เปลี่ยนเฟรมจาก "ของแพง" เป็น "ของที่ไม่ได้ขายในไลฟ์"** — พูดตรงว่า *"วงนี้ไม่ได้ขายในนี้นะคะ ทำตามจำนวน ใครสนใจพิมพ์เส้นทาง เดี๋ยวคุยกันในไลน์"* ความหายากอธิบายราคาแทนเรา โดยไม่ต้องแตะเรื่องเนื้อเงินเลย
4. **บทพูดห้ามมีคำว่า กรัม / น้ำหนัก / ราคาเงิน** — เล่าเป็น: ใครใส่แล้วเปลี่ยนอะไร · ช่างฝังมือ · พลอยไม่ซ้ำวง · พระพิฆเนศคือผู้เปิดทางในสิ่งที่กำลังจะเริ่ม
   **ห้ามพูดว่าใส่แล้วรวย / ปลุกเสก ถ้าไม่ได้ทำจริง** — เสี่ยงทั้งกฎหมายโฆษณาและดราม่า
5. **ทำให้เป็น segment ประจำที่มีชื่อ** — คนดูจะจำเวลา และเราได้ waitlist ทุกคืนโดยไม่กระทบตะกร้าหลัก

> **บริบทเพิ่มจาก Tech Lead:** ตัวเรือนเป็นมินิมอลตั้งใจ ไม่มีลายช้าง/สัญลักษณ์เทพเลย → วางข้างแหวนพลอย 3-4 ร้อยในไลฟ์แล้วหน้าตาใกล้เคียงกัน ส่วนต่าง ฿1,200 แบกอยู่บนเรื่องเล่า การ์ด กล่อง และวิธีส่งมอบล้วนๆ ข้อ 3 กับ 4 ข้างบนจึงเป็นหัวใจ ไม่ใช่ลูกเล่น

## 5. ความเสี่ยงที่ CMO เห็น

1. **537 ใน 561 คนคือคนซื้อเงินแท่ง = mindset นักเก็บมูลค่า ไม่ใช่นักซื้อเครื่องประดับ** — audience นี้ "จ่ายไหว" แต่ไม่ใช่ "อยากได้" ความน่าจะเป็นที่ conversion ต่ำกว่าคาดสูงมาก จึงต้องมี kill gate ที่ D7 และเตรียม audience สำรอง (คนซื้อเครื่องประดับเดิม + คนดูไลฟ์) ไว้ตั้งแต่ต้น
2. **การยิง 528 คนมีต้นทุนแฝง** — พวกเขาคือคนที่เราต้องใช้ในวันที่ราคาเงินกลับมา ถ้าบล็อกไลน์เพราะรำคาญ เราเสียสินทรัพย์ที่มูลค่าสูงกว่ากำไรแหวนหลายเท่า จึงต้องขึ้นต้นด้วย "ขอให้ดูก่อน" ไม่ใช่ "ซื้อเลย"
3. **Brand debt** — ชื่อ Markawan อยู่บนกล่องแต่ไม่มีที่ให้คนไปต่อ ลูกค้าเสิร์ชแล้วไม่เจอ = ความน่าเชื่อถือหาย ขั้นต่ำต้องมี 1 landing page + rich menu ใน LINE ก่อนส่งของล็อตแรก
4. **พลอยธรรมชาติสีไม่เท่ากัน** = ต้นเหตุ return ที่พบบ่อยสุด ต้อง disclose ในข้อความ (ใส่ไว้แล้ว) + policy เคลมชัดจาก COO — ส่วนความเสี่ยง "ลูกค้าบีบวงเองแล้วพลอยหลุด" ลดลงมากแล้วหลังเคาะว่าช่างปรับไซส์ให้ก่อนส่ง (ไม่ต้องทำคลิปสอนปรับวงอีก เปลี่ยนเป็นข้อความว่าอยากปรับให้ส่งกลับร้าน)
5. **เวลาส่งคือความเสี่ยงใหญ่สุด** — ลูกค้ากลุ่มนี้จ่ายก้อนใหญ่และปากต่อปากแรง ส่งช้า 1 ครั้งเสียมากกว่ากำไรทั้งล็อต
