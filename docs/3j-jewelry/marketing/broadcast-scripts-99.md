**รูปแบบ:** ทักเป็นรายบุคคลในแชท 1:1 (ไม่ใช่ broadcast) — โทนส่วนตัวสุด รู้จักเขาจริง

```

ถ้าสนใจ ทักบอกพี่ในแชทนี้ได้เลยนะคะ พี่จะกันชิ้นไว้ให้เป็นพิเศษ พร้อม [perk: สลักชื่อฟรี/กล่องพิเศษ — เลือกอย่างที่ต้นทุนต่ำ ไม่ใช่ลดราคา]
```

## ธงเตือน

1. **ส่วนลด % — ✅ CFO เคาะแล้ว** (`discount-policy-99.md`): **LINE ไม่ใส่ % ลดเลย** (ช่องกำไร) → placeholder ถอดออกหมดแล้ว ใช้ exclusivity/perk แทน · ถ้าจะมีตัวเลขลด ให้ไปไว้ที่ **TikTok/Shopee เท่านั้น ≤5% หรือมูลค่าบาทคงที่ (เช่น ฿50)** และเลขสุดท้ายรอ **ต้นทุน hero SKU + fee จริง** (กรอกก่อน 1 ก.ย.) · เครื่องประดับที่ margin จริง (กรอกต้นทุนแล้ว) อาจเปิดเพดานได้ถึง 25–35%
2. **เงินแท่ง 999** — ตั้งใจไม่ใส่ในชุดนี้ เพราะแผน CMO ระบุว่า silver-bar segment ดึงไม่ได้ตอนนี้ (ต้อง line-item SKU) และมีแผนแยกไปช่วง post-sale 11–12 ก.ย. "มุมลงทุน" ต่างหาก — ถ้าจะดันแท่งในชุดนี้ด้วย ต้องบรีฟใหม่ + ย้ำห้ามใช้คำว่า "ลด" เด็ดขาด ใช้มุมลงทุน/buy-back/NFC เท่านั้น
3. **จำนวนคงเหลือ (ข้อ 6)** — ต้องเป็นเลขจริง ไม่ประดิษฐ์
4. **ปุ่ม CTA / template message** — ร่างนี้เขียนแบบมี "ปุ่ม" (LINE Flex/template) เพราะช่วย tag click ได้ตามแผน หากบัญชี LINE OA ปัจจุบันทำ template message ไม่ได้ ให้เปลี่ยนเป็นลิงก์ธรรมดาแทน (จะ tag click แม่นน้อยลง — ต้องพึ่งคำสั่ง "พิมพ์รับสิทธิ์99" แทน)

## วัตถุดิบที่ยังขาด (ทำให้บางข้อความยังเป็น generic)

1. **ชื่อ/ราคา hero SKU 9.9 จริง** — ทุกข้อความยังเป็น `[ชื่อ hero SKU]` เพราะยังไม่ได้รับ list ชิ้นที่จะขาย 9.9
2. **รายชื่อ + SKU ที่แต่ละ champion คนเคยซื้อ/สนใจ** — จะทำให้ข้อความ 1:1 (ข้อ 2) แม่นระดับ personal จริง ไม่ใช่แค่ "ทักด้วยชื่อ"
3. **Mapping SKU→ชิ้นเข้าชุด** (เช่น สร้อยเส้นนี้ คู่กับต่างหูรุ่นไหน) — ตอนนี้ข้อความข้อ 4 ใช้คำกลาง "ชิ้นเข้าชุดกับสิ่งที่คุณมี" แทน
4. ~~เพดานส่วนลด % จาก CFO~~ — ✅ เคาะแล้ว (LINE=ไม่ลด, placeholder ถอดออกแล้ว) ดู `discount-policy-99.md`
5. **ลิงก์/แฮนเดิล TikTok live วันที่ 9 ก.ย.** — ยังไม่มีให้ใส่ในข้อ 5
6. **จำนวนสต็อกคงเหลือจริงช่วงค่ำ 9 ก.ย.** — ต้องเช็คหน้างานวันจริง ใส่ไม่ได้ล่วงหน้า
