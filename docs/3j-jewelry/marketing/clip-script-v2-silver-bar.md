## 1. Hook 3 แบบให้เลือก (0-3 วิ)

| # | hook_line (คำต่อคำ) | มุมที่เล่น | คนดูที่จะหยุด |
|---|---|---|---|
| **A — แนะนำ** (contrarian/challenge) | "ร้านขายเงินแท่ง... กล้าชั่งให้ลูกค้าดูสดๆ กันกี่ร้านคะ" | ท้าทายธรรมเนียมวงการตรงๆ (ไม่พาดพิงร้านไหนเป็นชื่อ) — ตรงกับธีมที่โจทย์ให้มา "ร้านไหนกล้าชั่งให้ดูบ้าง" | คนที่เคยลังเลซื้อเงินแท่งเพราะไม่มั่นใจเรื่องน้ำหนัก/ราคา จะรู้สึกว่าเจอคำถามที่ตัวเองก็คาใจอยู่พอดี |
| B (curiosity/price) | "1 บาททองเงินแบบนี้... วันนี้ราคาเท่าไหร่ มาดูกันชัดๆ ค่ะ" | ชวนดูตรงๆ ไม่มีดราม่า เน้นความอยากรู้ตัวเลขจริง | สายเก็บ/ลงทุนเงินแท่งที่ตามราคาอยู่แล้ว อยากเห็นร้านไหนอัปเดตราคาไว จับต้องได้ |
| C (proof-first, ไม่มีเสียงพูดเปิด) | ภาพเปิดคลิป: เข็มตาชั่งค่อยๆ นิ่ง + หน้าจอราคาเลื่อนขึ้น ตัดเข้าเสียง "แท่งนี้... หนักเท่านี้ ราคาวันนี้เท่านี้ค่ะ" | ให้ภาพพิสูจน์ก่อนคำพูด สั้น กระชับ ไม่อารัมภบท | คนที่กำลังจะตัดสินใจซื้ออยู่แล้ว ต้องการความมั่นใจเร็วที่สุด ไม่ชอบคลิปที่มีคำนำยาว |

**แนะนำถ่ายก่อน: Hook A** — เพราะ (1) ตรงกับธีมที่ CMO/เจ้าของวางไว้เป๊ะ ไม่ต้องตีความใหม่ (2) เป็น pattern-interrupt ที่แรงกว่า B/C เพราะตั้งคำถามท้าทายวงการ ทำให้คนคอมเมนต์ต่อเองว่า "ร้านฉันก็ไม่เคยชั่งให้ดู" ซึ่งดันทั้ง comments และ saves (3) ยังนำไปสู่ proof shot (ตาชั่ง+ราคาสด) ได้ลื่นเหมือน Hook C แต่มี hook แรงกว่าตรงเปิดฉาก

## 6. CTA

พูด (close): "อยากเช็คราคาวันไหนก็เปิดเว็บดูได้เลย หรือทักแชท/LINE มาคุยกับเราได้ตลอดค่ะ"

- **หลัก:** เช็คราคาสดที่ `3jthailand.com` (สอดคล้อง "ราคาเดียวทุกคน ทุกช่องทาง ไม่มีราคาลับ")
- **รอง:** ทักแชท/LINE สั่งซื้อ — **ห้ามพูด/โชว์ราคาส่งหรือราคาต่อรองใน DM ในคลิปนี้** (นอกขอบเขต §2.1)

## 7. Do/Don't หน้ากอง (เช็คก่อนกดอัด — อ้างอิง §2.1)

**Do**
- [ ] เปิดหน้า `/silver-price` จริงบนจอ ก่อนอัด ให้ตรงกับราคาป้ายแท่งที่จะชั่งวันนั้น
- [ ] ชั่งแท่งเงินสดหน้ากล้อง ให้ตัวเลขบนตาชั่งอยู่ในเฟรมจริง ไม่ตัดต่อใส่ตัวเลขทีหลัง
- [ ] พูดแค่: ราคาเนื้อเงินวันนี้ / น้ำหนักจริง / ราคาขายวันนี้ / "ส่วนต่างคือค่าผลิต ค่าใบรับรอง ค่าดำเนินการ" (เชิงคุณภาพเท่านั้น) / "ราคาเดียวกันทุกคน ทุกช่องทาง" / "ราคาขยับทุกวันตามตลาดโลก"
- [ ] ใส่ super "ราคา ณ วันที่..." ทุกเฟรมที่มีตัวเลข
- [ ] **ชั่งเฉพาะเงินแท่งเท่านั้น** — ห้ามหยิบแหวน/กำไล/เครื่องประดับ 925 มาอยู่ในคลิปเดียวกันเด็ดขาด

**Don't**
- [ ] ❌ ห้ามพูดตัวเลข % premium / % กำไร / margin / ค่าผลิตเป็นตัวเลขบาท
- [ ] ❌ ห้ามพูดราคาที่ร้านซื้อเข้า / ชื่อโรงหลอม-ซัพพลายเออร์ / ปริมาณสั่งผลิต
- [ ] ❌ ห้ามพูด "ราคานี้ถึงสิ้นเดือน" / "การันตีราคา"
- [ ] ❌ ห้ามเทียบราคาร้านอื่นเป็นตัวเลข (Hook A ท้าทาย "กี่ร้าน" ได้ แต่ห้ามระบุชื่อหรือราคาร้านคู่แข่ง)
- [ ] ❌ ห้ามพูดเชิงชวนลงทุน/ผลตอบแทน ("ซื้อไว้ได้กำไรแน่", "ลงทุนคุ้ม")
- [ ] ❌ **ห้ามเอาเครื่องประดับ 925 มาชั่งในคลิปเดียวกัน** — ถ้าอยากทำคลิปคู่กันสำหรับ 925 ต้องแยกเป็นคลิปอื่นและเปลี่ยนมุมเป็น "ขั้นตอนการผลิต" ตามที่ CFO สั่งไว้ (§2.2)
- [ ] ❌ ห้ามพูดคำว่า "หัก x บาท/บาท" หรือตัวเลขรับซื้อคืนใดๆ ในคลิปนี้ (เป็นเรื่องของ V3 คนละคลิป)

## วัตถุดิบที่ยังขาด

1. **ขนาดแท่งที่จะใช้ถ่าย** — ต้องเลือกว่าจะโชว์ขนาดไหน (0.5 บาท / 1 บาท / 10 บาท / 1kg) ให้เหมาะกับงบภาพ (แท่งเล็กชั่งง่ายกว่าแต่ตัวเลขน้อยกว่า, แท่งใหญ่ภาพอิมแพคกว่าแต่ต้องเช็คสต็อกพร้อม) — ขอ COO/หน้าร้านยืนยันว่าวันถ่ายมีขนาดไหนพร้อมโชว์
2. **ใครพูดหน้ากล้อง** — สคริปต์เขียนแบบ neutral speaker (ลงท้าย "ค่ะ") ต้อง confirm เจ้าของ/พนักงานคนไหนพูด เผื่อต้องปรับโทนเสียง/มุมมองการเล่าเล็กน้อย
3. **ราคาจริงวันถ่าย** — ตามตาราง §8 ทั้ง 3 ค่า (น้ำหนัก/ราคาเนื้อเงิน/ราคาป้าย) เติมได้เฉพาะวันที่จะอัดจริงเท่านั้น เขียนล่วงหน้าไม่ได้เพราะราคาขยับทุกวัน
