## 1. LINE Broadcast "คิดถึง" (win-back — เงียบ 2-6 เดือน, เคยยอด ≥3,000)

⚠️ **คนกลุ่มนี้ไม่เปิดข้อความร้านมานาน — บรรทัดแรกต้องหยุดนิ้วสไลด์ ห้ามขึ้นต้นด้วยชื่อร้าน/โปรโมชัน**

### เวอร์ชัน A — โทนอบอุ่นส่วนตัว

```
หายไปนานเลยนะคะ 🤍 เป็นห่วงว่าสบายดีไหม

พักนี้ไม่เห็นคุณแวะมาเลยค่ะ คืนนี้ร้านไลฟ์เหมือนเดิม 2-3 ทุ่ม
มีแบบใหม่มาโชว์ทุกคืน ถ้าแวะทักแชทหรือเข้าไลฟ์วันนี้
มีของเล็กๆ ติดไม้ติดมือให้เป็นกำลังใจที่กลับมาเยี่ยมกันค่ะ

[ปุ่ม: ทักแชทเลย]  [ปุ่ม: ตั้งเตือนดูไลฟ์คืนนี้]
```
(ความยาว ~230 ตัวอักษร)

### เวอร์ชัน B — โทนของใหม่เข้าร้าน

```
เข้ามาดูของใหม่หน่อยไหมคะ 🪞

ร้านมีคอลเลกชันใหม่เข้ามาเรื่อยๆ ทุกชิ้นขึ้นรูปด้วยมือช่างของเราเอง
เงินแท้ 925 ทุกชิ้น ไม่ใช่เงินชุบ

คืนนี้ไลฟ์ 2-3 ทุ่มค่ะ ถ้าเข้ามาดูหรือทักแชทวันนี้
มีของเล็กๆ แถมให้กลับไปด้วยนะคะ

[ปุ่ม: ดูของใหม่ในไลฟ์คืนนี้]  [ปุ่ม: ทักแชทตอนนี้เลย]
```
(ความยาว ~215 ตัวอักษร)

**ข้อเสนอ:** ระบุกลางๆ ว่า "ของเล็กๆ" ไม่เจาะจงชิ้น — ดูวัตถุดิบที่ยังขาดข้อ 1 ท้ายไฟล์
**A/B แนะนำ:** ยิง A กับครึ่งหนึ่ง, B กับอีกครึ่ง วัด click/reply แล้วเลือกตัวชนะไปใช้กับ broadcast ก้อนถัดไป

## 2. LINE Broadcast "ครั้งที่ 2" (ซื้อครั้งเดียว 1-3 เดือนก่อน)

```
ขอบคุณนะคะที่เคยอุดหนุน 3J 🤍

ของที่รับไปเป็นไงบ้างคะ ใส่แล้วถูกใจไหม มีอะไรอยากถามเรื่องการดูแลเงินแท้ ทักมาได้เลยค่ะ
ตอนนี้มีคอลเลกชันใหม่เข้าร้านเรื่อยๆ แวะดูในไลฟ์คืนนี้ 2-3 ทุ่มได้นะคะ
ซื้อครั้งถัดไป มีต่างหูเล็กๆ แถมให้เป็นของขวัญจากร้านด้วยค่ะ

[ปุ่ม: เข้าไลฟ์คืนนี้]  [ปุ่ม: ทักแชทถามของใหม่]
```
(ความยาว ~260 ตัวอักษร)

**โทน:** ขอบคุณจริงใจ + ถามความเห็น (สร้าง engagement) + ข้อเสนอชัดเจน "ต่างหูเล็ก" ไม่ใช่ของกลางๆ เพราะกลุ่มนี้ซื้อจริงมาแล้ว ควรให้ข้อเสนอที่จับต้องได้กว่ากลุ่ม win-back

## 3. Hook คลิป TikTok 3 ตัว + โครง script

⚠️ ทุก hook เขียนเป็น "คำพูดหน้ากล้อง" ไม่ใช่คำบรรยาย — พูดแล้วต้องฟังเป็นธรรมชาติ ไม่ใช่สคริปต์อ่าน

### Hook 1 — เงินแท้ใส่แล้วไม่ดำไม่แพ้

**บทพูดเปิด (0-3 วิ):** "แหวนวงนี้ใส่มาเป็นเดือนแล้วนะคะ ดูสิ ยังไม่ดำเลย"
*(พูดพร้อมยกมือ/ซูมกล้องเข้าแหวนหรือสร้อยที่ใส่จริง)*

Script ต่อ:
- ซูมกล้องใกล้ๆ ให้เห็นผิวเงินยังเงา ไม่หมองคล้ำ
- พูดสั้นๆ ว่าเป็นเงินแท้ 925 ทุกชิ้น ไม่ใช่เงินชุบที่ลอกง่าย
- ✅ **[28 ส.ค. 69 เจ้าของยืนยันแล้วว่าใช้ได้]** "ไม่แพ้ผิว" พูดได้ — ยังคงโทนแบ่งปัน
  ประสบการณ์/คุณสมบัติวัสดุ (เงินแท้ 925 ไม่ใช่ของชุบ) **ห้ามยกระดับเป็นคำโฆษณาเชิงการแพทย์**
  เช่น "รักษา/ป้องกันอาการแพ้" หรือ "การันตีไม่แพ้ 100%" — เส้นแบ่งนี้คือกฎโฆษณา ไม่ใช่ความเห็น
- ชวนดูของจริงหลายแบบในไลฟ์คืนนี้ 2-3 ทุ่ม
- CTA: กดตั้งเตือนไลฟ์ / ทักแชทถามรุ่นที่ชอบได้เลย

### Hook 2 — แบบใหม่เข้าทุกคืน

**บทพูดเปิด (0-3 วิ):** "ของล็อตนี้เพิ่งมาถึงร้านเมื่อกี้เองค่ะ ยังไม่ทันโชว์ที่ไหนเลย"
*(พูดพร้อมแกะกล่องของใหม่สดๆ)*

Script ต่อ:
- เปิดกล่อง/ถุงของใหม่ให้เห็นสดๆ หน้ากล้อง
- พูดว่าร้านอัปเดตแบบใหม่แทบทุกคืนที่ไลฟ์ ไม่ใช่รอเป็นเดือน
- โชว์เร็วๆ 2-3 ชิ้นเด่นให้เห็นความหลากหลาย
- ย้ำว่าอยากเห็นแบบไหนก่อนใครต้องมาไลฟ์ เพราะของไม่ซ้ำทุกคืน
- CTA: กดตั้งเตือนไลฟ์คืนนี้ 2 ทุ่ม

### Hook 3 — ราคาจับต้องได้

**บทพูดเปิด (0-3 วิ):** "เงินแท้ 925 ไม่ต้องรอโปรก็จับต้องได้ค่ะ มาดูกัน"

Script ต่อ:
- พูดตรงๆ ว่าร้านตั้งราคาเดียวทุกวัน ไม่ต้องรอลดราคาถึงจะซื้อได้
- เล่าว่าโรงงานทำเองมา 30 ปี คุมต้นทุนได้เอง ราคาเลยไม่บวกเวอร์
- โชว์ตัวอย่างชิ้นเล็กๆ ที่ราคาเข้าถึงง่าย (พูดราคาจริงในไลฟ์เท่านั้น ห้ามใส่ตัวเลขเทียบราคาตลาดเงินในคลิปนี้)
- ชวนดูราคาจริงทีละชิ้นในไลฟ์คืนนี้
- CTA: เข้าไลฟ์คืนนี้ 2 ทุ่ม ดูราคาจริงเลย

## 4. ข้อความบนภาพโฆษณา (Ad Copy) — 3 ชุด

### ชุด 1 — กลุ่ม win-back
- **หัว:** คิดถึงคุณอยู่นะ
- **รอง:** แวะดูของใหม่ มีของเล็กๆ ต้อนรับกลับมา
- **CTA:** ทักแชท หรือดูไลฟ์คืนนี้
- **ภาพควรโชว์:** บรรยากาศอบอุ่นของร้าน หรือมือช่างกำลังทำชิ้นงาน ให้ความรู้สึก "จำคุณได้" ไม่ใช่ภาพขายของแข็งๆ

### ชุด 2 — กลุ่มครั้งที่ 2
- **หัว:** ขอบคุณที่กลับมา
- **รอง:** ซื้อครั้งถัดไป แถมต่างหูเล็กให้เลย
- **CTA:** ดูของใหม่ในไลฟ์คืนนี้
- **ภาพควรโชว์:** ต่างหูของแถมวางคู่กับสินค้าหลัก ให้เห็นเป็นเซ็ตที่จับต้องได้จริง

### ชุด 3 — คนใหม่เข้าไลฟ์
- **หัว:** เงินแท้ 925 ทุกคืน
- **รอง:** แบบใหม่เข้าร้านไม่ซ้ำ ไลฟ์ 2-3 ทุ่ม
- **CTA:** กดตั้งเตือนดูไลฟ์คืนนี้
- **ภาพควรโชว์:** บรรยากาศไลฟ์จริง เห็นมือช่างหรือสินค้าหลายแบบเรียงโชว์ ให้รู้สึกว่ามีของให้เลือกเยอะ
