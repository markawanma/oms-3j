# แพ็กเกจส่งทีมออกแบบ — รอบ 2 (7 ต.ค. 2569)

สวัสดีครับ ในแพ็กเกจนี้มี 2 ไฟล์ อ่านตามลำดับ

| ไฟล์ | คืออะไร |
|---|---|
| `01-request-round2.md` | รายการที่ขอให้ปรับและเติมจากแพ็กเกจรอบแรก (15 board) — **เริ่มที่ไฟล์นี้** |
| `02-brief-v1.3.md` | brief ฉบับเต็มล่าสุด — ใช้เป็นกติกาอ้างอิงทุกข้อ (ฉบับนี้ทับฉบับ 1.0 ที่ส่งไปรอบแรก) |

## สิ่งที่อยากได้กลับ
1. ไฟล์แบบหน้าจอชุดเดียวกับรอบแรก (ส่งกลับเป็น zip ทั้งโปรเจกต์ได้เลย) — แก้ board เดิม + board ใหม่ตามคำขอ
2. sitemap 1 board + เส้นทางผู้ใช้ 3 เส้น (ข้อ 7.4 ในไฟล์ 01-request-round2.md)
3. ตาราง token สีที่เดียวใน board Component (ข้อ 9.1)
4. รายการคำถาม/สมมติฐานที่ตัดสินเองระหว่างทำ (ข้อ 9.3)

## ลำดับความสำคัญ ถ้าทำไม่ทันทั้งหมด
1. ข้อ 0 (ปรับให้ตรง brief 1.3) และข้อ 1 (หน้าแคมเปญ)
2. ข้อ 2 (แบบมือถือที่ขาด) และข้อ 3 (ส่วนที่ยังไม่ครบ)
3. ข้อ 5 (การเปลี่ยนสถานะ · ยืนยัน/เลิกทำ) และข้อ 8 (เก็บกวาด)
4. ข้อ 6 (แบบ PC ของหน้ามือถือ) · ข้อ 7 (เมนู/เส้นทาง)
5. ข้อ 4.1–4.2 (มุมมองผู้ช่วย/คนไลฟ์) — ลำดับรองสุด

## ไม่ต้องทำ
- สถานะ "กำลังโหลด" และ "ผิดพลาด" (ทีมพัฒนาทำเอง)
- หน้า ค่าแอด / วัดผลโค้ด / กลุ่มลูกค้า / แบบทดสอบพลอย (มีอยู่แล้ว แค่วางในเมนู)
