## 1. Hook 3 แบบ (เสียงบรรยาย 0-3 วิ)

| รหัส | hook_line | ภาพ 0-3 วิ | ตัวหนังสือบนจอ | ทำไมหยุดนิ้ว |
|---|---|---|---|---|
| **A** | "โรงงานเรากำลังลังเล... ว่าจะทำของชิ้นนี้อีกดีไหม" | โคลสอัพกล่อง/ซองเก็บพลอยเก่าของอาม่า มือค่อยๆ เปิดฝา | "ทำอีกดีไหม?" | ความลังเลของคนทำ = คนดูอยากรู้ว่า "ทำไมลังเล" + อยากเข้าไปช่วยตัดสิน |
| **B** | "ขายไปแล้ว... แต่ซื้อวัตถุดิบคืนยังไม่ได้" | รูปงานที่ขายไป ค่อยๆ ซูมเข้า | "ซื้อคืนไม่ได้" | ขัดความคาดหวัง (ขายหมดควรดีใจ) · แต่ฟังเป็นบ่นง่ายกว่า A |
| **C** | "อาม่าเก็บพลอยกล่องนี้ไว้ 30 ปีกว่า... แล้วลูกค้าก็รับไปจนหมด" | กล่อง/ซองเก่าของอาม่า | "30 ปีกว่า" | อบอุ่นสุด มีตัวละคร แต่ยังไม่มีความขัดแย้งใน 3 วิ — ต้องรอวินาทีที่ 18 |

**แนะนำ: A** — มีความขัดแย้ง (ลังเล) ตั้งแต่วินาทีแรกตามที่สั่ง · ภาพกล่องอาม่าให้ความอบอุ่นพร้อมกัน · เสียง "ลังเล" ชวนให้คนดูคิดว่า "ฉันช่วยได้" ซึ่งเชื่อมกับ CTA ท้ายคลิปตรงๆ
สำรอง: ถ้า A ได้ 3s-retention ต่ำ ให้ลอง B (เปลี่ยนแค่ 3 วิแรก เนื้อหลังเดิม)

## 2. บทเต็ม (ใช้ hook A) · รวม ~42 วิ

| เวลา | ภาพ | เสียงบรรยาย | ตัวหนังสือบนจอ |
|---|---|---|---|
| **0-3s** HOOK | โคลสอัพกล่อง/ซองเก็บพลอยเก่าของอาม่า มือเปิดฝาช้าๆ (ถ่ายเพิ่ม) | "โรงงานเรากำลังลังเล... ว่าจะทำของชิ้นนี้อีกดีไหม" | **ทำอีกดีไหม?** |
| **3-11s** | กล่อง/ซองของอาม่าหลายมุม · มือหยิบซองเปล่าขึ้นมาดู (ถ่ายเพิ่ม) | "กล่องนี้เป็นของอาม่านะ ข้างในเคยเป็นทับทิมพม่าเผาเก่า อาม่าเก็บไว้ตั้ง 30 ปีกว่า" | ทับทิมพม่าเผาเก่า · อาม่าเก็บไว้ 30 ปีกว่า |
| **11-19s** | รูปงานที่ขายไปแล้ว สไลด์ทีละชิ้น (ใช้รูปที่มี) | "เราเอาออกมาทำเป็นเครื่องประดับ ล็อตนั้นมีใบเซอร์จากแล็บ ขายในราคาที่เป็นกันเองมาก ลูกค้ารับไปจนหมดเลย" | ล็อตเก่า · มีใบเซอร์จากแล็บ · ขายหมดแล้ว |
| **19-28s** | กล่องว่าง/ซองเปล่าวางบนโต๊ะ (ถ่ายเพิ่ม) · ตัดสลับโต๊ะช่างให้เห็นว่ากำลังคิด (ถ้ามี) | "แต่พอเราไปถามราคาพลอยมาทำใหม่ ตกใจเลยค่ะ... ราคาที่เคยขายไป เอาไปซื้อพลอยมาคืน ยังไม่ได้เลย" | ซื้อคืนไม่ได้ |
| **28-36s** | รูปงานที่ขายไปอีกรอบ (คนชอบ/ของที่ลูกค้าขอ) · ซองเปล่า | "เราเลยลังเล แต่ลูกค้าทักมาขอให้ทำอีกเยอะมาก ถ้าทำอีก เราจะหาพลอยที่ดีที่สุดที่หาได้ แล้วบอกชัดๆ ว่าเป็นพลอยอะไร แต่ต้องบอกก่อนนะ... อาจไม่เหมือนล็อตเดิม" | ล็อตใหม่ อาจไม่เหมือนเดิม · เราจะบอกชัดว่าเป็นพลอยอะไร |
| **36-43s** CTA | ซองเปล่ากลับมาเฟรมเดียวเหมือน hook (วนกลับ) | "ช่วยเราตัดสินใจหน่อย ถ้าอยากให้ทำอีก คอมเมนต์บอกไว้เลย ครบ [ต้องยืนยัน: จำนวนคอมเมนต์เป้าหมาย] คน เราจะไปหาพลอยมาทำ" | อยากให้ทำอีก? คอมเมนต์เลย · เป้า [ต้องยืนยัน: จำนวน] คน |

หมายเหตุการเล่า
- ผู้เล่าใช้ "เรา" · คำลงท้ายในบทเขียนเป็นกลาง/ใส่ "ค่ะ" จุดเดียว (วินาที 19-28) — `[ต้องยืนยัน: เพศ/คำลงท้ายของผู้พากย์ — ปรับให้ตรงคนอ่านจริง]`
- อ่านช้า มีช่วงเงียบ 0.5 วิหลัง "ลังเล..." และหลัง "ซื้อคืนไม่ได้" ให้ความรู้สึกคนคิดจริง ไม่ใช่อ่านสคริปต์
- ใบเซอร์: พูดว่า "มีใบเซอร์จากแล็บ" เท่านั้น ไม่ระบุชื่อแล็บ/ผลตรวจ/เกรด จนกว่าจะยืนยัน · ใบเซอร์ยืนยัน **ล็อตเก่าเท่านั้น** (ตัวหนังสือในจอเขียน "ล็อตเก่า" กำกับไว้แล้ว)

### ภาพที่ต้องถ่ายเพิ่ม (ไม่มีในของที่มี)
1. [ ] กล่อง/ซองเก็บพลอยของอาม่า โคลสอัพ + มือเปิดฝา (hero shot hook)
2. [ ] ซองเปล่า/กล่องว่างวางบนโต๊ะ 2-3 มุม (ภาพ "หมดแล้ว")
3. [ ] (ถ้ามี) โต๊ะช่าง/มือช่างที่กำลังพิจารณา — ไม่บังคับ
ภาพที่ใช้ของเดิม: รูปงานที่ขายไป · ชิ้นที่เหลือ (ดูธงข้อ 6 เรื่องชิ้นที่เหลือ)

## 5. เช็คลิสต์ผ่านกฎ 1-6

- [x] **1. ไม่มีตัวเลขราคา** — ไม่มีราคาขาย/ซื้อเก่า-ใหม่/% /ต้นทุน/กำไร · ใช้ "เป็นกันเองมาก" "ซื้อคืนไม่ได้" แบบความรู้สึก (ตัวเลขเดียวที่มี = "30 ปีกว่า" อายุที่เก็บ ไม่ใช่ราคา)
- [x] **2. ไม่มีมุมลงทุน** — ไม่มี "ราคาจะขึ้น/ซื้อเก็บ/มูลค่าเพิ่ม/รีบก่อนแพง" · ราคาแพงขึ้นเล่าเป็นประสบการณ์ร้าน ("ไปถามแล้วตกใจ") · **ตัดประโยค "ซื้อไว้ตอนราคายังไม่สูง" ออกโดยตั้งใจ** เพราะฟังเป็นเรื่องซื้อถูกขายแพง/ชวนคิดกำไร
- [x] **3. ไม่สัญญาล็อตใหม่เหมือนเดิม** — บทบอก "อาจไม่เหมือนล็อตเดิม" + "หาพลอยที่ดีที่สุดที่หาได้ บอกชัดว่าเป็นพลอยอะไร" · ใบเซอร์กำกับ "ล็อตเก่า"
- [x] **4. ไม่มีคำเด็ดขาด/มงคล** — ไม่มี "หายากที่สุด/ไม่มีที่ไหนแล้ว/ชิ้นสุดท้าย" · ไม่มีสรรพคุณ/มงคล · ความจำกัดสื่อด้วยข้อเท็จจริง ("ขายหมดแล้ว" "ซื้อคืนไม่ได้")
- [x] **5. ไม่มี "แกะมือ/ฉลุมือ" · ไม่เรียก CZ ว่าเพชร** — ไม่พูดเทคนิคงานช่างหรือ CZ เลย
- [x] **6. ไม่เติมข้อมูลเอง** — ค่าที่ไม่รู้ใส่ `[ต้องยืนยัน]` ทั้งหมด (ด้านล่าง) · ไม่ระบุชื่อแล็บ/เกรด/แหล่ง/จำนวนชิ้นที่ขาย
- [x] ไม่มีลิงก์/LINE/เว็บ/tools. ในบท ตัวหนังสือ แคปชัน (grep แล้วในไฟล์: ไม่มี)

## 6. รายการ `[ต้องยืนยัน]` และธงเตือน

| # | รายการ | ผลถ้าไม่ยืนยัน |
|---|---|---|
| 1 | `[ต้องยืนยัน: จำนวนคอมเมนต์เป้าหมาย]` (บท 36-43s + ตัวหนังสือ) | ห้ามถ่าย/ลงจนกว่าเจ้าของเคาะ |
| 2 | `[ต้องยืนยัน: เวลาไลฟ์คืนนี้]` (แคปชัน) | ตัดบรรทัดนี้ออกได้ |
| 3 | `[ต้องยืนยัน: เพศ/คำลงท้ายผู้พากย์]` | ปรับตอนอัดเสียง |
| 4 | `[ต้องยืนยัน: ชิ้นที่ถ่ายขายหมดแล้วหรือยัง]` — เจ้าของให้ภาพ "ชิ้นงานที่เหลือ" แต่บทพูดว่า "ขายหมดแล้ว" | ถ้ายังมีชิ้นเหลือขายอยู่ ต้องแก้บทเป็น "เหลือไม่กี่ชิ้น" และ **ต้องมีจำนวน/สถานะจริง** หรือใช้เฉพาะรูปชิ้นที่ขายไปแล้ว |
| 5 | `[ต้องยืนยัน: ใบเซอร์ระบุอะไร]` — บทใช้แค่ "มีใบเซอร์จากแล็บ" · ห้ามเอาไปแปลว่า "ธรรมชาติ/ไม่เผา/เกรดสูง" | ถ้าอยากเสริมต้องมีใบเซอร์ให้ดู |
| 6 | `[ต้องยืนยัน: ชิ้นงานเป็นตัวเรือนเงินหรือไม่]` — ใช้ในแฮชแท็ก/คำว่า "เครื่องประดับ" ทั่วไปไว้ก่อน | อย่าใส่ 925/เงินแท้ จนกว่ายืนยัน |
| 7 | `[ต้องยืนยัน: เจ้าของโอเคให้เล่าว่าอาม่าเป็นผู้เก็บ + ใช้ชื่อ "อาม่า" ในคลิปสาธารณะ]` | ตัดเป็น "คนเก่าแก่ในโรงงาน" ได้ |

ธงอื่น
- **ความเสี่ยงคำสัญญา**: "ครบ X คน เราจะไปหาพลอยมาทำ" เป็นคำมั่นต่อสาธารณะ — ถ้าครบแล้วไม่ทำ เสียเครดิตหนัก → เจ้าของควรตัดสินใจก่อนว่า "ครบแล้วทำจริง" หรือเปลี่ยนเป็น "เราจะเอาไปคิดจริงจัง" (บทนี้เขียนตามที่สั่ง)
- **คอมเมนต์แล้วคาดหวังของ**: คนจะถามราคา/จองใต้คลิป → เตรียมคำตอบ "ยังไม่เปิดขาย ถ้าทำแล้วจะบอกในไลฟ์" ห้ามตอบราคา/ชวนไป LINE ในคอมเมนต์ (นโยบาย off-platform)
- ประโยค "ขายในราคาที่เป็นกันเองมาก" ไม่มีตัวเลข แต่ระวังคนตีความว่า "ของถูก" → ถ้าเจ้าของกังวล ให้ลดเป็น "ขายในราคาที่เราตั้งไว้ตอนนั้น"
