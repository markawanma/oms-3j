## ส่วนที่ 1 — ทำไมราคาเงินโลกขึ้นแรง แต่เงินแท่งเราขายไม่ได้

**ไม่เดาคำตอบเดียว — วางเป็นสมมติฐานที่ทดสอบได้ 4 ข้อ เรียงตามความเป็นไปได้ที่จะเป็นสาเหตุหลัก**

### H1 — Funnel พังตรงจุดที่ demand กำลังมา (น่าจะเป็นสาเหตุหลักที่สุด)

ราคาเงินโลกขึ้น 18% ในเดือนเดียวเป็นเหตุการณ์ที่น่าจะกระตุ้นให้คนค้น "ราคาเงินวันนี้" / "ซื้อเงินแท่งดีไหม" มากขึ้น แต่คนที่ค้นแล้วเข้าเว็บเรามาเจอ **US$0.00 บนหน้าแรก, 0 บาทตอนนอกเวลาทำการ, ชื่อสินค้าเป็นรหัส** (audit 6 ส.ค.) — นี่คือจุดที่ demand ภายนอกถูกฆ่าทิ้งก่อนถึงขั้นตอนตัดสินใจซื้อด้วยซ้ำ ไม่ใช่ปัญหาว่าคนไม่สนใจเงินแท่ง

**ทดสอบยังไง:** ดึง Google Analytics/Search Console ของ `/silver-bar`, `/silver-price` เทียบเดือน ก.ค.-ส.ค. — ถ้า organic traffic/impression ขึ้นตามราคาโลกแต่ order ไม่ขึ้น = ยืนยัน H1 ตรงเป้า ถ้า traffic ก็นิ่งด้วย = H1 ไม่ใช่ตัวหลัก ต้องดู H2-H4

### H2 — เราตอบไม่ได้จริงๆ ว่า broadcast ที่ส่งไปทำไมไม่ได้ผล เพราะไม่รู้ segment ที่ใช้

Memory ยืนยันว่าลูกค้าเงินแท่งกับเครื่องประดับทับกันแค่ 2.7% — ถ้า broadcast ที่ส่งไปแล้ว "ไม่ได้ผล" ยิงไปทั้งลิสต์ LINE (ซึ่งส่วนใหญ่เป็นลูกค้าเครื่องประดับ) แทนที่จะยิงเฉพาะกลุ่มเคยซื้อเงินแท่ง ผลลัพธ์ก็ควรจะแย่อยู่แล้วโดยไม่เกี่ยวกับว่าราคาขึ้นหรือลง — เป็นปัญหา targeting ไม่ใช่ปัญหาว่า "ลูกค้าไม่สนใจราคาเงิน"

**ทดสอบยังไง:** เช็ค log/audience filter ของ broadcast ที่ส่งไปแล้วจริง — ยิงกลุ่มไหน กี่คน เทียบกับจำนวนลูกค้าที่เคยซื้อเงินแท่งจริงในระบบ **(นี่คือการดูข้อมูลเก่า ไม่ใช่ข้อเสนอให้ส่ง broadcast ซ้ำ)**

### H3 — คนที่เคยซื้อตอนราคาพีคมกราคมอาจยังหวาดระแวง (ต้องยืนยัน fact ก่อน ห้ามใช้เลยตอนนี้)

Snippet ที่ยังไม่ยืนยัน (`[snippet]` ใน research) อ้างว่าเงินเคยขึ้นไปแตะ ~$122/oz ปลาย ม.ค. 2026 แล้วร่วง ~48% หลังข่าว Fed — **ถ้าเป็นจริง** จะอธิบายได้ว่าทำไมยอดขาย ม.ค. (฿12.2M) สูงมากแล้วร่วงเหลือ ฿975k มิ.ย. (ไม่ใช่แค่ราคาลง แต่คนที่ซื้อตอนพีคขาดทุนหนักและจำได้) — ถ้าจริง คนกลุ่มนี้อาจยังลังเลซื้อซ้ำตอนนี้แม้ราคาจะกลับมาขึ้น เพราะกลัวซ้ำรอย ไม่ใช่เพราะไม่มีเงิน

**ทดสอบยังไง:** ต้องยืนยัน fact นี้จากแหล่งที่เปิดอ่านได้จริง (ไม่ใช่ snippet) ก่อน — ถ้ายืนยันได้ ค่อยดูว่าลูกค้าเก่าที่ซื้อช่วง ม.ค. กลับมาซื้อซ้ำหรือส่งคำถามอะไรเข้ามาไหมหลังจากนั้น (ดูจาก LINE chat log ถ้าเก็บไว้)
**⚠️ ห้ามใช้ตัวเลข $122/-48% นี้ในคอนเทนต์สาธารณะจนกว่าจะยืนยันแหล่งจริง**

### H4 — เราตอบคำถามนี้ไม่ได้เต็มร้อยเพราะข้อมูลเราเองไม่ครบ

Memory ระบุชัดว่า `oem_metal_price` ว่างเปล่า — เราไม่มีข้อมูลราคาที่เว็บเราแสดงจริงในแต่ละวันช่วงที่ยอดขายร่วง เทียบกับ order date ไม่ได้ นี่ไม่ใช่สมมติฐาน แต่เป็น **gap ที่ทำให้ H1-H3 พิสูจน์ได้แค่บางส่วน**

**สรุปส่วนที่ 1:** สมมติฐานที่น่าเชื่อที่สุดตอนนี้คือ **H1 (funnel พัง) ร่วมกับ H2 (broadcast ผิดกลุ่ม)** เพราะมีหลักฐานยืนยันแล้ว (audit จริง + fact ลูกค้า 2 กลุ่มไม่ทับกัน) ส่วน H3 ต้องรอยืนยัน fact ก่อนถึงจะเอามาคิดต่อได้ — **ข้อสรุปเชิงปฏิบัติ: แก้ funnel (H1) ก่อนคิดผลิตคอนเทนต์เพิ่ม เพราะถ้า funnel ยังพัง คอนเทนต์ใหม่แค่ดันคนเข้าไปเจอหน้าเว็บที่ทำลายความเชื่อถือมากขึ้น**

## ส่วนที่ 2 — ช่องว่าง positioning ที่ UMA Silver 925 ยึดอยู่

UMA ใช้ "มีโรงงานมาตรฐานสากล" + "10+ ปี" + "All In One ออกแบบ→ผลิต→ส่ง" เป็นหัวเรื่องหลักของทั้งเว็บ — เราจริงมากกว่าเขาในทุกมิติ (30 ปี ไม่ใช่ 10+, ผลิตเองจริง ไม่ใช่แค่ "ได้มาตรฐาน") แต่เว็บเรา**ไม่พูดเรื่องนี้เลยแม้แต่บรรทัดเดียว** — `positioning-2pillar.md` มี pillar OEM วางไว้แล้วตั้งแต่ 6 ส.ค. (value prop "โรงงานเดียวจบ: ออกแบบ-ต้นแบบ-ผลิต-QC ครบวงจร โดยทีม 30 ปี") แต่ยังไม่เคยขึ้นเว็บจริง — ไม่ใช่ว่าไม่มีคนคิด แค่ไม่มีคน publish

**สิ่งที่ทำได้ตอนนี้ ไม่ใช่การเขียน OEM content cluster เต็มรูปแบบ** (นั่นคืองาน scope ใหญ่กว่าที่ content-plan-silver-bar วางไว้ และยังค้างคำตอบ 6 ข้อใน positioning doc §5 เรื่อง MOQ/lead time/ค่าแบบ) **แต่คือ trust block สั้นๆ 1 ก้อน** ที่ประกาศตัวตน "โรงงานเงิน 30 ปี" บนหน้าแรก/หน้า `/silver-bar` — ยึดพื้นที่ narrative ไว้ก่อนที่ใครจะยึดไปเต็มๆ โดยไม่ต้องรอคำตอบ MOQ/pricing ให้ครบก่อน (นั่นเป็นเงื่อนไขของหน้า OEM แบบเต็ม ไม่ใช่ trust block บนหน้าเงินแท่ง)

**ย้ำ:** ดู UMA เพื่อเข้าใจว่าเขาเล่าโครงสร้างข้อความยังไง (โรงงาน→ประสบการณ์→ครบวงจร) — เราเขียนข้อความของเราเองจากข้อเท็จจริงของเรา ไม่หยิบคำเขามาใช้

## ข้อที่ขัดกับสิ่งที่ทีมเราเชื่ออยู่

1. **`content-plan-silver-bar.md` วาง silver bar ทั้งหมดไว้ในกรอบ "SEO 6-12 เดือน ไม่ใช่ตัวทำยอด Q3-Q4"** ซึ่งถูกต้องสำหรับงาน content/SEO — แต่ #1, #2, #3 ในแผนนี้**ไม่ใช่งาน SEO** เป็นการแก้ของที่พังอยู่ตรงหน้า ขณะที่มีเหตุการณ์ราคาตลาดโลกขึ้นแรงเกิดขึ้นจริงตอนนี้ — กรอบเวลา "ไม่รีบ" ที่ทีมยึดอยู่ใช้ไม่ได้กับรายการนี้ ควรทำสัปดาห์นี้ ไม่ใช่รอคิว SEO
2. **อย่าตีความว่า "broadcast เงินแท่งไม่ได้ผล" = "ช่องทาง LINE ใช้ไม่ได้กับเงินแท่ง"** — ข้อ 5 ในแผนนี้ชี้ว่าอาจเป็นปัญหา targeting ไม่ใช่ปัญหาช่องทางหรือปัญหาว่าลูกค้าไม่สนใจ ถ้าสรุปเร็วเกินไปว่า "LINE ใช้ไม่ได้" อาจปิดโอกาสที่จริงๆ ยังไม่ได้ลองให้ถูกวิธี (แต่ตามกติกาที่ได้รับ — จะไม่เสนอส่ง broadcast ซ้ำจนกว่ามีข้อมูลจาก #5 ยืนยันก่อน)

4. **`oem_metal_price` ว่างเปล่า** — กู้ข้อมูลย้อนหลังได้ไหม ถ้ากู้ไม่ได้ H4 จะเป็น gap ถาวร ไม่ใช่แค่ชั่วคราว ต้องถามทีม DB/analytics
5. **ช่วงเวลาที่ bug "0 บาท" เกิดขึ้นจริงย้อนหลัง** — audit เจอเมื่อ 6 ส.ค. แต่ไม่รู้ว่า bug นี้มีมานานแค่ไหน ถ้ามีมาตั้งแต่ ม.ค.-มิ.ย. ก็อาจเป็นส่วนหนึ่งของสาเหตุยอดร่วง -96% ไม่ใช่แค่เรื่องราคาตลาดอย่างเดียว — ต้องเช็ค deploy history ของหน้า Wix
6. **TikTok analytics ของโปรไฟล์ร้าน** — ยังไม่มีสิทธิ์เข้าดูตัวเลขจริง (profile views, follow rate) ตอนนี้พูดได้แค่ "ไม่เคยมีใครดู" จาก note ของ CMO ยังไม่มีตัวเลขมายืนยันระดับความรุนแรง
