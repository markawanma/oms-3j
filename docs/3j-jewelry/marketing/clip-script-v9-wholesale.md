## กฎการพูดเรื่องราคา (OEM) — สรุปจาก brief

**พูดได้:** "ราคาโรงงานจริง เพราะผลิตเอง ไม่ผ่านคนกลาง" · "ตีราคาให้ตามแบบและจำนวน"
**ห้ามเด็ดขาด:** ตัวเลขราคาทุกชนิด (ราคาต่อชิ้น/% /ช่วงราคา/"เริ่มต้นที่ ฿xxx") · เทียบราคากับโรงงานอื่น/จีนเป็นตัวเลข · สัญญาว่าแบรนด์จะขายดี/คืนทุน/รวย · lead time เป็นตัวเลขวัน (ใช้ "แจ้งกำหนดเวลาตอนตีราคา" แทน)
**ต้องพูดให้ชัด:** งานทองอิงราคาทอง ณ วันสั่งผลิต + ค่าแรง (ไม่ใช่ราคาคงที่)

**แนะนำ: Hook E** (เปลี่ยนจาก D หลังเจ้าของส่งข้อมูลค่าแม่พิมพ์/คลังแบบมา) — เป็น offer ที่แข่งยากที่สุดในตลาด OEM เพราะทลาย objection #1 (ไม่มีแบบ) และ #5 (กลัว MOQ/ต้นทุนตั้งต้น) พร้อมกันตั้งแต่วินาทีแรก **proof เรื่องส่งออก (เดิม Hook D) ยังทรงพลังมาก ย้ายไปเป็นส่วนสนับสนุนใน Body 1 แทน** ไม่ทิ้งไปไหน แค่เปลี่ยนตำแหน่ง — สคริปต์เต็มด้านล่างเขียนจาก Hook E · **Hook D และ A ยังใช้ได้ดีเป็น execution คู่ขนานสำหรับทดสอบ A/B ทีหลัง**

✅ ตลาดส่งออกที่ 4 ยืนยันแล้วว่าเป็น **ออสเตรเลีย** — สคริปต์ทั้งไฟล์อัปเดตเป็น 4 ตลาด (ยุโรป/อเมริกา/ออสเตรเลีย/ญี่ปุ่น) เรียบร้อย

## 3. Shot list

> เจ้าของยืนยันว่ายังไม่มีผลงานลูกค้า OEM ให้โชว์ (จะหามาให้ทีหลัง) **แต่ถ่ายโรงงาน+กระบวนการผลิตจริงได้ทันที** — shot list ด้านล่างออกแบบให้คลิปยืนได้ด้วยฟุตเทจกระบวนการผลิตล้วน ไม่ต้องรอผลงานลูกค้าเลย ช็อต **[บังคับ]** คือสิ่งที่ต้องมีให้คลิปสมบูรณ์ ช็อต **[เสริม]** คือถ้ามีให้ใส่ ไม่มีก็ข้ามได้

1. [ ] **[บังคับ]** Establishing shot โรงงาน/เวิร์กช็อปเปิดคลิป (เห็นเครื่องจักร/ช่างทำงานจริง — พิสูจน์ว่าเป็นโรงงานไม่ใช่ห้องพรีเซนต์)
2. [ ] **[บังคับ]** หน้าคนพูดพูด hook ตรงกล้อง พร้อมถือแค็ตตาล็อก/แฟ้มแบบ หรือมือเปิดลิ้นชักแบบให้เห็นจำนวนเยอะจริง (ประกอบ claim "10,000 แบบ" — **ถ้าไม่มีภาพนี้ ห้ามใช้ Hook E** เพราะกลายเป็นคำพูดลอย)
3. [ ] **[บังคับ]** insert หน้าจอไฟล์แบบ/แคตตาล็อกดิจิทัลเลื่อนดูหลายหน้า (ถ้ามีระบบไฟล์ดิจิทัล) หรือถ่ายสมุด/แฟ้มแบบจริงเลื่อนหน้าต่อหน้า
4. [ ] **[บังคับ]** ช็อตหล่อ/ฉีดเทียน (wax injection/casting) — proof กระบวนการผลิตจริง
5. [ ] **[บังคับ]** ช็อตแต่งงาน (finishing) หลังหล่อ
6. [ ] **[บังคับ]** ช็อตขัด (polishing)
7. [ ] **[เสริม]** ช็อตชุบ (plating) ถ้ามีให้ถ่ายจริง
8. [ ] **[เสริม]** ช็อตยิงเลเซอร์สลักโลโก้ลงบนชิ้นงาน (ถ้ามีเครื่องจริงในโรงงาน — ยืนยันก่อนถ่าย ห้ามจำลอง)
9. [ ] **[บังคับ]** โคลสอัพชิ้นงาน 3 วัสดุ (เงิน/ทอง/ทองเหลือง) วางเทียบกันบนโต๊ะเดียว — hero shot ของคลิป ต้องเห็นความต่างของวัสดุชัดด้วยตาเปล่า
10. [ ] **[บังคับ]** ปิดท้าย: หน้าคนพูดตรงกล้อง + overlay CTA/3 บรรทัดบังคับ/QR LINE
11. [ ] **[เสริม]** ช็อตกล่อง/พัสดุเตรียมส่งออก หรือมุมโต๊ะแพ็กสินค้าส่งต่างประเทศ — ใช้ประกอบตอนพูดถึง "ส่งออกยุโรป อเมริกา ออสเตรเลีย ญี่ปุ่น" ไม่มีก็ข้ามได้ ไม่กระทบความสมบูรณ์ของคลิป

**เมื่อมีผลงานลูกค้า OEM มาให้ใช้ในอนาคต (คลิปต่อยอด/repurpose) — รวมถึงงานส่งออกต่างประเทศ:**
- [ ] **ต้องเบลอโลโก้/แบรนด์ของลูกค้าทุกจุดที่เห็น** ตอนตัดต่อ — ห้ามเปิดชื่อ/โลโก้ลูกค้า OEM รายใดโดยไม่ได้รับอนุญาตเป็นลายลักษณ์อักษร ไม่ว่าจะเป็นลูกค้าไทยหรือลูกค้าส่งออก (สอดคล้อง `positioning-2pillar.md` §4: "OEM ห้ามโชว์ผลงานลูกค้ารายใดโดยไม่ได้รับอนุญาต (NDA)")
- [ ] เอกสาร shipping/ใบส่งของที่มีชื่อลูกค้าต่างประเทศ ต้องเบลอหรือเก็บออกจากเฟรมทั้งหมด

## 7. Do/Don't หน้ากอง

**Do**
- [ ] ถ่ายให้เห็นขั้นตอนผลิตจริงอย่างน้อย 3 ขั้น (หล่อ/แต่งงาน/ขัด/ชุบ/เลเซอร์ — เลือกตามที่มีจริงหน้างานวันนั้น)
- [ ] วางชิ้นงาน 3 วัสดุ (เงิน/ทอง/ทองเหลือง) เทียบกันในเฟรมเดียว ให้แสงพอเห็นความต่างของสี/เนื้อวัสดุชัด
- [ ] ถือแค็ตตาล็อก/เปิดลิ้นชักแบบให้เห็นจำนวนแบบเยอะจริงตอนพูด hook "10,000 แบบ" — ขาดภาพนี้ = ห้ามใช้ hook นี้
- [ ] พูดตัวเลข MOQ ให้ตรงตามวัสดุเป๊ะ: **เงิน 925 = 50 ชิ้น, ทอง = 20 ชิ้น, ทองเหลือง = 100 ชิ้น** ห้ามสลับ/พูดผิดวัสดุ
- [ ] เก็บเอกสารใบเสนอราคา/ตารางราคาออกจากพื้นที่ถ่ายก่อนตั้งกล้อง
- [ ] เช็คก่อนถ่ายว่าชิ้นงาน OEM ของลูกค้าเดิมที่อยู่ในเฟรม (ถ้ามี) — ได้รับอนุญาตให้โชว์หรือยัง ถ้าไม่แน่ใจ **เบลอหรือเก็บออกจากเฟรม**
- [ ] คนพูดต้องพูดประโยค "ราคาขึ้นกับแบบและจำนวน" หรือความหมายเดียวกันเองอย่างน้อย 1 ครั้งในคลิป (ไม่ใช่แค่ overlay)
- [ ] เช็คว่า LINE ID/QR ที่ขึ้นจอเป็นช่องทางที่มีแอดมินพร้อมตอบจริงในวันโพสต์

**Don't**
- [ ] ห้ามพูดตัวเลขราคาทุกชนิด — ไม่มีราคาต่อชิ้น ไม่มี % ไม่มีช่วงราคา ไม่มี "เริ่มต้นที่ ฿xxx" **รวมถึงห้ามพูดตัวเลขค่าแม่พิมพ์เด็ดขาด** (เจ้าของยังไม่ให้ตัวเลขนี้ และไม่ควรเปิดแม้จะมีในอนาคต)
- [ ] ห้ามเทียบราคากับโรงงานอื่น/จีนเป็นตัวเลข (พูดเชิงคุณภาพได้ เช่น "คุยง่ายเพราะอยู่ไทย" แต่ห้ามมีตัวเลขราคาเทียบ)
- [ ] ห้ามพูดหรือสื่อว่า "ทำแบรนด์กับเราแล้วขายดีแน่นอน/คืนทุนไว/รวย" แม้จะเป็นการพูดให้กำลังใจเฉยๆ
- [ ] ห้ามพูด lead time เป็นตัวเลขวัน (เช่น "เสร็จใน 15 วัน") จนกว่าจะมีคนยืนยันตัวเลขจริง — ใช้ "แจ้งกำหนดเวลาตอนตีราคา" เท่านั้น
- [ ] ห้ามเปิดชื่อ/โลโก้ลูกค้า OEM รายใดในคลิปโดยไม่มีการอนุญาตเป็นลายลักษณ์อักษร
- [ ] ห้ามพูดว่างานทองราคาคงที่/ล็อกราคาได้ — ต้องย้ำว่าอิงราคาทอง ณ วันสั่งผลิตเสมอ
- [ ] ห้ามรับปากทำแบบก๊อปปี้จากแบรนด์อื่นในคลิปหรือ DM ก่อนเช็คที่มาแบบ
- [ ] ห้ามระบุชื่อแบรนด์ลูกค้าต่างประเทศที่เคยผลิตให้ ห้ามบอกจำนวนออเดอร์/มูลค่าการส่งออก — พูดได้แค่ "ส่งออกไปตลาดเหล่านี้" เชิงภาพรวมเท่านั้น
- [ ] ห้ามพูดคำว่า **"ถูก"** ลอยเดี่ยวๆ โดยไม่มีเหตุผลกำกับ (เสี่ยงให้คนที่ซีเรียสเรื่องคุณภาพตีความว่า "ถูก = งานไม่ดี" ซึ่งขัดกับ proof ส่งออกยุโรป/ญี่ปุ่น) — ใช้ **"คุ้มค่า / เป็นธรรม / ราคาโรงงานจริง"** เป็นคำหลักแทน ถ้าจะใช้คำว่า "ถูก" ต้องมีเหตุผลต่อท้ายเสมอ เช่น "ถูกได้เพราะผลิตเอง ไม่ผ่านคนกลาง"
- [ ] ห้ามพูดตัวเลข "ถูกกว่า x%" หรือเทียบราคากับโรงงานจีน/โรงงานอื่นเป็นตัวเลข (ซ้ำกับกฎราคาด้านบน — ย้ำเพราะเป็นจุดที่หลุดปากง่ายตอนอธิบายว่าทำไมราคาคุ้ม)

## 9. ภาคผนวก — ถ้ามีคนทักมาถามซื้อส่งไปขายต่อ (ไม่ใช่ OEM)

คลิปนี้คือ V9 เวอร์ชัน OEM แต่ธุรกิจขายส่ง (ส่งออก/order พิเศษ) จากรอบก่อนหน้ายังมีอยู่จริงและอาจมีคนทัก LINE มาถามแบบนั้นแทน — เก็บคำตอบชุดเดิมไว้ที่นี่กันแอดมินตอบขัดกันเอง (เอกสารก่อนหน้าถูกแทนที่ทั้งไฟล์แล้ว จึงย้ายมาไว้เป็นภาคผนวก):

**หลักการ:**
- ขายปลีกออนไลน์ (TikTok/Shopee/LINE) = **ราคาเดียวทุกช่องทาง** ไม่มีราคาส่งสำหรับการซื้อปลีก
- ราคาส่งมีจริง แต่สงวนไว้เฉพาะ **ลูกค้าส่งออก + ลูกค้าสั่ง order พิเศษ (สั่งจำนวนมาก)** เท่านั้น เริ่มต้นที่ **30-100 ชิ้นขึ้นไป แล้วแต่หมวด**
- หมวดเงิน 925 พื้นฐาน ส่วนต่างจากราคาส่งบางมาก **~5%** — ถ้าเป้าหมายคือกำไรต่อชิ้น แนะนำหมวดเครื่องรางหรือทองจีนแทน
- เงินแท่งไม่มีราคาส่ง ราคาเดียวทุกคน
- ซื้อจำนวนน้อยกว่าขั้นต่ำ (เช่น 5 ชิ้น) **ไม่ได้ราคาส่ง** — ต้องซื้อราคาปลีกเหมือนทุกคน
- เงื่อนไข: สั่งตรงผ่าน LINE เท่านั้น · ชำระเต็มก่อนส่ง · ไม่รับคืนสินค้าที่ขายไม่ออก (ยกเว้นชำรุดจากการผลิต)

**คำตอบ DM ตัวอย่างเมื่อลูกค้าทักมาถามแบบขายส่ง (ไม่ใช่ OEM):**
> "สวัสดีค่ะ ขอบคุณที่สนใจนะคะ 🙏 รบกวนถามก่อนค่ะว่าสนใจสั่งจำนวนมากใช่ไหมคะ (เช่นสั่งเพื่อส่งออก หรือ order พิเศษ) แล้วสนใจหมวดไหน ประมาณกี่ชิ้นคะ ราคาส่งของเราเริ่มที่สั่งจำนวนมากตั้งแต่ 30 ชิ้นขึ้นไปค่ะ จะได้คำนวณราคาให้ตรงล็อตเลยค่ะ"

⚠️ **หมายเหตุสำคัญ:** ตัวเลข MOQ ของ OEM (§8 ข้อ 1) กับตัวเลข 30-100 ชิ้นของขายส่งข้อนี้ **เป็นคนละตัวเลขคนละธุรกิจ** — ห้ามแอดมินสลับใช้ ต้องถามลูกค้าก่อนเสมอว่า "อยากทำแบรนด์ตัวเอง (OEM)" หรือ "อยากซื้อสินค้าสำเร็จรูปไปขายต่อจำนวนมาก (ขายส่ง)" ก่อนตอบราคา/เงื่อนไข
