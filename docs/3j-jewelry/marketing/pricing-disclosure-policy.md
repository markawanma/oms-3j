## 2. กติกาพูดหน้ากล้อง

### 2.1 V2 — เงินแท่ง (เปิดเต็ม)

**พูดได้**
- ราคาเนื้อเงินวันนี้ ต่อกรัม/ต่อบาท — **อ่านจากหน้าจอ `/silver-price` จริง ไม่ใช่จำมาพูด**
- น้ำหนักจริงบนตาชั่ง (ตั้งกล้องให้เห็นตัวเลขตาชั่ง)
- ราคาขายแท่งนั้น **ของวันนี้** (ราคาป้ายจริง)
- "ส่วนต่างคือค่าผลิต ค่าใบรับรอง ค่าดำเนินการ" — เชิงคุณภาพได้
- "ราคาเดียวกันทุกคน ทุกช่องทาง ไม่มีราคาลับ" · "ราคาขยับทุกวันตามตลาดโลก"

**ห้ามพูด**
- ❌ ค่าผลิต/ค่าดำเนินการ **เป็นตัวเลข** ต่อแท่ง
- ❌ % premium / % กำไร / คำว่า margin
- ❌ ราคาที่ร้าน**ซื้อเข้า** · ชื่อโรงหลอม/ซัพพลายเออร์ · ปริมาณสั่งผลิตต่อรอบ
- ❌ "ราคานี้ถึงสิ้นเดือน / การันตีราคา"
- ❌ เทียบราคาร้านอื่นเป็นตัวเลข

**ต้องขึ้นจอ:** `ราคา ณ วันที่ [DD/MM/YY] · เปลี่ยนแปลงทุกวันตามตลาด · เช็คราคาสดที่ 3jthailand.com`

⚠️ คลิปโพสต์ช้ากว่า **3 วัน** จากวันถ่าย → ต้องเบลอ/ตัดตัวเลขออก เหลือแต่ super

### 2.2 V2 — เครื่องประดับ 925 (จำกัด)

**พูดได้:** น้ำหนักจริงในบริบท **คุณภาพ** ("หนัก 4.8 กรัม เนื้อเต็ม ไม่กลวง ไม่ถ่วงตะกั่ว") · "เงินแท้ 925" + โชว์ตราประทับ · "ราคานี้รวมค่าฝีมือช่าง 30 ปี + ขึ้นรูปในโรงงานเราเอง"

**ห้ามพูด**
- ❌ **ห้ามพูดราคาเงินต่อกรัม ในคลิปเดียวกับที่ชั่งเครื่องประดับ** (ข้อห้ามหลัก)
- ❌ "เนื้อเงินในชิ้นนี้เท่ากับ ฿xxx"
- ❌ แจกแจงต้นทุน (ค่าแรง/ชุบ/กล่อง/OEM) เป็นตัวเลข · "ต้นทุนเราแค่..."

> อยากได้คลิป "ทำไมราคานี้" สำหรับ 925 → เล่าเป็น **ขั้นตอนการผลิต** (กี่ขั้น กี่ชั่วโมง กี่มือ) ไม่ใช่ **ส่วนประกอบต้นทุน** — ได้ trust เท่ากันโดยไม่เสียอำนาจต่อรอง

### 2.3 V3 — รับซื้อคืน

> ⚠️ **แก้ไข 2026-08-19 (§5.1)** — spread จริงคือ **หัก ฿1,000–2,000/กิโล แล้วแต่ช่วงเวลา** (≈ ฿15–30 ต่อบาทน้ำหนัก) ประกาศไว้บนเว็บอยู่แล้ว · ข้อห้ามพูดตัวเลขคงที่ยังอยู่ครบ **แต่เพิ่มสิ่งที่พูดได้:** ชี้ไปหน้า `3jthailand.com/silver-price` ได้เลย

**พูดได้:** "รับซื้อคืนเงินแท่งของเราทุกแท่ง" · "อ้างอิงราคาเนื้อเงิน ณ วันที่รับซื้อ ตามราคาตลาดจริง" · "ออนไลน์ล็อกราคา ณ วันที่ของถึงร้าน แล้วโอนเงินให้" · ตัวเลขของ **ธุรกรรมที่กำลังถ่ายอยู่** พร้อม super วันที่

**ห้ามพูด**
- ❌ **ตัวเลขส่วนต่างคงที่ทุกรูปแบบ** — "หัก 30 บาท/บาท", "หักแค่ x%", "ส่วนต่างเท่าเดิมตลอด"
- ❌ "ได้ราคาเท่าที่ซื้อไป" / "ไม่ขาดทุนแน่นอน" / "การันตีราคาไม่ต่ำกว่า…"
- ❌ "ลงทุนเงินได้กำไร x%/ปี" / เทียบผลตอบแทนกับทอง-หุ้น-เงินฝากเป็นตัวเลข
- ❌ "รับซื้อคืนทุกยี่ห้อ" (ถ้ายังไม่ใช่นโยบายจริง)

**ต้องขึ้นจอทุกครั้ง 5 บรรทัด (ห้ามตัด)**
1. `ราคารับซื้อคืนอ้างอิงราคาเนื้อเงิน ณ วันรับซื้อ (ออนไลน์ = วันที่ของถึงร้าน)`
2. `ราคาในคลิปคือราคา ณ วันที่ [DD/MM/YY] เท่านั้น`
3. `รับซื้อคืนเฉพาะเงินแท่ง 3J ที่มีใบรับรอง + โลโก้ประทับครบ`
4. `น้ำหนัก/สภาพต้องตรงใบรับรอง — ชำรุด/ตัดแบ่ง คิดตามน้ำหนักจริงหลังตรวจสอบ`
5. `ไม่ใช่การรับประกันผลตอบแทนการลงทุน · มูลค่าเงินขึ้นลงได้`

**+ ในแคปชัน/ปักหมุด:** `รับซื้อคืนมูลค่าสูงกรุณานัดหมายล่วงหน้า` (เหตุผลเงินสด §4.3)

## 3. ตัวเลขที่อนุมัติให้ใช้

**3.1 V2 (เงินแท่ง)** — ราคาเนื้อเงิน = ค่าสดจาก `/silver-price` วันถ่าย · น้ำหนัก = ตาชั่งในเฟรม · ราคาขาย = ป้ายจริงวันนั้น

โครงสร้างที่ **ห้ามพูดออกไมค์**: ขาย ≈ spot **+20%** → margin **16.7%** (`0042` header); catalog เงินแท่ง 99.99% margin **19%** (owner 2026-08-14)

**3.2 V3** — สูตรที่พูดได้ = **"ราคาเนื้อเงิน ณ วันรับซื้อ"** (ไม่มีตัวเลข spread) · ตัวเลขขึ้นจอได้เฉพาะยอดธุรกรรมที่ถ่ายอยู่ + วันที่ · "หัก 30 บาท/บาท" 🔴 **ห้ามใช้** (spread จริง = ช่วง ฿1,000–2,000/กิโล ดู §5.1 — ชี้ไปหน้าเว็บแทนได้)

**3.3 V9 — เพดานราคาส่ง (guardrail ภายใน ห้ามลงคลิป ใช้ตอบ DM)**

สูตร: `W = R(1−d)` · `C = R(1−m)` · margin หลังลด `= (W−C)/W`
เกณฑ์ **≥12%** เพราะค่าส่ง+แพ็กยังตั้ง = 0 ในระบบ (กดจริงลงอีก 2–4 จุด) → ลงพื้นที่จริง ≈ floor 10% ตาม `discount-policy-99`

| Live 925 | 17% | **5%** | 12.6% | 5% |
| **เงินแท่ง (S 99.99%)** | 19% | **0% — ไม่มีราคาส่ง** | 19% | — |

**เงื่อนไขบังคับ (dealbreaker ทุกข้อ)**
1. **LINE/สั่งตรงเท่านั้น** — ขึ้น marketplace โดน fee 5–10% ทับส่วนลด = ต่ำกว่า floor ทันที
2. **ชำระเต็มก่อนส่ง ห้าม COD ห้ามเครดิต** — บิลใหญ่ + COD = ความเสี่ยงเงินสดที่ไม่มีใครชดเชย
3. **ไม่รับคืนของที่ขายไม่ออก** (คืนเฉพาะชำรุดจากการผลิต) — ไม่งั้นเราออกเงินทุนสต็อกให้แม่ค้าฟรี
4. ค่าส่งลูกค้าจ่าย หรือฟรีเมื่อบิลถึงขั้น — **ห้ามฟรีค่าส่งทุกบิล** (กิน 2–4 จุดจาก 12–13 ที่เหลือ)
5. ~~ขั้นต่ำ **฿5,000/บิล**~~ 🔴 **ยกเลิก (§5.2)** — ขั้นต่ำจริงเป็นจำนวนชิ้น **30–100 ชิ้นขึ้นไป** ตามที่เจ้าของใช้อยู่

**Trade-off ที่ยอมรับ:** ราคาส่ง 925 ที่ −5% → margin เหลือ ~13% ต่ำกว่าขายปลีก LINE (18%) — **ยอม** เพราะแลกกับ ค่าแอด ≈ 0, ไม่มีค่าคอม platform, บิลใหญ่, จ่ายก่อนส่ง (cash cycle ดีกว่าปลีกทุกช่องทาง). แต่เพราะเหลือน้อย **จึงห้ามต่อรองเพิ่มแม้แต่จุดเดียว**

## 4. ความเสี่ยง + ทางลด

### 4.1 ทำไมห้ามชั่งเครื่องประดับเทียบราคาเงิน (ตัวเลข)

คนดู **ลบเลขเองได้**: เห็น "5 กรัม" + "เงินกรัมละ ฿xx" + "ราคา ฿xxx" ในเฟรมเดียว → คอมเมนต์ "เนื้อเงินแค่นี้ ขายเท่านี้ ฟันกำไรหลายเท่า" ข้อสรุปนั้น **ผิด** (ไม่นับค่าแรงช่าง OEM ชุบ กล่อง ของเสีย ค่าคอม) แต่จะเกิดแน่นอน และเป็น narrative ที่ฆ่าราคา — margin จริงหมวดนี้แค่ **17–18%**

ผลถ้าถูกต่อรองสำเร็จแค่ **5 จุด** (ต่อยอด ฿1,000): ก่อน 1,000 − 820 = gross **฿180** → หลัง 950 − 820 = gross **฿130** = กำไรขั้นต้นหาย **28%** ต้องขายเพิ่ม **+38.5%** ถึงได้เท่าเดิม

ฝั่งเงินแท่งตรงข้าม: premium ~20% เป็นเรื่องปกติของ bullion + ลูกค้ารู้อยู่แล้วตอนขายคืน → **เปิดแล้วไม่เสียอะไร ได้ trust ฟรี**

**คู่แข่งได้อะไรจากการเปิด:** ราคาเงินสด + ราคาป้ายเงินแท่ง = **เผยแพร่บนเว็บเราอยู่แล้ว leak = 0** · สิ่งที่คู่แข่งอยากได้จริงคือ ตารางราคาส่ง + ค่าแรงต่อชิ้น + ชื่อซัพพลายเออร์ → ทั้ง 3 ถูกห้ามในนโยบายนี้

### 4.2 V3 ทำไมห้ามตัวเลข spread

- **ตัวเลขยังขัดกันเอง:** "฿30/บาท" (เจ้าของเคยพูด) vs ส่วนต่างในตาราง "฿348/บาท" — บันทึก 2026-08-06 ระบุว่า **คนละชั้น** (ตาราง = เนื้อเงินล้วน, ราคาขายจริง = +ค่าผลิต+premium) และ **มีมติแล้วว่า content buy-back ห้ามล็อกตัวเลข spread** → V3 ตามที่ CMO เขียน **ขัดมติเดิม**
- **binding offer:** ลูกค้าดูคลิปวันนี้ กลับมาขายคืนอีก 8 เดือนแล้วยื่นคลิปให้ดู = ข้อพิพาทที่เราแพ้ทางภาพลักษณ์แม้ถูกทางเงื่อนไข
- **เปิด short position:** ล็อกส่วนต่างเป็นบาทคงที่ = รับความเสี่ยงราคาเงินไว้เองทั้งก้อน ราคาตกแรง = รับซื้อคืนสูงกว่าตลาด (ตรงกับที่ `discount-policy-99` §2 เตือนเรื่อง arbitrage)

**ทางลด:** พลังของคลิปอยู่ที่ "ถ่ายให้ดูว่ารับคืนจริง" **ไม่ได้อยู่ที่ตัวเลข** ตัดตัวเลขออกแล้ว hook แรงเท่าเดิม ความเสี่ยงเป็นศูนย์

### 4.3 V3 ความเสี่ยงเงินสด (จุดที่ทีมอื่นมองไม่เห็น)

คลิปรับซื้อคืนที่ทำงานได้ผล = **สร้างภาระเงินสด ไม่ใช่รายได้** ถ้าไวรัลแล้วมีคนหอบแท่ง 1 กิโลมาขายคืนพร้อมกัน 10 ราย = เงินสดออกหลักล้านในวันเดียว ได้กลับมาเป็นสต็อกที่ต้องรอขายรอบใหม่

**ข้อบังคับก่อนโพสต์ V3:** (ก) วงเงินสดสำรองรับซื้อคืน/วัน ที่เจ้าของกำหนด (ข) ข้อความ "มูลค่าสูงนัดหมายล่วงหน้า" (ค) COO รับเป็นเจ้าภาพ — **ครบ 3 ข้อค่อยโพสต์ และ V3 ไม่ใช่คลิปแรกที่ควรยิงงบ boost**

### 4.4 V9 แม่ค้าจะต่อรองหนักขึ้นไหม

**หนักขึ้นแน่นอน — และนั่นคือเหตุผลที่ต้องพูดเพดานเอง ก่อนถูกถาม** ประกาศ "สูงสุด 25% เฉพาะบางหมวด" = ตั้ง anchor ให้เราเอง ถ้าเงียบ แม่ค้าจะเปิดที่ 40–50% ตามธรรมเนียมตลาด ซึ่งหมวด 925 (margin 18%) **ให้ไม่ได้แม้ครึ่งเดียว**

ทางลด: พูดเพดานหมวดสูงเท่านั้น · พูดตรงๆ ว่า 925 ส่วนต่างบาง (ปิดประตูต่อรองล่วงหน้าอย่างสุภาพ + self-select DM ไปหมวดกำไร) · ราคาจริงคุยใน DM รายราย

### 4.5 กฎหมาย/ข้อพิพาท

V3 แตะเรื่องลงทุน: ห้ามคำว่า "ผลตอบแทน/กำไร/การันตี" + super 5 บรรทัด · V9 ชวนทำธุรกิจ: ห้ามตัวเลขรายได้ (เข้าข่ายชวนลงทุน) · V2: super วันที่ + กฎคลิปเก่าเกิน 3 วันตัดตัวเลข

### 5.1 spread รับซื้อคืน — ตอบแล้ว (เจ้าของ 2026-08-19)

> "จะรับซื้อราคาเนื้อเงินหักประมาณ **กิโลละ 1,000–2,000 บาท แล้วแต่ช่วงเวลา** ปกติแจ้งลูกค้าไว้ในเว็บไซต์ (`3jthailand.com/silver-price`)"

**ตัวเลขที่ขัดกันเอง — ปิดเคสแล้ว** (1 บาทน้ำหนัก = 15.16 ก. → 1 กก. ≈ 65.96 บาทน้ำหนัก):

| หัก/กิโล | = หัก/บาทน้ำหนัก |
|---|---|
| ฿1,000 | ≈ **฿15.2** |
| ฿2,000 | ≈ **฿30.3** |

→ "หัก 30 บาท/บาท" ที่เคยพูด **ไม่ได้ผิด** แต่คือ **ปลายบนของช่วง** ไม่ใช่ค่าคงที่ · ส่วน ฿348/บาท ในตารางเก่าเป็นคนละชั้น (ส่วนต่างราคาขาย ไม่ใช่ spread รับซื้อ) ตามที่บันทึก 2026-08-06 ระบุไว้

**ผลต่อนโยบาย — คำสั่งห้ามใน §2.3 ยังอยู่ครบ แต่เหตุผลเปลี่ยน:**
- ห้ามพูด "หัก 30 บาท/บาท" ต่อไป — ไม่ใช่เพราะไม่รู้ตัวเลข แต่เพราะ **มันเป็นช่วง ไม่ใช่ค่าคงที่** พูดปลายเดียวออกไป = คำมั่นที่เราทำตามไม่ได้ทุกวัน
- ✅ **สิ่งที่พูดได้เพิ่มขึ้น (ปลดล็อกใหม่):** "ราคารับซื้อคืนประกาศไว้หน้าเว็บ `3jthailand.com/silver-price` เปิดดูได้ทุกวัน" — ชี้ไปที่แหล่งที่เผยแพร่อยู่แล้ว ไม่ใช่การล็อกตัวเลขในคลิป **ได้ trust เท่าการพูดตัวเลข โดยไม่สร้าง binding offer** และคลิปไม่หมดอายุตามราคา
- ⚠️ เงื่อนไขใหม่: หน้า `/silver-price` **ต้องมีราคารับซื้อคืนแสดงจริงและอัปเดตจริง** ก่อนคลิป V3 อ้างถึง — ถ้าเว็บไม่มี ห้ามพูดประโยคนี้

### 5.2 ราคาส่ง — ตอบแล้ว (เจ้าของ 2026-08-19)

> "ราคาส่งถ้าขาย online จะไม่ได้มีให้ จะขายราคาเดียวหมดเลย จะเป็นเอาไว้ลูกค้าส่งออกหรือลูกค้าสั่ง order พิเศษ ที่จะขายส่งปกติจะรับ **30–100 ชิ้นขึ้นไป**"

**เปลี่ยนโครงเรื่อง V9 ทั้งอัน:**
- ค้าปลีกออนไลน์ทุกช่องทาง = **ราคาเดียว ไม่มีราคาส่ง** (ข้อนี้กลายเป็นจุดขาย ไม่ใช่ข้อจำกัด)
- ราคาส่ง = ช่องทาง **B2B/ส่งออก/order พิเศษ** เท่านั้น
- ขั้นต่ำเป็น **จำนวนชิ้น 30–100 ชิ้นขึ้นไป** — **ยกเลิกข้อเสนอ "฿5,000/บิล" ใน §3.3 ข้อ 5** (CFO เสนอไว้ตอนยังไม่รู้ว่ามี MOQ จริง)
- ❌ **"ส่วนลดสูงสุด 25%" ห้ามพูดเป็นตัวเลขในคลิปแล้ว** (เปลี่ยนจากมติเดิมใน §2.4) — เหตุผล: พอราคาส่งไม่ใช่ข้อเสนอสาธารณะสำหรับทุกคน การประกาศ % ออกไปจะถูกลูกค้าปลีกเอามาอ้างต่อรอง ทั้งที่เขาไม่เข้าเกณฑ์ → เปลี่ยนเป็น "ราคาขึ้นกับหมวดและจำนวน คุยเป็นรายล็อต"
- ✅ เพดาน §3.3 ยังใช้เป็น guardrail ภายในตอนตีราคาล็อตเหมือนเดิม
- ยังค้าง: **ขั้นต่ำจริงต่อหมวด** (หมวดไหน 30 หมวดไหน 100) — คลิปจะพูดตัวเลขนี้ ต้องให้เจ้าของเคาะก่อนโพสต์

### 5.3 ต้นทุน — เจ้าของเคาะวิธีแล้ว (2026-08-19)

> "ให้ทำแบบนี้ไปก่อน แล้ว stamp ราคาทุนตามนี้ไปเลย อนาคตถ้ามาปรับราคา **ไม่ต้องไปแก้กำไรย้อนหลัง** จะปรับราคาขึ้นลงตามราคาโลกเองอีกที ปรับวันไหนค่อยวางทุนใหม่ถอยย้อน margin ไปวันนั้น"

**ตรวจระบบแล้ว — ทำแบบนี้อยู่แล้ว ไม่ต้องแก้อะไร:**

| กลไก | สถานะจริงใน DB (ตรวจ 2026-08-19) |
|---|---|
| ต้นทุนถูก stamp ตอนขาย | ✅ `fact_order_item.unit_cost_snapshot` — เติมแล้ว 6,133 / 6,175 รายการ |
| กำไรถูก freeze ต่อออเดอร์ | ✅ `fact_order.cogs` + `profit` เก็บเป็นค่าจริง ไม่ได้คำนวณสดตอนอ่าน → **แก้ `product.unit_cost` วันนี้ ไม่กระทบกำไรเดือนที่ผ่านมา** ตรงตามที่เจ้าของสั่ง |
| ต้นทุนแบบผูกราคาสด | ✅ ไม่มี — `cost_type='fixed'` ทั้ง 301 SKU (0 ตัวเป็น `spot`) |

**ที่ยังเหลือจริงๆ 2 จุด (technical debt บันทึกไว้ ไม่เร่ง):**
1. **278 ออเดอร์ยังไม่มี cogs** (~฿62k revenue, ~1.5% ของยอดรวม) — ส่วนใหญ่เป็นออเดอร์ที่ SKU ยังไม่มีในระบบตอน import
2. **ไม่มีประวัติว่าทุนเปลี่ยนวันไหน** — `product.unit_cost` มีค่าเดียว ทับของเก่า ออเดอร์เก่าปลอดภัยเพราะ snapshot ไว้แล้ว แต่ย้อนดูไม่ได้ว่า "ทุนก้อนนี้ตั้งเมื่อไหร่ ตอน margin เท่าไหร่" → ถ้าจะปรับราคาตามราคาโลกบ่อยขึ้น ควรมี `product_cost_history` (วันที่มีผล + margin ที่ใช้ถอย)

### ข้อมูลการเงินที่ต้องมีในระบบเพื่อวัดผลนโยบายนี้ (ให้ Tech Lead)

1. `public.product.wholesale_price` + `wholesale_min_qty` — วันนี้ราคาส่งอยู่ในหัวคน วัดไม่ได้เลย
2. `fact_order.order_type` (`retail`/`wholesale`) — ดู contribution margin แยก 2 ขา ว่าราคาส่งกินกำไรหรือสร้างกำไร
3. `fact_order.platform_fee` + `shipping_cost_shop` กรอกจริง — สองตัวนี้ขาดทำให้ทุกเพดานในเอกสารนี้เป็น conservative estimate
4. **`buyback_transaction`** (น้ำหนัก, ราคาเนื้อเงินอ้างอิง, จำนวนจ่าย, วันที่) — ตอนนี้เงินสดที่จ่ายซื้อคืน **ไม่มีที่บันทึกเลย** = มองไม่เห็นภาระเงินสดของ V3
5. `clip.claim_risk = needs_cfo` ต้อง block การโพสต์จนกว่ามี `verified_by` (ตาม schema §5 taxonomy v2) — ไม่งั้นนโยบายนี้เป็นแค่กระดาษ
