**⚠️ at-risk = 0** — ข้อมูลมีแค่เดือนเดียว ทุกคนเพิ่งซื้อ → **win-back campaign ยังยิงไม่ได้** (ไม่มี audience) รอสะสม 2–3 เดือนให้ recency โต. โฟกัสตอนนี้ = champion/loyal (early access) + new (second purchase).
**silver-bar segment** = ดึงไม่ได้ (ต้อง line-item ต่อ SKU ซึ่งยังว่าง). **geo (กทม.)** = ดึงได้จาก province.

## Decision หลัก (CMO)
1. LINE ห้ามเล่นสงครามราคา — เป็นช่องกำไร (AOV ฿1,626 = 3.3× TikTok) 9.9 ขาย "ได้ก่อน + limited + บริการ"
2. แยก win-back ออกจาก 9.9 (คนละ mood) — *แต่ตอนนี้ win-back พับไว้เพราะไม่มี at-risk*
3. Broadcast teaser แรก = เครื่อง segment ตัวเอง (กดรับสิทธิ์ → tag click → audience วันจริง + ประหยัด quota)

## กลุ่ม + ข้อเสนอ (เฉพาะที่ทำได้ตอนนี้)
- **champion (6):** 1:1 ใน chat — "9.9 Private Access" จอง limited ก่อนขึ้น live 3–4 วัน · perk ต้นทุนต่ำ (สลักชื่อ/กล่องพิเศษ) ไม่ลดเพิ่ม
- **loyal (55):** early access + สิทธิ์ VIP 9.9 · ขาย exclusivity
- **new (177):** เป้า = second purchase (ไม่ใช่ AOV) · offer ชิ้นเข้าชุด ฿500–900 + เล่ามุม craftsmanship 30+ ปีสร้าง trust
- **เงินแท่ง (รอ line-item):** ห้ามลดราคา — มุมลงทุน buy-back หัก 30/บาท + NFC · 9.9 = ฟรีค่าส่ง/ประกัน หรือ bundle แท่ง+จี้ (CFO เคาะก่อน)
- **กทม. (geo):** ถ้า tag ได้ → ดัน Heirloom/ชิ้นสูง + ส่งด่วน กทม.

## ตัวชี้วัด
- Teaser click "รับสิทธิ์" ≥ 15–20% ของ follower = ขนาด audience วันจริง
- champion: absolute — 6 คน เป้า 4–5 ออเดอร์ AOV ≥ ฿1,600
- วันจริง: attribute ด้วย code พิมพ์ใน chat (เช่น "รับสิทธิ์99") — ยังไม่มี tracking link
- สุขภาพช่อง: block/unsub < 2%/broadcast — เกินหยุดทบทวน
- second-purchase rate ของ new (metric ระยะยาวที่ต้องขยับ)

## ต้องระวัง
1. เงินแท่งห้ามลด · 2. ส่วนลดเครื่องประดับ **ต้องผ่าน CFO** (ต้นทุน SKU ยังไม่กรอก) · 3. อย่าไล่คน LINE ไป Shopee 9.9 (เสียค่าธรรมเนียม) · 4. ความถี่/quota — targeted หลัง teaser เท่านั้น · 5. เก็บ consent ใน flow กดรับสิทธิ์

## ข้อมูลที่ยังขาด (ต้องได้จากเจ้าของก่อนส่งจริง)
1. **จำนวน follower LINE OA + แพลน (quota ข้อความ)** — กำหนดว่า blast ได้กี่รอบ
2. **LINE OA รองรับ tag/narrowcast แค่ไหน** — ถ้าไม่มี tag = พึ่ง teaser-click อย่างเดียว
3. Match rate CRM ↔ LINE follower (รู้แล้วบอกได้ว่า broadcast ถึงแต่ละกลุ่มกี่ %)
