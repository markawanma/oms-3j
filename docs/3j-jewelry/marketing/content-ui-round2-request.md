4. ผลลัพธ์ — ขอเพิ่มอีก 3 มุม (มีแล้วแค่ "ต่อโพสต์")
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    · แถวที่ยังไม่ครบ 4 โพสต์แสดง "ยังสรุปไม่ได้ (3/4)" แบบสงบ · ยังไม่ต้องมีกราฟ
4.2 สรุปรายสัปดาห์ฉบับเต็มในแอป: สรุป 5 บรรทัด · ตัวเลขหลัก · ข้อเสนอที่กดตอบได้ในหน้า (เชื่อมกับ inbox กอง 4)
4.3 สัดส่วนเดือนหน้า (สิ้นเดือน): AI เสนอ ชนะ 50% / รอง 25% / เผื่อ 25% · เจ้าของปรับได้
4.4 ทุกตัวเลขผลลัพธ์ต้องมี "โฮสต์คืนนั้น" กำกับ

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5.3 สถานะ "ผิดพลาด" (โหลดไม่ได้ / บันทึกไม่สำเร็จ) + ปุ่มลองใหม่
5.4 สถานะ "ตกรอบวัด" ของโพสต์ (ไม่มียอดรอบวันที่ 5–9) พร้อมเหตุผล

6. สถานะชิ้นงาน — ขอ 1 board สเปกโดยเฉพาะ (brief §3)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6.1 แผนภาพสถานะครบทุกตัว: ไอเดีย → วางแผนแล้ว → AI ร่าง → รอตรวจ → อนุมัติแล้ว → ผลิตแล้ว → โพสต์แล้ว
    → กำลังวัดผล → วัดผลแล้ว · สถานะข้าง: ส่งกลับแก้ · รอเงื่อนไข · เลื่อน · ยกเลิก
6.2 stepper หน้าตาเดียวกันในทุกหน้าที่แสดงชิ้นงาน (inbox · ปฏิทิน · หน้าชิ้นงาน · ผลลัพธ์)
6.3 ใครกดเปลี่ยนสถานะไหนได้ (เจ้าของ / ผู้ช่วย / ระบบ) — ผู้ช่วยต้องไม่เห็นปุ่มอนุมัติ
6.4 การย้อนสถานะ: ย้อนทีละขั้น + กล่องยืนยัน หรือแถบ "เลิกทำ" 5 วินาที
    · ห้ามมีปุ่มที่ทำให้ "อนุมัติแล้ว" หลุดกลับเป็นร่างโดยไม่ตั้งใจ · อนุมัติทั้งชุดต้องยืนยัน
6.5 ตัวอย่างการ์ดที่มี [ต้องยืนยัน: …] ค้างอยู่ → ปุ่มอนุมัติถูกล็อก + บอกว่าต้องแก้อะไร

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7.1 inbox ของ "ผู้ช่วย" (มือถือ): วันนี้ต้องโพสต์ · กรอกยอดวันนี้ · บันทึกหลังไลฟ์ที่ค้าง — ไม่มีกองอนุมัติ
7.2 หน้าของ "คนไลฟ์" (มือถือ เปิดจากลิงก์ตรง): ฟอร์มหลังไลฟ์ + storyboard ที่ตัวเองต้องเป็นหน้ากล้องคืนนี้

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. เส้นทางและการเชื่อมต่อระหว่างหน้า
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8.1 sitemap 1 board: เมนู 6 หมวดตาม brief §7 · ทุกหน้ามีทางเข้า · เมนูข้างกับเมนูย่อยตรงกัน
8.2 เส้นทางผู้ใช้ 3 เส้นแบบ storyboard ต่อกัน (ลูกศรระหว่างจอ):
    (ก) เช้าวันจันทร์ของเจ้าของ: inbox → คัดไอเดีย → อนุมัติชุดสัปดาห์
    (ข) วันปกติก่อนไลฟ์: inbox → คัดลอกฉบับโพสต์ → sheet "โพสต์แล้ว" → บันทึกหลังไลฟ์
    (ค) คลิปคู่แข่ง → ไอเดีย → ชิ้นงาน (hook A/B ชี้กลับคลิปต้นทาง) → โพสต์ → ผลลัพธ์ → ผลไหลกลับคลัง hook
8.3 sheet "หยิบเข้ากล่อง" จากเทรนด์รายวัน: แสดงว่าลิงก์ · เหตุผล · ประเภท ติดไปครบ
8.4 drawer รายละเอียดสัญญาณ: ทุกฟิลด์ + ประวัติ "ถูกหยิบเป็นไอเดียไหน → ชิ้นงานไหน → ผลเป็นยังไง"
8.5 โพสต์นอกแผน: ปุ่ม "ผูกกับชิ้นงาน" ภายหลัง + หน้าตาตอนเลือกชิ้นงาน

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

9.1 ตาราง token สี: สีสถานะ (แยกจากสีประเภท 5 สี) · สีป้าย mass · สีผลลัพธ์ เหนือ/ปกติ/ต่ำ — กำหนดที่เดียวใน board Component
9.2 รายการคำถามหรือสมมติฐานที่ผู้ออกแบบตัดสินเองระหว่างทำ (ดีกว่าเดา)
