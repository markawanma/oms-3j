# วิธีกรอกไฟล์นำเข้าสินค้า (product-import-template.csv)

เปิดไฟล์ `product-import-template.csv` ด้วย Excel หรือ Google Sheets → **ลบ 2 แถวตัวอย่างทิ้ง** →
กรอกสินค้าจริงลงไป (1 แถว = 1 SKU) → บันทึกเป็น **CSV UTF-8** → อัปโหลดที่หน้า
`/catalog` ปุ่ม **"นำเข้าจากไฟล์"**

> ⚠️ ตอนเซฟจาก Excel เลือก **"CSV UTF-8 (Comma delimited)"** ไม่งั้นภาษาไทยจะเพี้ยน

## คอลัมน์ (ห้ามเปลี่ยนชื่อหัวคอลัมน์แถวแรก)

| คอลัมน์ | บังคับ? | ความหมาย | ตัวอย่าง |
|---|---|---|---|
| `sku` | ✅ ใช่ | รหัสสินค้า (ห้ามซ้ำ — ถ้าซ้ำ SKU เดิมจะถูกอัปเดตทับ) | `R-SILVER-01` |
| `name` | ✅ ใช่ | ชื่อสินค้า | `แหวนเงินแท้ลายเกลียว` |
| `category` | ไม่ | หมวด (แหวน/สร้อยคอ/สร้อยข้อมือ/กำไล/จี้/ต่างหู/เงินแท่ง/อื่นๆ) | `แหวน` |
| `cost_type` | ✅ ใช่ | โหมดต้นทุน: `fixed` หรือ `spot` | `fixed` |
| `unit_cost` | เฉพาะ fixed | ต้นทุนต่อชิ้น (บาท) — ใช้เมื่อ `cost_type=fixed` | `180` |
| `silver_weight_g` | เฉพาะ spot | น้ำหนักเงิน (กรัม) — **บังคับเมื่อ `cost_type=spot`** | `15.244` |
| `silver_purity` | ไม่ | ความบริสุทธิ์ (0–1) เว้นว่าง = 0.925 · เงินแท่ง 999 = `0.999` | `0.999` |
| `labor_cost` | ไม่ | ค่ากำเหน็จ/ค่าแรงต่อชิ้น (บาท) — บวกเพิ่มในโหมด spot | `50` |
| `list_price` | ไม่ (แต่ควรมี) | ราคาตั้ง/ป้าย (บาท) — **ต้องมีระบบถึงคำนวณ margin ให้** | `490` |
| `barcode` | ไม่ | บาร์โค้ด | `8850001234567` |
| `supplier` | ไม่ | ซัพพลายเออร์/OEM | `โรงหลอม A` |
| `note` | ไม่ | หมายเหตุ | |
| `is_active` | ไม่ | เปิดใช้งาน: `true`/`false` เว้นว่าง = `true` | `true` |

## กฎสำคัญ
- **fixed** (เครื่องประดับ ต้นทุนคงที่): กรอก `unit_cost` · เว้น `silver_weight_g` ว่างได้
- **spot** (เงินแท่ง ต้นทุนตามราคาเงิน): กรอก `silver_weight_g` (บังคับ) + `silver_purity` + `labor_cost` · เว้น `unit_cost` ว่าง · **ต้องตั้งราคาเงินสปอตที่หน้า /settings ก่อน** ต้นทุนถึงจะคำนวณ
- ค่าเงินทั้งหมด (`unit_cost`, `labor_cost`, `list_price`) ต้อง **≥ 0** · `silver_purity` ต้องอยู่ 0–1
- เงินแท่งไทย: 1 บาท = 15.244 กรัม, ครึ่งบาท = 7.622 ก., 2 บาท = 30.488 ก. (คูณตามน้ำหนัก)
- นำเข้าซ้ำ SKU เดิมได้ = **อัปเดตทับ** (ไม่สร้างซ้ำ) ปลอดภัย แก้ราคาแล้วนำเข้าใหม่ได้เรื่อยๆ

## หลังอัปโหลด
ระบบจะ **แสดงตัวอย่าง + จำนวนแถว** ให้ตรวจก่อน แล้วกด "ยืนยันนำเข้า" · ถ้าแถวไหนผิด
ระบบจะข้ามเฉพาะแถวนั้นแล้วรายงานสาเหตุ (แถวที่ถูกต้องยังนำเข้าได้ตามปกติ)
