## จุดที่ต่างหูต้องคุมเป็นพิเศษ

### 1. ระบบล็อก (back mechanism)
ต้องระบุชัดว่าใช้แบบไหน — กระทบทั้งความปลอดภัย/ต้นทุน/ความสะดวกใส่:
- **Post + friction back (butterfly clutch)** — มาตรฐานที่สุด ต้นทุนต่ำ เหมาะ stud ทั่วไป
- **Post + screw back** — ล็อกแน่นกว่า เหมาะชิ้นที่หนัก/ห้อยยาว กันหลุดง่ายกว่า
- **Hook (ear wire)** — เหมาะดีไซน์ห้อยยาว/dangle ต้องระบุขนาด hook wire (mm) ให้พอดีรูหู ไม่หลวม/แน่นเกิน
- **Clip-on / omega back** — สำหรับคนไม่เจาะหู (นิยมในบางกลุ่มลูกค้าไทย) ต้นทุน/ความซับซ้อนสูงกว่า

### 2. น้ำหนักเบา กันติ่งหูล้า
- ต่างหูเป็นชิ้นเดียวที่ **น้ำหนักกระทบความสบายโดยตรงและทันที** (ห้อยที่ติ่งหูทั้งวัน) — ต้องประเมินน้ำหนักต่อข้าง (กรัม) และเทียบเกณฑ์ทั่วไป: stud เบา ~1–3g/ข้าง, dangle ยาวไม่ควรเกิน ~5g/ข้างถ้าใส่ทั้งวัน
- ถ้าดีไซน์ใหญ่/มีพลอยเยอะจนหนักเกิน → ต้องเตือนตรงๆ และเสนอลดมวล (ลด solid เป็น hollow/open structure ที่ยังผ่านเกณฑ์ผนัง 0.8mm, ลดขนาดพลอย)

### 3. คู่ซ้าย-ขวา mirror
- ต้องระบุชัดว่าเป็น **mirror pair** (ซ้าย-ขวาสมมาตรกลับด้านกัน) ไม่ใช่ copy ชิ้นเดียวกันซ้ำ — สำคัญมากถ้าดีไซน์ไม่สมมาตรในตัวเอง (เช่น ห้อยเอียงข้างเดียว)
- ใน RhinoPython: สร้าง geometry ข้างหนึ่งก่อน แล้ว mirror ด้วย plane ที่ถูกต้อง (ไม่ใช่แค่ copy แล้วหมุน) — ระบุใน comment ให้ช่างเช็ค

### 4. Post/hook attachment point
- จุดเชื่อม post เข้ากับตัวชิ้นงานต้องอยู่ตำแหน่งที่ **สมดุลเมื่อห้อยจริง** (คล้าย center of gravity ของจี้) ไม่ใช่แค่กึ่งกลางเรขาคณิต — ไม่งั้นต่างหูจะเอียงเมื่อใส่จริง

---

## Checklist เฉพาะต่างหู

- [ ] ระบุระบบล็อกชัด (post+friction / screw back / hook / clip-on) พร้อมขนาด mm ของ post/wire
- [ ] ประเมินน้ำหนักต่อข้าง (กรัม) เทียบเกณฑ์ความสบาย
- [ ] ยืนยันเป็น mirror pair ไม่ใช่ copy ตรง
- [ ] จุดเชื่อม post/hook อยู่ตำแหน่งสมดุลเมื่อห้อยจริง
- [ ] Gemstone setting (ถ้ามี) ตามเกณฑ์มาตรฐาน (prong/bezel ≥ 0.7mm)
- [ ] Finish ระบุชัดทั้งสองข้าง (ต้องเหมือนกัน)
- [ ] น้ำหนักเงินรวมทั้งคู่ + เทียบงบ
