## 3. Motif/Metaphor เฉพาะ collection นี้ (หัวใจของไฟล์นี้)

> **ดีไซน์ Wave Embrace = "คลื่นทะเลนุ่ม (soft ocean wave) โอบพลอยที่ซ่อนอยู่ด้านใน" ไม่ใช่ "คลื่นแหลม/ลอนเยอะ" และไม่ใช่ "พลอยที่มองเห็นจากภายนอก"**

- **Motif/Metaphor หลัก**: ผิวบนของ band ไหลเป็นคลื่นนุ่มลูกเดียว (single soft wave peak) เหมือนผิวน้ำทะเลตอนสงบมีระลอกอ่อนๆ — ไม่ใช่คลื่นซัด ไม่ใช่ลอนเวฟถี่แบบผ้าจีบ ควบคู่กับ concept **"ประกายซ่อนด้านใน" (hidden sparkle)**: พลอยฝัง flush อยู่ด้านในวงแหวน มองจากภายนอกจะไม่เห็นเลย เป็นความลับระหว่างคนใส่กับตัวเอง

- **Test คำถามตัดสินใจ** (ใช้เช็คทุกจุดของงาน Wave Embrace):
  1. **"คลื่นยังนุ่มและต่อเนื่องอยู่ไหม?"** — ถ้าดูแหลม/หัก/ลอนถี่เกิน → ทิ้งวิธีนั้น
  2. **"พลอยยังซ่อนอยู่ไหม (มองจากด้านนอกไม่เห็น)?"** — ถ้ามุมไหนเห็นพลอยจากภายนอก → แก้ seat/ตำแหน่งจนซ่อนสนิท ไม่ใช่ยอมให้เห็น

- **NEVER-DO เฉพาะ motif นี้**:
  - ❌ **Sharp wave** — คลื่นมีมุมหักคม/สันแหลม (ขัดกับ "นุ่ม" และเสี่ยงบาดนิ้ว/เกี่ยวเสื้อผ้า)
  - ❌ **Deep curve** — คลื่นลึกเกินจนดูเป็นร่อง/ทำให้ผนัง band บางเฉพาะจุดต่ำกว่าเกณฑ์หล่อ
  - ❌ **Overly wavy** — มีมากกว่า 1 ยอดคลื่นต่อวง หรือคลื่นถี่จนดูรก (ขัดหลัก "มินิมอล" ของแบรนด์)
  - ❌ **Visible stone** — พลอยโผล่ให้เห็นจากมุมมองภายนอกไม่ว่ามุมไหน (คือหัวใจของ "hidden sparkle" ถ้าเห็นพลอย = ผิด concept ทั้งชิ้น ไม่ใช่แค่รายละเอียด)
  - ❌ **Decorative edges** — ขอบตกแต่ง/สลัก/ลายเสริมที่ไม่ได้ทำหน้าที่ (ขัดหลักมินิมอลของแบรนด์และของ collection นี้)

- **กฎโครงสร้างเฉพาะ**:
  - Wave เกิดที่ **ผิวบนของ band เท่านั้น** เป็น **soft peak เดียว** ต่อรอบวง (single peak, ไม่ใช่หลายลอน) — band width ไล่จาก 2.00mm (bottom/ตรงข้ามยอดคลื่น) ไปยัง 2.10mm (top/wave peak) อย่างค่อยเป็นค่อยไป
  - พลอย (White Sapphire 1.3mm, 1–2 เม็ด) ฝัง **flush ด้านในวงแหวนเท่านั้น** ที่ตำแหน่งกลางล่างด้านในใกล้ยอดคลื่น — ห้ามยื่น/นูนจากผิวใน (ต้องเสมอผิวเพื่อไม่บาดนิ้วและไม่มองเห็นจากนอก)
  - Curve ต้องต่อเนื่องแบบ **G1/G2 continuity** ทุกจุด (ไม่มี tangent break, ไม่มี curvature spike ที่จุดเปลี่ยนจาก bottom cross-section ไป wave peak cross-section)

## 4. ภาษาดีไซน์ที่ยึดสำหรับ collection นี้

- **Curve Language**: โค้งนุ่มต่อเนื่องแบบผิวน้ำ (single soft wave, G1/G2 ทุกผิว) — ไม่มีจุดเปลี่ยนทิศฉับพลัน
- **Ribbon/Motif Language**: ไม่มี ribbon ใน collection นี้ — motif คือ "ผิวบน band เป็นคลื่นเดียว" ล้วนๆ ไม่มีชิ้นส่วนแยก/พับ (ต่างจาก Satin Flow ที่เป็นริบบิ้น 2 เส้น — ห้ามสับสน)
- **Surface**: Polish ทั้งด้านนอกและด้านใน (ต่างจาก brand default 2-tone ของ Satin Flow — Wave Embrace เป็น full high polish เพราะไม่มีจุดสัมผัสผิวหนังที่ต้องลด friction เป็นพิเศษ นอกจาก seat พลอยด้านในที่ต้อง flush เนียนไม่สะดุดนิ้ว)
- **Stone**: White Sapphire 1.3mm × 1–2 เม็ด, flush setting ฝังด้านในเท่านั้น ห้ามเห็นจากนอก — ใช้ค่านี้สม่ำเสมอตลอด collection ถ้าจะขยายไปจี้/ต่างหูในอนาคต (คงคอนเซปต์ hidden sparkle เดียวกัน)
- **Metal**: เงิน 92.5 (brand default)
- **Proportion/Balance/Negative Space/Symmetry**: วงแหวนสมมาตรรอบแกน มี wave peak เดียวเด่นเป็นจุดสนใจตรงกลางบน ส่วนที่เหลือของ band เรียบง่ายไม่มี detail แข่ง
