# Satin Flow — Collection Design Intent (AUTHORITATIVE สำหรับ collection นี้เท่านั้น)

> **สถานะ**: ยืนยันจากเจ้าของแบรนด์แล้ว — authoritative สำหรับงานทุกชิ้นใน **collection "Satin Flow" เท่านั้น**
> **ต้องอ่านคู่กับ [`../../00_Brand_Principles.md`](../../00_Brand_Principles.md) เสมอ** — ไฟล์นั้นคือหลัก brand-level (สากลทุก collection), ไฟล์นี้คือ motif เฉพาะของ Satin Flow เพียงอย่างเดียว
> **ห้ามนำ motif "folded satin" ในไฟล์นี้ไปใช้เป็นกฎของ collection อื่น** — นี่คือความผิดพลาดที่เคยเกิดในระบบเดิม (เอา satin ไปตั้งเป็น DNA ทั้งแบรนด์) และแก้ไขแล้วด้วยโครงสร้าง 2 ชั้นนี้

---

## หัวใจของ Motif นี้ (สำคัญที่สุด — อ่านย้ำก่อนเริ่มงาน Satin Flow ทุกครั้ง)

> **ดีไซน์ Satin Flow = "ผ้าซาตินพับ (folded satin fabric)" ไม่ใช่ "การบิดโลหะ (twist)"**

- ❌ **ห้ามคิด/ออกแบบจากคำว่า**: twist, rope, cable, spiral, braided wire, woven, Celtic, mechanical
- ✓ **ให้คิดว่า**: ผ้าซาตินนุ่มพับโอบวัตถุ → กลายเป็นเงินขัดเงา · ริบบิ้น **กว้าง นุ่ม ต่อเนื่อง เรียบ** ผิวใหญ่สะท้อนแสงลื่น โค้งนุ่มนวล

### Test ตัดสินใจทุกครั้ง (ใช้เช็คทุกจุดของงาน Satin Flow)

> **"ยังดูเหมือนผ้าซาตินพับอยู่ไหม?"** — ถ้าไม่ → ทิ้งวิธีนั้น เลือกทางอื่น

---

## กฎการสร้างแหวน Satin Flow (สำคัญมาก — โมเดลแรกทำผิดเพราะบิดทั้งวง ห้ามพลาดซ้ำ)

- แหวน **ไม่บิดรอบวง** (ไม่ใช่ twist ตลอดเส้นรอบวง)
- **Split (การแยก/เปิดริบบิ้น) เกิดเฉพาะบริเวณใกล้หัวแหวนเท่านั้น**
- **ครึ่งล่างของวง (ฝั่งตรงข้ามพลอย) กลับเป็น band ต่อเนื่องธรรมดา ใส่สบายปกติ** — ไม่มี motif ริบบิ้นตรงนี้

### ลำดับโครงสร้างที่ถูกต้อง

```
Normal band (ต่อเนื่อง เรียบ)
    → เปิดออกใกล้พลอย (split เริ่มเฉพาะจุดนี้)
        → ริบบิ้นซาติน 2 เส้น โอบพลอย
    → band รวมกลับเป็นเส้นเดียว (ฝั่งตรงข้ามพลอย)
```

> กฎ split-near-head นี้เป็น**กฎเฉพาะ Satin Flow** — collection อื่นที่ไม่มี ribbon motif ไม่ต้องยึดกฎนี้ (แต่ยังต้องยึดหลัก curve ต่อเนื่อง/comfort-fit ระดับแบรนด์ใน `00_Brand_Principles.md`)

---

## เม็ดพลอย (Stone) — ตามภาษา Satin Flow

- พลอยเป็น**ศูนย์กลางภาพ** — ริบบิ้นมีหน้าที่**โอบรับ ไม่แข่งกับพลอย**
- พลอยต้องดู **floating** (ลอยอยู่ในอ้อมโอบของริบบิ้น ไม่ถูกกลืนหรือถูกบัง)
- Setting ต้อง**กลืนไปกับริบบิ้น** เป็นเนื้อเดียวกับ flow ของผ้า ไม่ใช่ชิ้นส่วนแยก
- **ห้าม prong เทอะทะ** — ถ้าต้องมี prong/setting mechanism ต้องซ่อน/กลืนในเนื้อริบบิ้น ไม่ยื่นแข่งกับพลอย
- **ห้ามแยกพลอยออกจากริบบิ้น** อย่างชัดเจน (ไม่ใช่ setting แบบเกาะติดแยกชิ้น)

## Ribbon Language (ภาษาริบบิ้น) — หัวใจของ collection นี้

| GOOD (ใช้ได้) | BAD (ห้ามเด็ดขาด) |
|---|---|
| Folded satin — ผ้าพับซ้อนเป็นชั้น | Rope / cable — ดูเป็นเชือกกลม |
| Flowing sheet — แผ่นผ้าไหลลื่น | Spiral — บิดเป็นเกลียวรอบแกน |
| Continuous reflection — แสงสะท้อนไหลต่อเนื่องเป็นเส้นยาว | Braided / woven — ลายถักสาน |
| Large smooth surface — ผิวใหญ่เรียบเนียน | Aggressive twist — บิดจัดจนดูเป็นกลไก |
| Gentle curvature — โค้งนุ่มนวล | Mechanical look — ดูเหมือนชิ้นส่วนเครื่องจักร/Celtic knot |

## Surface (ผิว) — เฉพาะ Satin Flow

- ผิวใหญ่ ขัดเงา **calm** (สงบ ไม่รก ไม่เกิดแสงสะท้อนแตกกระจาย) — สอดคล้อง brand default แต่เน้นย้ำเพราะเป็นหัวใจของ "ผ้า"
- Transition (รอยต่อระหว่างส่วน) ต้อง**นุ่ม** — ไม่มีรอยตัดคม
- ไม่มี detail เกินจำเป็น (ไม่ใส่ลาย/ร่อง/texture เสริมที่ไม่ได้ทำหน้าที่)

## Shape (ทรง) — เฉพาะ Satin Flow

- เหมือนการเคลื่อนไหวต่อเนื่องเส้นเดียว (one continuous motion) ของผ้า
- ไม่มีเปลี่ยนทิศมั่ว ไม่มีมุมหักฉับพลัน ไม่แข็งทื่อ

---

## NEVER-DO LIST — เฉพาะ motif นี้ (ห้ามเด็ดขาด)

- ❌ บิดทั้งวง (twist ตลอดเส้นรอบวง)
- ❌ ริบบิ้นเป็นเชือก (rope-like) — ต้องเป็นแผ่นผ้า ไม่ใช่เส้นเชือกกลม
- ❌ ดู Celtic / woven / braided (ลายถักสาน)
- ❌ เพิ่มเส้น/ร่อง/texture/มุมก้าวร้าวเกินความจำเป็น
- ❌ Over-design — เติม detail เกินภาษาดีไซน์นี้เพื่อความ "น่าสนใจ"
- ❌ Prong เทอะทะ / แยกพลอยออกจากริบบิ้นชัดเจน

## Final Goal ของ Satin Flow

> ลูกค้าเห็นแล้วต้องคิดว่า **"ผ้าซาตินกลายเป็นเงิน"** — ไม่ใช่ **"โลหะบิด"**
