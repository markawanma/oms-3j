# 08 — Bracelet Workflow (กำไล/สร้อยข้อมือ)

> **ใช้ตอนไหน**: ทำกำไล/สร้อยข้อมือชิ้นใหม่ — ใช้คู่กับ `04_Claude_Master_Prompt.md` และ `03_3J_CAD_Guideline.md`
> ยังไม่มีตัวอย่างจริงในระบบ — ใช้หลักด้านล่างเป็น checklist หลัก

---

## จุดที่กำไล/สร้อยข้อมือต้องคุมเป็นพิเศษ

### 1. ข้อต่อ/บานพับ (links/hinge)
- ถ้าเป็น **rigid bangle** (วงแข็งชิ้นเดียว/มีบานพับเปิด): ระบุกลไก hinge + safety catch ชัด, จุด hinge เป็นจุดที่ล้าจากการใช้งานซ้ำๆ ต้องหนากว่าเกณฑ์ผนังขั้นต่ำ
- ถ้าเป็น **chain/link bracelet**: ระบุขนาด link แต่ละชิ้น (mm), jump ring ที่เชื่อม, ความหนาลวด (wire gauge) ของแต่ละ link ≥ 0.8mm

### 2. Clasp (ตะขอ/ระบบล็อก)
ต้องระบุชนิดชัด — กระทบความปลอดภัย/ความสะดวกใส่เอง:
- **Lobster clasp** — มาตรฐานที่สุด ใส่เองสะดวก
- **Toggle clasp** — ดีไซน์เด่น แต่หลุดง่ายกว่าถ้าไม่แน่นพอ ไม่เหมาะสร้อยที่มีน้ำหนักดึงมาก
- **Box clasp / hidden clasp** — ดูเรียบร้อย เหมาะกำไลหรู
- **Magnetic clasp** — สะดวกสุดแต่ความปลอดภัยต่ำกว่า ไม่แนะนำถ้าชิ้นงานมูลค่าสูง/พลอยเยอะ

### 3. ขนาดรอบข้อมือ + เผื่อขยับ
- วัดเส้นรอบข้อมือ (cm) ของกลุ่มเป้าหมาย แล้ว**เผื่อ slack** สำหรับความสบาย: กำไลแบบหลวมใส่สบาย +1.5–2cm จากรอบข้อมือจริง, กำไลแบบกระชับ +1–1.5cm
- ถ้ามี extension chain (โซ่ต่อปรับขนาด) ระบุความยาวที่ปรับได้ (เช่น +3–5cm)

### 4. การขยับ/ยืดหยุ่น (articulation)
- Bracelet ต่างจากแหวน/จี้ตรงที่**ต้องขยับตามข้อมือได้** ไม่แข็งเป็นแท่งเดียว (เว้นแต่เป็น cuff/bangle ที่ตั้งใจแข็ง) — ถ้าเป็น flexible design ต้องระบุจุดหมุน/ข้อต่อทุกจุดใน CAD ไม่ใช่ solid ทึบ

### 5. จุดรับแรง (stress points)
- จุดเชื่อมต่อ (link-to-link, link-to-clasp) คือจุดที่รับแรงดึงซ้ำๆ ทุกวัน — ต้องหนา/แข็งแรงกว่าส่วนอื่นของชิ้นงาน แม้ภาพรวมจะดู delicate
- Jump ring ที่เชื่อม clasp เข้ากับสร้อย: เกจลวด ≥ 0.8mm ปิดรอยเชื่อมสนิท (soldered jump ring) ไม่ใช่แค่งอปิด

---

## Checklist เฉพาะกำไล/สร้อยข้อมือ

- [ ] ระบุชนิดโครงสร้าง: rigid bangle / hinged bangle / chain-link / cuff
- [ ] ถ้ามี hinge: ระบุกลไก + safety catch + ความหนาจุด hinge
- [ ] ถ้าเป็น chain-link: ระบุขนาด link + wire gauge ≥ 0.8mm ทุกจุด
- [ ] ระบุชนิด clasp ชัด (lobster/toggle/box/magnetic) + เหตุผลที่เลือก
- [ ] ขนาดรอบข้อมือเป้าหมาย + slack ที่เผื่อ (cm)
- [ ] ระบุจุด articulation/ข้อต่อทุกจุดใน CAD (ถ้าไม่ใช่ rigid design)
- [ ] จุดรับแรง (link-to-clasp, jump ring) หนา/แข็งแรงกว่าเกณฑ์ทั่วไป
- [ ] น้ำหนักเงินรวม + เทียบงบ (bracelet มักหนักกว่าแหวน/ต่างหูมาก — เช็คงบให้ดี)
