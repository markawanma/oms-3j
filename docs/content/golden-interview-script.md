# Golden Energy — Script สัมภาษณ์หัวหน้าช่าง (Shoot Day 1)

**Brand voice**: ผู้เชี่ยวชาญที่ไว้ใจได้ ให้ความรู้ ตอบข้อกลัวตรงๆ ไม่ hard sell (pre-launch — สร้าง credibility)
**เป้าหมาย**: สัมภาษณ์ 1-2 ชม. ครั้งเดียว → แตกเป็น content อย่างน้อย 6 ชิ้น
**กลุ่มเป้าหมาย**: เจ้าของบ้าน 35-55 ปี กลัวโดนหลอก/รั่ว/ทิ้งงาน

---

## ลำดับการถ่ายทำ (rundown วันเดียว)

แนะนำถ่ายตามลำดับนี้ เพราะ warm-up ช่างจากคำถามง่าย → เข้าเนื้อหาเทคนิค → ปิดท้ายด้วยแนะนำตัว (ตอนช่างผ่อนคลายที่สุดแล้ว มักได้ take ที่เป็นธรรมชาติสุด)

1. Warm-up เล็กน้อย (ไม่ต้องอัด) — คุยเล่นให้ช่างชิน กล้อง/ไมค์
2. **Block A: แนะนำตัว + ประสบการณ์** (เริ่มจากง่าย ให้ช่างคุ้นกล้องก่อน)
3. **Block B: ติดโซลาร์คุ้มไหม** (คลิปหลัก — ต้องมีบิลค่าไฟจริงพร้อมหน้ากล้อง)
4. **Block C: ตอบ 3 ข้อกลัว** (รั่ว / ประกัน / คืนทุน)
5. **Block D (เผื่อเวลาเหลือ): 5 สัญญาณช่างไม่ควรจ้าง**
6. B-roll ปิดท้าย (ไม่ต้องมีช่างพูด)

---

## Block A: แนะนำตัวหัวหน้าช่าง (ใช้ทำโพสต์เปิดตัว page)

### คำถาม (เรียงตามลำดับ)
1. "พี่ทำงานด้านโซลาร์เซลล์มากี่ปีแล้ว เริ่มต้นเข้าวงการนี้ได้ยังไง"
2. "ทุกวันนี้ทีมงานติดตั้งไปแล้วกี่หลังคา/กี่ไซต์งานประมาณนี้"
3. "งานติดตั้งที่พี่ภูมิใจที่สุด หรือจำได้แม่นที่สุด คือหลังไหน เพราะอะไร"
4. "เจ้าของบ้านที่มาหาพี่ ส่วนใหญ่มากับความกังวลอะไรมากที่สุด"
5. "ถ้าจะให้พี่บอกสั้นๆ ว่าทำไมเจ้าของบ้านควรเชื่อทีมพี่ พี่จะพูดว่าอะไร"

### ประเด็นที่ต้องพูดให้ครบ (checklist)
- [ ] จำนวนปีประสบการณ์ (ตัวเลขจริงจากช่างเอง)
- [ ] จำนวนงาน/ไซต์ที่เคยทำโดยประมาณ (ถ้าช่างจำได้แม่น ให้พูดตรงๆ ไม่ปัดตัวเลขให้)
- [ ] เคสที่จำได้ชัด (สร้างความเป็นมนุษย์ ไม่ใช่แค่ resume)
- [ ] ความกังวลของลูกค้าที่พบบ่อย (เชื่อมไปสู่ Block C ตามธรรมชาติ)
- [ ] one-liner แนะนำตัวที่ใช้เป็น caption/cover ได้

---

## Block B: "ติดโซลาร์คุ้มไหม" (คลิปหลัก 2-3 นาที)

### คำถาม
1. "เวลามีลูกบ้านถามว่า 'ติดแล้วคุ้มไหม' พี่มักจะเริ่มอธิบายจากอะไร"
2. "ขอให้พี่ลองหยิบบิลค่าไฟตัวอย่างสักใบ แล้วอธิบายให้ฟังว่าพี่ดูตรงไหนก่อน"
3. "จากบิลนี้ พี่จะแนะนำขนาดระบบกี่กิโลวัตต์ ทำไมถึงเลือกขนาดนี้"
4. "เงินลงทุนสำหรับขนาดระบบนี้ ประมาณเท่าไหร่ พี่คิดจากอะไรบ้าง"
5. "แล้วกี่ปีถึงจะคืนทุน พี่คำนวณจากอะไรบ้าง"
6. "มีปัจจัยอะไรที่ทำให้ระยะคืนทุนของแต่ละบ้านไม่เท่ากันบ้าง" (เช่น พฤติกรรมใช้ไฟ, ทิศบ้าน, เงา)

### ประเด็นที่ต้องพูดให้ครบ (checklist)
- [ ] ค่าไฟเดิมต่อเดือน (จากบิลตัวอย่าง — ตัวเลขจริง)
- [ ] ขนาดระบบที่แนะนำ (กิโลวัตต์) + เหตุผลที่เลือกขนาดนี้
- [ ] เงินลงทุนโดยประมาณ
- [ ] ระยะคืนทุนโดยประมาณ + **พูดเป็นช่วง ไม่พูดฟันธงตัวเดียว** (เช่น "ประมาณ X-Y ปี ขึ้นอยู่กับ...")
- [ ] ปัจจัยที่ทำให้แต่ละบ้านต่างกัน (กันคนเข้าใจผิดว่าทุกบ้านเหมือนกันหมด)

---

## Block C: ตอบ 3 ข้อกลัว (แตกเป็น 3 คลิปสั้น ~30-60 วิ ต่อคลิป)

### C1 — หลังคารั่วไหม
**คำถาม**
1. "คำถามที่เจ้าของบ้านกลัวที่สุดข้อหนึ่งคือ 'ติดแล้วหลังคารั่วไหม' พี่ตอบคำถามนี้ยังไง"
2. "วิธีการติดตั้งของทีมพี่ ทำยังไงถึงมั่นใจว่าไม่รั่ว มีขั้นตอนป้องกันอะไรบ้าง"
3. "ถ้าเกิดรั่วขึ้นมาจริงๆ หลังติดตั้งไปแล้ว ทีมพี่รับผิดชอบยังไง"

**ประเด็นต้องครบ**
- [ ] วิธี/เทคนิคการติดตั้งที่ป้องกันการรั่ว (ระบบยึด, วัสดุกันซึม ฯลฯ)
- [ ] สิ่งที่ทำก่อน-หลังติดตั้งเพื่อเช็ค (เช่น ทดสอบรอยต่อ)
- [ ] เงื่อนไขรับผิดชอบถ้ารั่ว (ระยะเวลา, ขอบเขต)

### C2 — ประกันอะไรบ้าง
**คำถาม**
1. "งานติดตั้งโซลาร์ของทีมพี่ มีประกันอะไรคุ้มครองลูกค้าบ้าง"
2. "ประกันแต่ละตัวคุ้มครองอะไร นานแค่ไหน"
3. "ถ้าอุปกรณ์เสียหรือมีปัญหาหลังติดตั้ง ลูกค้าต้องทำยังไง ติดต่อใคร"

**ประเด็นต้องครบ**
- [ ] ประกันงานติดตั้ง (workmanship warranty) — ระยะเวลา, ขอบเขต
- [ ] ประกันอุปกรณ์/แผง/inverter (ถ้าแยกจากผู้ผลิต ต้องบอกชัดว่าใครรับผิดชอบ)
- [ ] ขั้นตอนเคลมจริง (ติดต่อใคร ใช้เวลาเท่าไหร่)
- [ ] **ต้องมีเอกสารประกันจริงถ่ายประกอบ** (ดู B-roll ด้านล่าง)

### C3 — กี่ปีคืนทุน
**คำถาม**
1. "นอกจากตัวอย่างบิลที่ดูไปแล้ว พี่อยากบอกอะไรเพิ่มเติมเรื่องการคืนทุน ที่คนมักเข้าใจผิด"
2. "มีเคสไหนที่คืนทุนเร็วกว่าคาด หรือช้ากว่าคาดบ้าง เพราะอะไร"

**ประเด็นต้องครบ**
- [ ] ย้ำว่าระยะคืนทุนแตกต่างตามบ้าน (ไม่ใช่ตัวเลขตายตัวเดียวทั้งหมด)
- [ ] เคสตัวอย่างจริงถ้ามี (เสริมความน่าเชื่อถือ)

---

## Block D (เผื่อเวลา): "5 สัญญาณช่างโซลาร์ที่ไม่ควรจ้าง"

### คำถาม
1. "ถ้าพี่ต้องเตือนเจ้าของบ้านว่าเจอช่างแบบไหนให้ระวัง พี่จะบอกอะไรบ้าง ลองไล่มาทีละข้อ"
2. (ถามต่อทีละข้อที่ช่างพูด) "ทำไมข้อนี้ถึงเป็นสัญญาณอันตราย เจอแบบนี้แล้วเกิดปัญหาอะไรตามมา"
3. "แล้วช่างที่ไว้ใจได้ควรมีลักษณะตรงข้ามยังไง"

**ประเด็นต้องครบ**
- [ ] ให้ช่างพูดเองอย่างน้อย 3-5 ข้อ (ห้าม script ป้อนลิสต์ให้ช่างอ่านตาม)
- [ ] แต่ละข้อมีเหตุผล/ผลเสียประกอบ ไม่ใช่แค่หัวข้อลอยๆ

---

## B-roll ที่ต้องถ่ายเสริมวันเดียวกัน

- มือช่างกำลังชี้/อธิบายบนบิลค่าไฟ (close-up)
- อุปกรณ์: แผงโซลาร์, inverter, ระบบยึดหลังคา (ถ่ายแยกเป็นชิ้นๆ)
- เอกสารประกัน/ใบรับประกันจริง (ต้องเบลอ/ครอปข้อมูลลูกค้าที่อาจติดในเอกสารตัวอย่าง)
- ภาพช่างกำลังทำงานจริงบนหลังคา (ถ้ามีไซต์งานอยู่ระหว่างติดตั้งช่วงนั้น)
- เครื่องมือช่าง, รถ/ยูนิฟอร์มทีมงาน (สร้างความเป็นมืออาชีพ)
- ภาพกว้างของบ้าน/หลังคาที่ติดตั้งเสร็จแล้ว (ถ้ามีเคสเก่าให้ถ่ายได้)
- หัวหน้าช่างเดินสำรวจ/ตรวจงาน (cutaway ใช้คั่นระหว่างพูด)

## คำแนะนำการถ่าย

- **ฉากหลัก**: โต๊ะทำงาน/ออฟฟิศเรียบร้อย มีอุปกรณ์/เอกสารวางประกอบฉาก หรือถ่ายที่หน้างานจริงถ้ามีไซต์ในวันนั้น (เพิ่มความน่าเชื่อถือกว่าฉากในร่ม)
- **บิลค่าไฟ**: ต้องเป็นบิลจริง (ไม่ใช่ mockup) แต่ **เบลอชื่อ-ที่อยู่-เลขบัญชี/CA-เลขผู้ใช้ไฟ** ของลูกค้าก่อนถ่าย หรือขอ consent จากเจ้าของบิลก่อน — คงไว้เฉพาะตัวเลขหน่วยไฟ/ยอดเงินที่จำเป็นต่อการอธิบาย
- **มุมกล้อง**: มีอย่างน้อย 2 มุม (กว้าง + close-up) ถ่ายพร้อมกันหรือ take ซ้ำ 2 รอบ เผื่อตัดสลับมุมตอน edit ให้คลิปสั้นไม่น่าเบื่อ
- **ไมค์**: ใช้ไมค์ติดปกเสื้อ (lavalier) กันเสียงแตกจากเสียงแอร์/ไซต์งาน
- **แสง**: ถ้าถ่ายในไซต์งานกลางแจ้ง ระวังแสงแดดจ้าเหนือหัว เลือกช่วงเช้า/บ่ายแก่ หรือหาที่ร่ม
- **การพูด**: บอกช่างล่วงหน้าว่า "พูดเหมือนเล่าให้เพื่อนบ้านฟัง ไม่ต้องท่องสคริปต์" — ปล่อยให้ตอบยาวได้ ตัดต่อทีหลัง
- ถ่าย safety shot: ให้ช่างพูดจบประโยคนิ่งๆ 2 วินาทีก่อนตัด (เผื่อพื้นที่ตัดต่อ)

## ธงเตือน (สำคัญ — ต้องอ่านก่อน shoot)

1. **ตัวเลขทุกตัวที่ช่างพูดต้องมาจากช่างเอง ห้าม script ป้อนตัวเลขให้** — ค่าไฟ, ขนาดระบบ (กิโลวัตต์), เงินลงทุน, ระยะคืนทุน (ปี), % ประหยัด ทั้งหมดต้องเป็นตัวเลขจริงที่ช่างยืนยันจากงานจริงหรือเคสจริง คำถามในสคริปต์นี้ออกแบบให้ "ถาม" ไม่ใช่ "บอกคำตอบ"
2. **claim "ประหยัด X%" หรือ "คืนทุนใน X ปี" ต้องมีเงื่อนไขกำกับเสมอ** เมื่อนำไปตัดเป็น caption/on-screen text ทีมงานหลัง production ต้องใส่ข้อความกำกับ เช่น "ตัวเลขจากเคสตัวอย่าง ผลจริงขึ้นอยู่กับขนาดระบบ พฤติกรรมใช้ไฟ และสภาพหลังคาของแต่ละบ้าน" — ห้ามปล่อยตัวเลขลอยๆ แบบฟันธงราวกับใช้ได้กับทุกบ้าน
3. **ข้อมูลส่วนตัวลูกค้าในบิลค่าไฟ/เอกสารประกัน/ภาพไซต์งาน** ต้องเบลอหรือขอ consent ก่อนถ่าย/เผยแพร่ — ชื่อ, ที่อยู่, เลขผู้ใช้ไฟ, เลขบัญชี, ป้ายทะเบียนรถหน้าบ้านลูกค้าที่อาจติดในเฟรม
4. เนื้อหาประกัน (Block C2) ทีม content ต้องเช็คกับเงื่อนไขประกันจริงในสัญญาก่อนใช้ตัด caption — ห้ามสรุปเกินกว่าที่ช่างพูดหรือเกินกว่าเอกสารจริงระบุ
5. เนื้อหานี้เป็น pre-launch (ยังไม่ขาย) — เมื่อตัดต่อเป็น final content ต้องยึดโทน "ให้ความรู้/สร้างความน่าเชื่อถือ" ห้ามใส่ CTA ขาย/ราคาโปรโมชันในคลิปชุดนี้

---

## วัตถุดิบที่ยังขาด (ต้องเตรียมก่อน/ระหว่าง shoot day)

- บิลค่าไฟตัวอย่างจริง (พร้อม consent จากเจ้าของบิล หรือเลือกบิลที่ตกลงใช้ได้แล้ว)
- รายชื่อ/รายละเอียดประกันที่บริษัทให้จริง (เอกสารต้นฉบับ) เพื่อเช็คกับสิ่งที่ช่างพูดหลังสัมภาษณ์
- ยืนยันว่ามีไซต์งานจริงให้ถ่าย B-roll ในวันเดียวกันหรือไม่ (ถ้าไม่มี ต้องวางแผนถ่าย B-roll อุปกรณ์แยกที่โกดัง/ออฟฟิศแทน)
- ชื่อ/ตำแหน่งทางการของหัวหน้าช่าง (สำหรับ caption แนะนำตัว) และช่องทางติดต่อที่จะใช้โปรโมต (ถ้ามีการเปิด page แล้ว)
