# 3J Jewelry — Content Calendar เดือนแรก (Phase 1 Pilot)

> ขอบเขต: **เฉพาะ 3J Jewelry** ตามมติบอร์ด — pilot 4-6 สัปดาห์ให้ workflow นิ่งก่อนขยายไป Golden Energy / ชุนหลีคลินิก
> Capacity จริง: ~5-7 ชิ้น content/สัปดาห์ (ไม่รวมชั่วโมง live) + host รับ live เพิ่มได้ ~2 ชม./วัน

---

## 0. เหตุผลการจัดลำดับ (ทำไมวางแบบนี้)

- **Live คือเครื่องยนต์รายได้หลัก** → ทุกชิ้น short-form content ต้องรับใช้ live (ดึงคนเข้า live หรือ recap หลัง live) ไม่ใช่ทำคอนเทนต์แยกโดด
- **ราคาเงินวันนี้** เป็น hook ที่ต้นทุนต่ำสุด (แค่เช็คราคา+กราฟิก) แต่สร้าง habit ให้คนกลับมาดูทุกวัน → วางเป็น "แกนกลาง" ของสัปดาห์ ทำก่อนสิ่งอื่น
- **Behind-the-scenes ช่าง 30 ปี** ใช้ทรัพยากรถ่ายครั้งเดียวได้หลายชิ้น (ส่งต่อให้ content-repurposer ตัดเป็น 3-4 คลิป) → ควร shoot สัปดาห์แรกให้ได้ "stock footage" ไว้ใช้ทั้งเดือน
- **สัปดาห์ 1-2** เน้นสร้างจังหวะ (rhythm) + เก็บ baseline metric ก่อน **สัปดาห์ 3-4** เริ่มดูข้อมูลแล้วปรับ theme/เวลา live ตาม data จริง
- ยังไม่ใส่ Golden Energy / คลินิกในสายการผลิต — มีแค่ 1 task เดียวคือ "เผื่อเวลาไว้ล่วงหน้า" ให้เจ้าของนัดสัมภาษณ์หมอ/ทีม solar แบบไม่กระทบ 3J (ระบุใน "วัตถุดิบที่ต้องเตรียม" ด้านล่าง เป็น optional)

| **ความรู้เงินแท้/ลงทุน** | educational — วิธีดูเงินแท้ 925, ทำไมเงินแท่งน่าลงทุน | "เงิน 925 กับเงินชุบ ต่างกันยังไง ดูยังไงไม่โดนหลอก" | 1/สัปดาห์ |

## 2. Live Cadence

- **ความถี่**: 3 ครั้ง/สัปดาห์ (จันทร์ / พุธ / ศุกร์ หรือ ศุกร์-เสาร์-อาทิตย์ ถ้า weekend ขายดีกว่า — ให้ host ยืนยันจาก data เดิม)
- **เวลา**: 2 ชม./ครั้ง (ใช้ budget เดิมของ host เต็ม)
- **โครงสร้าง live**:
  - 15 นาทีแรก: เปิดด้วยราคาเงินวันนี้ + ของเด่นวันนี้ (ดึงคนที่มาจาก short-form)
  - กลาง live: หมุนเวียนสินค้า + ดีลจำกัดเวลา
  - 15 นาทีสุดท้าย: recap + teaser live ครั้งหน้า (ใช้ตัด clip เป็น content recap)
- **Theme หมุนตามวัน**: จ. = เงินแท่งลงทุน / พ. = เครื่องประดับใหม่/คอลเลกชัน / ศ. = โปรท้ายสัปดาห์+ล้างสต็อก
- ทุก live ต้องมีคนจับเวลา/log: viewer peak, order count, GMV → ส่งเข้า tracking (ดูข้อ 6)

## 5. วัตถุดิบที่เจ้าของ/host ต้องเตรียมสัปดาห์แรก

**บังคับ (blocking สัปดาห์ 1):**
1. **Shoot day ช่าง** (อังคารสัปดาห์ 1) — ถ่าย 15-20 นาที กระบวนการทำเครื่องเงิน/หลอมเงินแท่ง เก็บเป็น stock footage ตัดใช้ได้ทั้งเดือน
2. **สัมภาษณ์สั้น 5 นาที** เรื่องเงินแท้ 925 vs เงินชุบ (เจ้าของหรือช่าง) — ใช้สำหรับ pillar ความรู้
3. **แหล่งราคาเงินอ้างอิงรายวัน** — ต้องมีคนรับผิดชอบเช็ค/ส่งราคาให้ copywriter ทุกเช้าก่อน 10 โมง (ไม่มีราคา = โพสต์ไม่ได้)
4. **นัดลูกค้าเก่า 1 คน** สำหรับ testimonial/รีวิว (ใช้สัปดาห์ 2)

**เผื่อไว้ล่วงหน้า (ไม่กระทบ 3J, optional สำหรับขยาย Phase 2):**
- แจ้งทีม Golden Energy/คลินิกว่าจะเริ่มขอสัมภาษณ์ในเดือนถัดไป ให้เริ่มนัดคิวหมอ/ทีม solar ไว้ล่วงหน้าได้ (ไม่ต้องถ่ายจริงตอนนี้)

## 6. Metric ที่ต้องวัดใน 4 สัปดาห์นี้ (ส่งให้ CMO/CFO)

| Metric | เก็บจากไหน | ความถี่ |
|---|---|---|
| **Live viewer → order conversion** | log ต่อ live session (viewer peak, order count) | ทุกครั้ง live |
| **GMV/ชม.live** | ยอดขายระหว่าง live ÷ ชั่วโมง | ทุกครั้ง live |
| **Engagement ต่อ pillar** (view/like/share ราคาเงินวันนี้ vs BTS vs highlight vs รีวิว) | TikTok analytics | รายสัปดาห์ |
| **Content ที่ทำได้จริง vs แผน** (เช็ค overcommit) | นับจากตาราง | รายสัปดาห์ |
| **Shopee traffic ที่มาจาก TikTok** (ถ้า track ได้) | UTM/แชท | รายสัปดาห์ |

**สิ่งที่ต้องให้ Tech Lead ทำใน OMS:**
- เพิ่ม field/log สำหรับบันทึก **live session** (วันที่, ช่วงเวลา, viewer peak, order count, GMV) — ผูกกับ order ที่มาจาก live ใน OMS ให้แยกจาก order Shopee ปกติ ได้
- Dashboard ง่ายๆ สรุป GMV/ชม.live รายสัปดาห์ ให้ CMO/CFO ดึงดูได้โดยไม่ต้องขอ export มือ

## 7. จุดเสี่ยง / ต้อง watch

- **ราคาเงินวันนี้เป็น blocking dependency ทุกวัน** — ถ้า host ไม่ส่งราคาทันเวลา content ทั้งชุดของวันนั้นหลุด ต้องมี fallback (เช่น เช็คราคาจากเว็บสมาคมค้าทองคำ/เงินเอง)
- **Shoot day สัปดาห์ 1 (อังคาร)** เป็นจุดเสี่ยงสุด — ถ้าไม่ได้ถ่ายตามแผน จะไม่มี stock footage ป้อน BTS pillar ทั้งเดือน ต้องยืนยันคิวกับช่างล่วงหน้า
- **Live highlight ต้องรอ host เลือก clip ก่อน** content-repurposer ถึงตัดได้ — ถ้า host ไม่ mark timestamp เด่นหลัง live จะช้า
- **ห้ามแทรก Golden Energy/คลินิกเข้า calendar นี้** แม้จะมีโอกาสด่วน — เข้าคิว Phase 2 เท่านั้น ตามมติบอร์ด
